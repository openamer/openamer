# OpenAmer Agent

**An agent AI dre ar pezh-kemmadur — deskañ eus an arvor, kreiñ skiouezhoù, kouezañ oc'h preferences, ha skeuñ ar redundant evit oc'h parting bezañ.**

Kaoz an ankouzh model a c'hallit d'izhañ — OpenRouter, OpenAI, DeepSeek, ha m eusoc'h. Kemezhañ gant `openamer model` — hep skiouez kod.

## Menmaennoù

- **Interfas terminal gwir — TUI komplett gant autocomplete, istori, ha streaming output ar hervezhoù**
- **Ebo anv e lec'h ma an own eus — Telegram, Discord, Slack, WhatsApp ha mperzh eus unigop porzhill**
- **DispacC'hwez d'ar wele —H — memories, skiouezhoù a zeskuzont ivez, kouezoù tras-sesion**
- **Deleged & paraleliz — kreate sub-aotour evit an oberadur paralel**
- **Automations programad evit reportioù dyverek, kopioù reserved ha gontrolioù — cron integrad**
- **Eleder e plug an traoù bezañ e ront — lokal, Docker, SSH, cloud, serverless**

## Installadur Rapide

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS :
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Kevrezh an ddevezh

```bash
openamer              # Kevrez gant me
openamer setup        # Seta a ranh your kleiojen API ha an tiskizher
openamer model        # Kaozehoc'h an model evit oc'h
openamer update       # Aktualiza gant la version zo nevezoc'h
```

## Kemmañ

Risha OpenAmer evit kemeria a menudo hag e showz ur avertoement e-barzh ar banner kemres. Sevenit `openamer update` evit obtains ar versionne direc'hañ — ruzh an denezh an own data rakouez.
