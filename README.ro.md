# OpenAmer Agent

**Agentul de inteligență automată care se îmbunătățește — învață din experiență, creează abilități, ține minte preferințele tale și lucrează pentru tine oriunde.**

**Traducere**:

## Caracteristici

- **Interfață terminal reală — TUI completă cu completare automată, istoric și ieșire în flux a instrumentelor de lucru.**
- **Trăieșște unde locuiști — Telegram, Discord, Slack, WhatsApp și mai multe dintr-un singur gateway**
- **Învățări pe parcursul timpului — memorie, îmbunătățirea abilităților, recunoașterea în sesiuni diferite**
- **Delegați & paralelizează — lansați subagenți pentru muncă paralelă**
- **Automări programate — cron intern pentru rapoarte zilnice, copii de siguranță, audituri**
- **Runește oriunde — local, Docker, SSH, cloud, serverless**

## Instalare Rapidă

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Pentru început

```bash
openamer              # Începeți discuția.
openamer setup        # Setați cheile tale API & furnizor
openamer model        # Alegeți modelul dvs.
openamer update       # Actualizați la cea mai recentă versiune.
```

## Actualizare

OpenAmer verifică automat actualizările și arată o avertizare în banner-ul de binevenit. Rulăm comanda `openamer update` pentru a obține versiunea cea mai recentă — ea face o copie de siguranță a datelor tale înainte.
