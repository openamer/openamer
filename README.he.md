## התקנה מהירה

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

לינוקס / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## התחלה

```bash
openamer              # התחל לדבר
openamer setup        # הגדר API Keys &amp; ספקית
openamer model        # **בחר את המודל**
openamer update       # עדכנו למהדורה האחרונה
```

## עדכון

OpenAmer בודק אוטומטית אם יש עדכונים ומציג התרשמות התרשמות בבארד הפתיחה. רוץ openamer update כדי לקבל את הגרסה האחרונה — הוא עוקב אחרי נתונים שלך בתחילה.

## **התנדבות**

התנדבות היא פעילות שבה אדם נותן את זמנו, ידעו או משאביו לטובת אחרים. התנדבות יכולה להיות בצורה פרטית או מקצועית, ויכולה לכלול פעילויות שונות, כגון:

* **תרומה לארגונים חסות** - תרומה של זמן, ידע או משאבים לארגונים ללא מטרות רווח.
* **פעילות קהילתית** - פעילות שמטרתה לקדם את הקהילה, כגון עבודה בבתי ספר, פעילות ספורטיבית או חברתית.
* **תרומה למחקר** - תרומה של זמן, ידע או משאבים למחקר, כגון חקר רפואי או חקר מד

הצטרפו לקהילה, פתחו את העיסוקים הפתוחים, או שלחו פנייה להוספת תוספים.
