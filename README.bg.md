# OpenAmer Agent

**Самоусъвършенстващият се AI агент — учи се от опита, създава умения, помни предпочитанията ви и работи за вас навсякъде.**

Използвайте всеки модел, който пожелаете — OpenRouter, OpenAI, DeepSeek и други. Превключвайте с `openamer model` — без промени в кода.

## Функции

- **Истински терминален интерфейс — пълен TUI с автодопълване, история и стрийминг на изхода от инструментите**
- **Бъдете там, където са и вашите потребители — Telegram, Discord, Slack, WhatsApp и още много други от един единствен шлюз**
- **Учи се с времето — памет, самоусъвършенстващи се умения, припомняне между сесиите**
- **Делегира и паралелизира — създава под-агенти за паралелна работа**
- **Планирани автоматизации — вграден cron за ежедневни отчети, архиви и одити**
- **Работи навсякъде — локално, в Docker, през SSH, в облака, serverless**

## Бърза инсталация

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Първи стъпки

```bash
openamer              # Започнете чата
openamer setup        # Настройте вашите API ключове и доставчик
openamer model        # Изберете своя модел
openamer update       # Обновете до последната версия
```

## Актуализиране

OpenAmer проверява за актуализации автоматично и показва предупреждение в приветствения банер. Изпълнете `openamer update`, за да получите последната версия — първо ще бъде направено резервно копие на вашите данни.
