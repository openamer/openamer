# OpenAmer Agent

**Agbanyeghị AI na-emezi onwe ya — mụta site na ahụmịhe, mepụta nka, cheta mmasị gị, na rụọ ọrụ maka gị n'ebe ọ bụla.**

Jiri ụdị ọ bụla ịchọrọ — OpenRouter, OpenAI, DeepSeek, na ndị ọzọ. Gbanwee na `openamer model` — enweghị mgbanwe koodu.

## Njirimara

- **Ezi interface terminal — TUI zuru ezu nwere autocomplete, akụkọ, na ngwá ọrụ na-ebufe ihe.**
- **Bi ebe ị nọ — Telegram, Discord, Slack, WhatsApp na ọtụtụ ndị ọzọ site na otu ụzọ.**
- **Na-amụta n’oge — ncheta, nka na-emezi onwe ya, icheta n’oge dị iche.**
- **Ndị nnọchiteanya & na-eme ka ọ bụrụ nke dị iche — mepụta ndị ọrụ ndị ọzọ maka ọrụ dị iche.**
- **Ntọala akpaghị aka — cron nke etinyere n'ime ya maka akụkọ kwa ụbọchị, ndabere, nyocha**
- **Na-agba ebe ọ bụla — mpaghara, Docker, SSH, igwe ojii, na-enweghị sava**

## Ntuziaka ngwa ngwa

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Iji malite

```bash
openamer              # Malite ikwu okwu
openamer setup        # Hazie igodo API gị na onye na-enye.
openamer model        # Họrọ ụdị gị
openamer update       # Melite na nsụgharị kachasị ọhụrụ
```

## Na-emelite

OpenAmer na-enyocha maka mmelite n'onwe ya ma na-egosi ịdọ aka ná ntị na banner nnabata. Gbaa openamer update ka ị nweta ụdị kachasị ọhụrụ — ọ na-echekwa data gị mbụ.

## Ikwado
