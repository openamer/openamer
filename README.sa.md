# OpenAmer Agent

**स्व-उन्नति-क्षमः कृत्रिम-बुद्धि-अभिकर्ता — अनुभवात् शिक्षताम्, कौशलानि सृजताम्, भवतः अभिरुच्यान् स्मरताम्, तथा च सर्वत्र भवतः कृते कार्यताम्।**

यत् इच्छिते तत् प्रतिरूपं (model) उपयुङ्क्तुं शक्नोषि — OpenRouter, OpenAI, DeepSeek, अन्ये च। `openamer model` इत्यनेन परिवर्तनं कुरु — कस्यापि सङ्केतपरिवर्तनस्य (code changes) आवश्यकता नास्ति।

## विशेषताः

- **वास्तविक-टर्मिनल-अन्तराफलकम् — पूर्ण-TUI (Text User Interface) स्वयंपूर्णाङ्कन-सुविधाया (autocomplete), इतिहास-रक्षणाया (history), तथा च प्रवहमान-उपकरण-निर्गमनाय (streaming tool output) सह।**
- **तत्रैव निवसति यत्र भवान् — Telegram, Discord, Slack, WhatsApp इत्याद्याः एकस्मात् द्वारतः (gateway)**
- **कालेन शिक्षते — स्मृतिः, स्व-सुधारक-कौशलाणि, सत्र-पार-स्मरणम्**
- **प्रतिनिधित्वं तथा समानान्तरणम् करोति — समानान्तरकार्यार्थं उप-अभिकर्तरणानां सृजनं करोति**
- **नियतकालात् स्वयंचालिताः प्रक्रियाः — दैनिकीप्रतिवेदनाय, प्रतिरूपणाय, लेखापरीक्षणाय च अन्तर्निहितं 'cron' तंत्रम्**
- **सर्वत्र चलति — स्थानीय-यन्त्रे, Docker-मध्ये, SSH-मार्गे, क्लाउड-यन्त्रे, सर्वरलेस-यन्त्रे च।**

## त्वरित-स्थापनम्

विण्डोज़ (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

लिनक्स / मॅक ओएस (Linux / macOS):
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## आरम्भः

```bash
openamer              # सम्भाषणम् आरभत
openamer setup        # स्वतनः API-कुञ्जिकाः प्रदाता च स्थापयन्तु
openamer model        # स्वकीयं प्रारूपं चिनुत
openamer update       # नूतनतमाय संस्करणाय अद्यतनीकुरु।
```

## अद्यतनीकरणम्

OpenAmer स्वचालितरूपेण अद्यतनीकरणान् (updates) अन्वेषयति स्वागत-बैनर-मध्ये च चेतावनीं प्रदर्शयति। नवीनतम-संस्करणं प्राप्तुं `openamer update` आदेशं चालयतु — एतत् प्रथमं भवतः दत्तानां सुरक्षितप्रतिलिपिं (backup) रचयति।
