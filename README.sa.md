## आरंभ करणे

```bash
openamer              # **वार्तालाप आरम्भः** (Vārtālāpa ārambhaḥ)
openamer setup        # **API Key Setup**

अनुप्रयोग प्रवर्तनकर्ता की स्थापना करें (API Key Setup)

अनुप्रयोग प्रवर्तनकर्ता (API Key) एक विशिष्ट संकेतक है जो आपको अनुप्रयोग प्रवर्तनकर्ता प्रदाता (API Provider) के साथ जुड़ने की अनुमति देता है। यहाँ कुछ प्रमुख अनुप्रयोग प्रवर्तनकर्ता प्रदाताओं के लिए सेटअप प्रक्रिया है:

1. **Google Cloud Platform**
	* [Google Cloud Console](https://console.cloud.google.com/) पर जाएँ।
	* अपना अकाउंट बनाएँ या साइन इन करें।
	* **APIs &amp; Services** में जाएँ।
	* **Dashboard** पर क्लिक करें।
	* **Enable APIs and Services** पर क्लिक करें।
	* **Search for** में "Cloud Translation API" टाइप करें और **Cloud Translation API** पर क्लिक करें।
	* **Enable** पर क्लिक करें।
2. **Microsoft Azure**
	* [Azure Portal](https://portal.azure.com/) पर जाएँ।
	* अपना अकाउंट बनाएँ या साइन इन करें।
	* **Azure Active Directory** में जाएँ।
	* **App registrations** पर क्लिक करें।
	* **New registration** पर क्लिक करें।
	* **Name** में अपने अनुप्रयोग का नाम डालें और **Register** पर क्लिक करें।
	* **API permissions** में जाएँ और **Microsoft Translator Text API** को अनुमति दें।
3. **IBM Watson**
openamer model        # **Sanskrit Translation Model**
openamer update       # **नवीनतम संस्करण अपडेट करें**
```
