# OpenAmer Agent

**آژانسی هوشمند خودبه‌روز — از تجربه یاد بگیرید، مهارت‌های خود را ایجاد کنید، ترجیحات خود را به خاطر بسپارید و برای شما کار کنید هرجا که بخواهید.**

**ترجمه:** 
از مدل OpenRouter استفاده می‌کنم. با `openamer model` می‌توانید مدل را عوض کنید.

## ویژگی‌ها

- **این رابط کاربری واقعی — TUI کامل با امکان تکمیل خودکار، تاریخچه و خروجی ابزار جریان‌دار**
- **در جایی که زندگی می‌کنید — تلگرام، دیسکورد، اسلاک و واتساپ و بسیاری دیگر از طریق یک گیت‌وای**
- **تحصیل در طول زمان — حافظه، مهارت های بهبودیافته، بازشناسی در جلسات مختلف**
- **نماینده‌ها و همزمان‌سازی — برای کار همزمان، نماینده‌های فرعی ایجاد می‌کنند**
- **مکاتبات برنامه‌ریزی شده — کرون داخلی برای گزارش‌های روزانه، پشتیبان‌گیری، حسابرسی**
- **هر جا اجرا می شود — محلی، Docker، SSH، ابری، بدون سرور**

## نصب سریع

پاور شل (پاور شل)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

لینوکس / مک او اس
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## شروع کردن

```bash
openamer              # آغاز گفتگو
openamer setup        # **تعیین کلید های API و ارائه دهنده**
openamer model        # من مدل انتخاب کرده‌ام
openamer update       # بروز رسانی به آخرین نسخه
```

## بروزرسانی

OpenAmer به‌ طور خودکار برای بروزرسانی‌های جدید جستجو می‌کند و در باندریست خوش‌آمدی هشدار می‌دهد. برای دریافت نسخه‌ی جدید، دستور openamer update را اجرا کنید — ابتدا داده‌های شما را پشتیبان می‌گیرد.
