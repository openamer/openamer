## Hoʻokani ʻAiʻole

Ka ʻElele o Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Ka 'Īnux / ka 'Ōlelo Mākāua.
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Ka ʻōlelo e hōʻike ai i ka hōʻike

```bash
openamer              # He ʻōlelo aiʻai! (Let's talk!)
openamer setup        # E hoʻomaʻa ʻoe i nā kāinoa API ʻo ʻoe & nā ʻōlelo aʻo
openamer model        # E ʻōlelo ʻaiʻai loa no kāu model.
openamer update       # ʻOu kaʻu i mea hoʻokōkō i nā mea ʻāina ʻōlelo ʻōlelo Hawaiʻi.
```
