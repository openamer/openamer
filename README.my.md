# OpenAmer Agent

**အောက်ပါကျွန်းပြောင်းသော AI အေဂျင့် — ကျွန်းပြောင်းမှာလို့ ကြို့ပြောင်းခြင်း, ကျွန်းပြောင်းမှာလို့ ကြို့ပြောင်းခြင်း, ကျွန်းပြောင်းမှာလို့ ကြို့ပြောင်းခြင်း, ကျွန်းပြောင်းမှာလို့ ကြို့ပြောင်းခြင်း နို့့့့့့့့့့့**

မြန်မာစာပြန်ခြင်းသည် အခြေခ်မ်းသော ပြန်ခြင်းဖြစ်ပြီး အခြေခ်မ်းသော ပြန်ခြင်းဖြစ်သည်။ အခြေခ်မ်းသော ပြန်ခြင်းသည် ပြန်ခြင်းဖြစ်သည်။ အခြေခ်မ်းသော ပြန်ခြင်းသည် ပြန်ခြင်းဖြစ်သည်။ အခြေခ်မ်းသော ပြန်ခြင်းသည် ပြန်ခြင်

## **အချက်များ**

- ****အကွက်စက်ပြင်ပြင်းပြင်းပြင်းပြင်းပြင်း** **အကွက်စက်ပြင်ပြင်းပြင်းပြင်းပြင်း** **အကွက်စက်ပြင်ပြင်းပြင်းပြင်း** **အကွက်စက်ပြင်ပြင်းပြင်းပြင်း** **အကွက်စက်ပြင်ပြင်းပြင်းပြင်း** **အကွက်စက်ပြင်ပြင်းပြင်းပြင်း** **အကွက်စက်ပြင်ပြင်**
- **အချိန်ပါလို့ အချိန်မှားပါတယ်။ အချိန်ပါလို့ အချိန်မှားပါတယ်။**
- **ပြောင်းလာသောနေ့စဉ် — အမြင်ခြင်း, ပိုမိုအေလက်ခြင်းစွမ်းဆုံးခြင်း, ဆက်လက်ခြင်း**
- **သဘာဝနှင့် အချုံးချယ် — အခြားအချုံးချယ်အချက်အားများဖြင့် အခြားအချုံးချယ်အချက်အားများကို ဖြစ်စေသည်**
- **အမြင်တော်မူချက်များကိုပြုလုပ်နိုင်သောပရဝတ္ထုများ — တစ်နှစ်ပတိုင်းအချိန်တွင်အချက်ပြက်များ၊ ပြန်ပြင်ခြင်းများ၊ အတုပြုခြင်းများ**
- **အသုံးပြုနိုင်ပါတယ် — မိုင်းလူး, Docker, SSH, လော့ဒ်, ဆားဗာလက်, ဆားဗာလက်လက်စ်**

## အလွစ်တော်တော်

ဝင်းဒိုးစ် (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## စတာ့စတာ့

```bash
openamer              # ပြန်တမ်းစကားပွားပွား
openamer setup        # အေပါင့်အပိုင်းအချက်အလက်များကို စီစဉ်ပါ။
openamer model        # မြန်မာစကားပြန်ခြင်း
openamer update       # အောက်ဖြစ်ပါစေ။
```
