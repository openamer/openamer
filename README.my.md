# OpenAmer Agent

**ကိုယ်တိုင်တိုးတက်အောင် ပြုလုပ်နိုင်သော AI agent — အတွေ့အကြုံများမှ သင်ယူခြင်း၊ ကျွမ်းကျင်မှုများ ဖန်တီးခြင်း၊ သင်၏ နှစ်သက်မှုများကို မှတ်သားထားခြင်းနှင့် နေရာမရွေးတွင် သင့်အတွက် အလုပ်လုပ်ပေးခြင်း။**

သင်နှစ်သက်ရာ မော်ဒယ်ကို အသုံးပြုပါ — OpenRouter, OpenAI, DeepSeek နှင့် အခြားမော်ဒယ်များ။ ကုဒ်များကို ပြင်ဆင်ရန်မလိုဘဲ `openamer model` ဖြင့် အလွယ်တကူ ပြောင်းလဲအသုံးပြုနိုင်ပါသည်။

## အင်္ဂါရပ်များ

- **အစစ်အမှန် terminal interface — autocomplete၊ history နှင့် streaming tool output တို့ပါဝင်သော ပြည့်စုံသော TUI**
- **သင်အသုံးပြုနေကျနေရာများတွင် ရှိနေမည် — Telegram, Discord, Slack, WhatsApp နှင့် အခြားသော နေရာများအားလုံးကို gateway တစ်ခုတည်းမှတစ်ဆင့် အသုံးပြုလိုက်ပါ**
- **အချိန်နှင့်အမျှ လေ့လာသင်ယူနိုင်ခြင်း — မှတ်ဉာဏ်၊ မိမိကိုယ်တိုင် တိုးတက်အောင်ပြုလုပ်နိုင်သော ကျွမ်းကျင်မှုများ၊ session တစ်ခုနှင့်တစ်ခုကြား ပြန်လည်အမှတ်ရနိုင်မှု**
- **တာဝန်ခွဲဝေပေးခြင်းနှင့် ပြိုင်တူလုပ်ဆောင်ခြင်း — ပြိုင်တူအလုပ်လုပ်နိုင်ရန် subagent များကို ဖန်တီးပေးသည်**
- **အချိန်ဇယားသတ်မှတ်ထားသော အလိုအလျောက်လုပ်ဆောင်ချက်များ — နေ့စဉ်အစီရင်ခံစာများ၊ backup ယူခြင်းများနှင့် စစ်ဆေးမှုများအတွက် built-in cron စနစ် ပါဝင်သည်**
- **ဘယ်နေရာမှာမဆို အသုံးပြုနိုင်သည် — local၊ Docker၊ SSH၊ cloud နှင့် serverless တို့တွင် အလုပ်လုပ်သည်**

## အမြန်တပ်ဆင်ခြင်း

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## စတင်အသုံးပြုခြင်း

```bash
openamer              # စတင်စကားပြောဆိုပါ
openamer setup        # သင်၏ API keys နှင့် provider ကို သတ်မှတ်ပါ
openamer model        # သင်၏ မော်ဒယ်ကို ရွေးချယ်ပါ
openamer update       # နောက်ဆုံးဗားရှင်းသို့ အပ်ဒိတ်လုပ်ပါ
```

## မွမ်းမံနေသည်

OpenAmer သည် update များရှိမရှိ အလိုအလျောက်စစ်ဆေးပြီး welcome banner တွင် သတိပေးချက်ကို ပြသပေးပါသည်။ နောက်ဆုံးထွက် version ကို ရယူရန် **openamer update** ကို run ပါ — ၎င်းသည် သင်၏ဒေတာများကို ဦးစွာ backup ပြုလုပ်ပေးမည် ဖြစ်ပါသည်။
