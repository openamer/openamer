## Ierobežojumi

- **Aizmugurējās komandas interfeisa — pilna TUI ar atpazīstamību, vēstures un strādājošo ierīces izvade**
- **Līvo, kur tu esi — Telegram, Discord, Slack, WhatsApp un vēl daži no vienas galvenības.**
- **Mācajas laikā — atmiņa, pašizdodamās spējas, atmiņa starp sesijām**
- **Delegāti & paralelizē — izveido atdalītus agentus paralēlo darbu veikšanai**
- **Sadalīgās automātizācijas — īstenojumi ar daļiņu krātošanu par dienu ziņojumus, atsauktiem, izmeklējumiem.**
- **Runas jebkurā vietā — lokāli, Docker, SSH, nākamās paaudis, bezserverīgi**

## Sākotnējais Instalēšanas process

Pavējuma (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Sākums

```bash
openamer              # Sākt runāt
openamer setup        # Izveidot savu API atslēgas & provideru
openamer model        # Lūk, mani izvēlesiet modeli!
openamer update       # Atjauniniet uz jaunāko versiju.
```

## Atjaunot.

OpenAmer automātiski pārbauda atjaunojumus un par to informē sākumrakstā. Lai iegūtu jaunāko versiju, izpildiet komandu openamer update — tā sagatavos savu dati.
