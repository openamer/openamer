# OpenAmer Agent

**Die self-verbeterende AI-agenteer — leer van ervaring, skep vaardighede, onthou jou voorkeure, en werk vir jou enige waar.**

**Vertaal na Afrikaans**

Ek is 'n professionele vertaler. Ek kan enige model gebruik, soos OpenRouter, OpenAI, DeepSeek, en meer. Ek kan selfs met `openamer model` switser om geen kode te verander.

## Funksies

- **Echte terminaalvrye interface — volle TUI met selfoneerder, geskiedenis, en strooming van werktuiguitset.**
- **Leef waar julle is — Telegram, Discord, Slack, WhatsApp en meer vanuit een poort**
- **Onderhoude oor tyd — geheue, selfverbeterende vaardighede, kruis-sessie onthouing**
- **Verteenwoordigers & paralleliseer — spaw subagents vir parallel werk**
- **Geplande outomatiese aktiwiteite — ingeboude cron vir daglikse verslae, back-ups, audits**
- **En loop op enige plek — plaaslik, Docker, SSH, cloud, serverloos**

## Snel Installeer

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Begin met

```bash
openamer              # Begin om te klets
openamer setup        # Stel jou API-sleutels en verskaffer in.
openamer model        # Ek sal 'n professionele vertaler wees.
openamer update       # **Versoen jouself met die laaste nuwe weergawe**
```

## **Onderhoude**

OpenAmer soek vir updates outomaties en toon 'n waarskuwing in die welkomme banner. Loop openamer update uit om die nuutste weergawe te kry — dit maak 'n back-up van jou data eerst.
