# OpenAmer Agent

**E agente di AI cu ta mehora su mes — siña di experiencia, crea habilidadnan, corda bo preferencianan, y traha pa bo unda sea cu bo ta.**

Uza kualke modelo ku bo kier — OpenRouter, OpenAI, DeepSeek, i mas. Switch ku `openamer model` — sin kambia kódigo.

## Karakterístikanan

- **Interfás di terminal real — TUI kompleto ku autocomplete, historia, i streaming di output di herment**
- **Biba unda bo ta — Telegram, Discord, Slack, WhatsApp i mas, tur for di un solo gateway**
- **Ta si cu tempo — memoria, habilidadnan cu ta mehora nan mes, recall entre sesionnan**
- **Delegá i paralisá — spawn sub-agentnan pa trabou paralelo**
- **Automatisashonnan programá — cron integrá pa rapòrtnan diario, backupnan i auditnan**
- **Ta kore kualke kaminda — lokal, Docker, SSH, cloud, serverless**

## Instalashon Rápidu

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Kuminsando

```bash
openamer              # Kuminsá chatiá
openamer setup        # Konfigura bo API keys & provider
openamer model        # Soge bo modelo
openamer update       # Actualisá pa e version mas reciente
```

## Aktualisando

OpenAmer ta check pa updates automaticamente y ta mustra un aviso den e banner di bienvenida. Ejecuta `openamer update` pa haya e version mas reciente — e ta haci un backup di bo datonan prome.
