# OpenAmer Agent

**Na AI agent e vakatubutuba koya vata — vulica mai na veisau, buli na veisau ni cakacaka, nanuma na nomu vinaka, ka cakobuca na nomu cakacaka ena gauna kece.**

Yana vakayaga na model e dua ga o via namaka — OpenRouter, OpenAI, DeepSeek, kei tani tale. Veisau vakayoga na `openamer model` — sega ni owni na veisau ena code.

## Vakatatabu Vakalevu

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Tekivutaki

```bash
openamer              # Tekivutaka na veitalanoa
openamer setup        # Seta vaka a tiko na nomu API keys kei na provider
openamer model        # Vuqa na nomu model
openamer update       # Vakavuturi ki na tikina vou duadua
```

## Soli vakavulici

E rawa vei OpenAmer ni vakatatutaki na vakatovutaki ni update ena kena nona own ka vakatakila e dua na nodvinaka ena banner ni welcome. Vakayagataka na `openamer update` me owni na version vou duadua — ena vakavulici mada na nomu data tani ni bera na kena vakatovutaki.
