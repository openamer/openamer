# OpenAmer Agent

**Ο αυτοβελτιωθείς AI πράκτορας — μαθαίνει από την εμπειρία, δημιουργεί δεξιότητες, θυμάται τις προτιμήσεις σας και εργάζεται για εσάς παντού.**

Χρησιμοποιήστε οποιοδήποτε μοντέλο επιθυμείτε — OpenRouter, OpenAI, DeepSeek και άλλα. Αλλάξτε το με την εντολή `openamer model` — χωρίς αλλαγές στον κώδικα.

## Χαρακτηριστικά

- **Πραγματικό τερματικό περιβάλλον — πλήρες TUI με αυτόματη συμπλήρωση, ιστορικό και ροή εξόδου εργαλείων (streaming tool output)**
- **Εκεί που βρίσκεστε — Telegram, Discord, Slack, WhatsApp και άλλα, από μία μόνο πύλη**
- **Μαθαίνει με τον καιρό — μνήμη, δεξιότητες αυτοβελτίωσης, ανάκληση μεταξύ συνεδριών**
- **Ανάθετση & παραλληλισμός — δημιουργία υπο-πρακτόρων (subagents) για παράλληλη εργασία**
- **Προγραμματισμένοι αυτοματισμοί — ενσωματωμένο cron για καθημερινές αναφορές, αντίγραφα ασφαλείας, ελέγχους (audits)**
- **Εκτελείται παντού — τοπικά, Docker, SSH, cloud, serverless**

## Γρήγορη Εγκατάσταση

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Πρώτα βήματα

```bash
openamer              # Ξεκινήστε τη συνομιλία
openamer setup        # Ρυθμίστε τα κλειδιά API & τον πάροχό σας
openamer model        # Επιλέξτε το μοντέλο σας
openamer update       # Ενημέρωση στην τελευταία έκδοση
```

## Ενημέρωση

Το OpenAmer ελέγχει αυτόματα για ενημερώσεις και εμφανίζει μια προειδοποίηση στο banner καλωσορίσματος. Εκτελέστε την εντολή `openamer update` για να λάβετε την τελευταία έκδοση — πρώτα δημιουργεί ένα αντίγραφο ασφαλείας των δεδομένων σας.
