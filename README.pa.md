# OpenAmer Agent

**ਆਪਣੇ ਆਪ ਨੂੰ ਸੁਧਾਰਨ ਵਾਲਾ ਐਆਈ ਐਜੰਟ - ਅਨੁਭਵ ਤੋਂ ਸਿੱਖੋ, ਕੌਸ਼ਲ ਬਣਾਓ, ਆਪਣੀਆਂ ਤਾਂਹਾਂ ਨੂੰ ਯਾਦ ਰੱਖੋ, ਤੇ ਤੁਹਾਡੇ ਲਈ ਹਰ ਥਾਂ ਕੰਮ ਕਰੋ।**

ਸਾਡੇ ਪਾਸ ਕੰਪਿਊਟਰ ਪ੍ਰੋਗਰਾਮਾਂ ਦੇ ਇੱਕ ਸੰਗ੍ਰਹਿਤ ਸੰਸਾਧਨ ਹੈ ਜੋ ਕਿ ਕਿਸੇ ਵੀ ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰਨ ਦੀ ਸਮਰੱਥਾ ਰੱਖਦਾ ਹੈ। ਜਦੋਂ ਤੁਸੀਂ "openamer model" ਦਾ ਉਪਯੋਗ ਕਰਦੇ ਹੋ, ਤਾਂ ਕੋਈ ਕੋਡ ਨੂੰ ਬਦਲਣ ਦੀ ਲੋੜ ਨਹੀਂ ਹੁੰਦੀ।

## ਵਿਸ਼ੇਸ਼ਤਾਂ

- **ਅਸਲੀ ਟਰਮੀਨਲ ਇੰਟਰਫੇਸ — ਪੂਰਾ TUI ਜਿਸ ਵਿਚ ਆਟੋਮੇਟਿਕ ਕਮਪਲੀਸ਼ਨ, ਹਿਸਟਰੀ ਅਤੇ ਸਟ੍ਰੀਮਿੰਗ ਟੂਲ ਆਉਟਪੁੱਟ ਹੈ।**
- **ਜਿੱਥੇ ਤੁਸੀਂ ਰਹਿੰਦੇ ਹੋ - ਇੱਕ ਗੇਟਵੇ ਤੋਂ ਟੈਲਗਰਾਮ, ਡਿਸਕਰਡ, ਸਲੈਕ, ਵਾਟਸਾਪ ਅਤੇ ਹੋਰ**
- **ਸਿੱਖਦਾ ਹੈ ਸਮਾਂ ਨਾਲ — ਯਾਦਦਾਸ਼ਤ, ਆਪਣੇ-ਆਪ ਨੂੰ ਸੁਧਾਰਨ ਵਾਲੀ ਕਿਸਮਤਾਂ, ਅਤੇ ਅਨੁਕੂਲਨ-ਸੈਸ਼ਨ ਯਾਦਦਾਸ਼ਤ**
- **ਸਹਿਯੋਗੀਆਂ ਅਤੇ ਪਰਾਲੈਲ ਕਰਦਾ ਹੈ — ਪਾਰਲੈਲ ਕੰਮ ਦੇ ਲਈ ਸਬਾਗੈਂਟਾਂ ਦਾ ਜਨਮ ਦਿੰਦਾ ਹੈ**
- **ਸ਼ੈਡਿਊਲਡ ਆਟੋਮੇਸ਼ਨਜ਼ — ਦਿਨੀਆਂ ਵਾਲੇ ਨਿਵੇਦਨ, ਬੈਕਅਪ, ਅਤੇ ਅਡਿਟਸ ਲਈ ਇੰਬਿਊਟਡ ਕਰਾਨ**
- **ਹਰ ਥਾਂ ਚਲੇਂਦਾ ਹੈ — ਸਥਾਨਕ, Docker, SSH, ਕਲਾਉਡ, ਬੇਕਾਰ ਸਰਵਰ**

## ਤੇਜ਼ੀ ਨਾਲ ਸਥਾਪਨਾ ਕਰੋ

ਵਿੰਡੋਜ਼ (ਪਾਵਰਸ਼ੈਲ)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

ਲਿਨਕਸ / ਮੈਕਓਐਸ
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## ਸ਼ੁਰੂ ਕਰਨ ਦਾ ਇੱਕ ਜ਼ਰੂਰੀ ਪੁੱਤਰ ਹੈ

```bash
openamer              # ਚਲੋ ਬਾਲਕਾਂ!
openamer setup        # ਅਪੀ ਕੀਆਂ ਸੈੱਟ ਕਰੋ ਅਤੇ ਪ੍ਰਦਾਤਾ ਸੈੱਟ ਕਰੋ
openamer model        # ਮਾਡਲ ਚੁਣੋ
openamer update       # ਸਾਡੇ ਪਲੇਟਫਾਰਮ 'ਤੇ ਅਪਡੇਟ ਕਰਨ ਲਈ ਕਿਸੇ ਵੀ ਸਮੇਂ ਆਇਆ ਜਾ ਸਕਦਾ ਹੈ। ਸਾਡੇ ਅਪਲੀਕੇਸ਼ਨ ਨੂੰ ਖੋਲ੍ਹਣ ਤੋਂ ਬਾਅਦ, ਤੁਸੀਂ ਸਕਰੋਲ ਦੱਸਣ ਦੇ ਨਿਸ਼ਾਨ 'ਤੇ ਕਲਿੱਕ ਕਰ ਕੇ ਅਪਡੇਟ ਕਰਨ ਦੀ ਜਾਂਚ ਕਰ ਸਕਦੇ ਹੋ।
```

## ਸੋਧਣਾ

ਓਪਨਏਮਰ ਆਪਣੇ ਨਵੇਂ ਸੰਸਕਰਣ ਲਈ ਆਪਣੇ ਆਪ ਹੀ ਨਵੀਆਂ ਨਵੀਆਂ ਜਾਂਚ ਕਰਦਾ ਹੈ ਅਤੇ ਸੁਵਿਧਾ ਬਾਰੇ ਦੱਸਣ ਵਾਲੇ ਬੈਂਨਰ ਵਿੱਚ ਇੱਕ ਚੇਤਵਣੀ ਦਿੰਦਾ ਹੈ। ਓਪਨਏਮਰ ਆਪਡੇਟ ਕਰੋ ਤਾਂ ਕਿ ਤੁਹਾਨੂੰ ਨਵੇਂ ਸੰਸਕਰਣ ਮਿਲੇ ਜਾਂਚੇ ਤੇ ਤੁਹਾਡੇ ਦਾਤਾਂ ਨੂੰ ਪਹਿਲਾਂ ਬੈਕਅੱਪ ਕਰੇ।

## ਸਹਿਯੋਗੀ

ਸਹਿਯੋਗ ਆਮਦਾਨ ਆਉਣ ਲਈ ਸਵਾਗਤ ਹੈ — ਖੋਲ੍ਹੇ ਮੁੱਦੇ, ਪੁੱਲ ਰੀਕੁਐਸਟ ਦੇਣ, ਜਾਂ ਸਮਾਜ ਵਿੱਚ ਸ਼ਾਮਲ ਹੋਣ।
