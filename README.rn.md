## Kuza kwanza

```bash
openamer              # **Kutembea** kwa njia ya kawaida.
openamer setup        # **Kuruhusu API zako kwa wakala**

Ili kufanya hivyo, unahitaji kufuata hatua hizi:

1. **Kuunda kikoa**: Kwanza, unahitaji kujipanga kikoa kwa wakala wa API. Hii inahusisha kuunda kikoa na kufanya maelezo yake ya kibinafsi.
2. **Kupata API key**: Baada ya kujipanga kikoa, unahitaji kupata API key. API key ni taarifa ya kibinafsi inayotumiwa kwa ajili ya kujiunga na wakala wa API.
3. **Kuweka API key**: Baada ya kupata API key, unahitaji kuiweka kwenye kikoa cha API. Hii inahusisha kubadilisha API key kwenye kikoa cha API.
4. **Kuweka wakala wa API**: Baada ya kuweka API key, unahitaji kujipanga wakala wa API. Hii inahusisha kuchagua wakala wa API unaofaa na kujipanga kwa ajili ya kufanya kazi naye.

**Mifano ya kujipanga kikoa**

Kwa mfano, ikiwa unataka kujipanga kikoa kwa wakala wa API ya **Google Maps**, unaweza kufanya hivi:

* Kwanza, unahitaji kujipanga kikoa kwa Google Cloud Console.
* Kisha, unahitaji kupata API key kwa kuchukua API key ya Google Maps.
* Baada ya kupata API key, unahitaji kuiweka kwen
openamer model        # **Mpitikizi wako**.
openamer update       # **Kuweka kwenye mwendo wa mwaka wa mwaka wa kwanza** (Update to the latest version) 

Kuweka kwenye mwendo wa mwaka wa mwaka wa kwanza ni muhimu kwa kuwa inaruhusu kuwa na nafasi ya kwanza katika mwendo wa mwaka wa kila mwaka. Hii inaruhusu kuwa na uwezo wa kufikia maendeleo ya mwaka wa kila mwaka, kama vile kuongeza uwezo wa kufanya kazi, kuongeza uwezo wa kufikia malipo, na kuongeza uwezo wa kufanya maamuzi.
```
