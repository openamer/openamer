# OpenAmer Agent

**O agente de IA que se autoaprimora — aprende com a experiência, cria habilidades, lembra-se de suas preferências e trabalha para você em qualquer lugar.**

Use qualquer modelo que desejar — OpenRouter, OpenAI, DeepSeek e mais. Alterne com `openamer model` — sem alterações no código.

## Recursos

- **Interface de terminal real — TUI completa com preenchimento automático, histórico e saída de ferramentas via streaming**
- **Está onde você está — Telegram, Discord, Slack, WhatsApp e mais, a partir de um único gateway**
- **Aprende com o tempo — memória, habilidades de autoaperfeiçoamento, recordação entre sessões**
- **Delega e paraleliza — cria subagentes para trabalho paralelo**
- **Automações agendadas — cron integrado para relatórios diários, backups, auditorias**
- **Executa em qualquer lugar — local, Docker, SSH, nuvem, serverless**

## Instalação Rápida

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Primeiros passos

```bash
openamer              # Comece a conversar
openamer setup        # Configure suas chaves de API e provedor
openamer model        # Escolha o seu modelo
openamer update       # Atualize para a versão mais recente
```

## Atualizando

O OpenAmer verifica atualizações automaticamente e exibe um aviso no banner de boas-vindas. Execute `openamer update` para obter a versão mais recente — ele faz o backup dos seus dados primeiro.
