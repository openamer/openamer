# OpenAmer Agent

**Agent AI oyo oyo kobongisaka nzoko moko — kobwaka mayele na experience, kokela bopesa, kokanisa makoki na yo, mpe kosala mpona yo kokonza esika nionso.**

Zala na model nionso oyo olingi — OpenRouter, OpenAI, DeepSeek, mpe ebele. Ongola na `openamer model` — kozanga kobongola code.

## Bimoko ya makasi

- **Interface ya terminal ya solosolo — TUI ya kokaba na autocomplete, history, mpe streaming ya output ya tool**
- **Ezali kuna esika ozali — Telegram, Discord, Slack, WhatsApp mpe ebele naino, longola na gateway moko**
- **Leyaka na ntango — kokangisa na mitembo, bokoli ya mayele, kokumbusa makambo ya mbala ekoyaki**
- ****Adelegi mpe asali na paralelisme** — atongaka ba sub-agents mpona kosala misala ebele na mbala moko**
- **Automatisations ya mbala na mbala — cron ya kokitela mpo na rapor ya mokolo na mokolo, backups, mpe audits**
- **Ezalaka partout — na local, Docker, SSH, cloud, serverless**

## Kotonga na noki

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Kobanda

```bash
openamer              # Banda kosolola
openamer setup        # Teya ba API keys na yo mpe provider
openamer model        # Pongela model na yo
openamer update       # Koma na version ya sika
```

## Kokobola

OpenAmer talaka soki ezali updates ya sika automatically mpe emonisi kobondela na banner ya welcome. Sala **openamer update** mpo ozwa version ya sika — ekosala backup ya data na yo liboso.
