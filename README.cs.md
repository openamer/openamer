# OpenAmer Agent

**Samovyvíjející AI agent — učí se z zkušeností, vytváří dovednosti, pamatuje si vaše preference a pracuje pro vás kdekoliv.**

**Použít kterýkoli model chcete** — OpenRouter, OpenAI, DeepSeek a další. Switch s `openamer model` — žádné změny kódu.

## Funkce

- **Reálný terminálový rozhraní — plný TUI s autocompletáží, historií a přetokem výstupu nástrojů.**
- **Žije tam, kde vy žijete — Telegram, Discord, Slack, WhatsApp a další z jednoho bránu.**
- **Učí se v čase — paměť, sebeúprava dovedností, paměť mezi sezeními**
- **Deleguje & paralelizuje — spustí podagenty pro paralelní práci**
- **Nastavené automatizace — v zabudované cron pro denní zprávy, zálohy, audit

**[Scheduled automations — built-in cron for daily reports, backups, audits](https://example.com)****
- **Spadá dohromady – lokálně, v Dockeru, přes SSH, v cloudu, bezserverovost**

## Rychlá Instalace

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## **Začínáme**

Krok 1: Zjistěte, jaký jazyk chcete překládat. Můžete si vybrat z mnoha jazyků, jako je angličtina, španělština, francouzština, němčina, italština, portugalština, japonština, korejština, čínština a mnoho dalších.

Krok 2: Vyberte si překladový software nebo nástroj, který vám bude sloužit jako pomocník při překladu. Existuje mnoho dostupných možností, jako jsou CAT (Computer-Assisted Translation) nástroje, online překladové služby a specializované software pro překlad.

Krok 3: Začněte s překladem malých částí textu a postupujte k větších částem. Nejprve překládejte základní informace a poté se přesuňte k detailům.

Krok 4: Používejte překladové slovníky a pravidla, aby vaše překlad byla přesná a konzistentní.

Krok 5: Kontrolujte si překlad, aby byl přesný a správný.

```bash
openamer              # Počínáme s konverzací.
openamer setup        # Nastavte své API klíče & poskytovatele.
openamer model        # Můj model je hluboký umělecký model, který je založen na sítích transformérů a byl vyvinut na základě velkého množství textových dat.
openamer update       # Aktualizujte na nejnovější verzi.
```

## Aktualizace

OpenAmer automaticky kontroluje aktualizace a zobrazuje upozornění v vlajkovém panelu. Spusťte příkaz openamer update, aby se stáhla nejnovější verze — nejprve se zálohuje váš data.
