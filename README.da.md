# OpenAmer Agent

**Selvforbedrende AI-agent - lær af erfaring, udvikl skilte, husk dine præferencer og arbejd for dig overalt.**

**Translation:**

Jeg bruger gerne enhver model, du ønsker - OpenRouter, OpenAI, DeepSeek og mere. Skift med `openamer model` - ingen kodeændringer.

## Funktioner

- ****Interaktiv terminalinterface** — fuld TUI med autocompletion, historik og streaming af værktøjsoutput**
- **Bo til, hvor du bor — Telegram, Discord, Slack, WhatsApp og meget mere fra én hub**
- **Lærer over tid — hukommelse, selvforbedrende færdigheder, overførsel mellem sessions**
- **Delegerer & parallelerer — starter underagenter til parallelt arbejde**
- ****Planlagte automatiske opgaver** — bygget-in cron for daglige rapporter, sikkerhedskopier, revisioner**
- **Kører overalt — lokal, Docker, SSH, i skyen, uden server**

## Hurtig installation

**Windows (PowerShell)**
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## **Starte med**

```bash
openamer              # **Hej, hvad kan jeg hjælpe dig med?**
openamer setup        # Indstil dine API-nøgler & leverandør
openamer model        # **Velg din modell**
openamer update       # Opdater til den seneste version.
```

## **Opgangsrevision**

OpenAmer tjekker automatisk efter opdateringer og viser en advarsel i velkomstbanneret. Kør openamer update for at få den seneste version – den sikrer først dine data op.
