## Vifaa

- **Mfumo wa terminal ya asili — TUI kamili yenye uandikaji wa pamoja, historia, na utupu wa mchakato wa zana**
- **Uniko wapi unakaa — Telegram, Discord, Slack, WhatsApp na zaidi kutoka kwa kumbukumbu moja.**
- **Linaelimika kwa muda — ujifunzaji, uwezo wa kujifunza, kumbukumbu ya kujumlisha kati ya seseni**
- **Wakati wa kutekelezeka na kudhibitiwa — kuweka subagents kwa ajili ya kazi ya kipindi**
- **Uendeshaji wa kihalijali — cron iliyojengwa kwa ajili ya ripoti za siku, kuuza, usimamizi wa kila siku**
- **Inaweza kufanyika kwa wote — mahali pa karibu, Docker, SSH, mazingira ya anga, bila mashirika**

## Uchakata Rasmi

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Kuanza

```bash
openamer              # Kuanza kujadili
openamer setup        # Uchague API yako na meneja wa huduma ya API
openamer model        # Chagua mbinu yako.
openamer update       # Tumia tofauti ya mwisho
```

## Kubadilisha

OpenAmer huangazia kila wakati kwa majibu ya kufupishwa na kuonyesha ujumbe wa kuwasilisha katika banner la kuwasiliana. Zungumza openamer update ili kupata tofauti zaidi za siku — inakamari data yako kabla ya kuanza.
