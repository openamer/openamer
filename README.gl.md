# OpenAmer Agent

**O axente de intelixencia artificial que se mellora a si mesmo — aprende da experiencia, crea habilidades, lembra as túas preferencias e traballa por ti en calquera parte.**

**Tradución**

O OpenRouter é unha rede aberta e descentralizada que permite a conexión entre diferentes redes e sistemas. Está baseada en tecnoloxías como a blockchain e a criptografía, e permite a creación de canles de datos seguras e privadas.

## Características

- **Interface de terminal real — TUI completo con autocompletar, historia e saída en tempo real**
- **Vive onde vosas — Telegram, Discord, Slack, WhatsApp e máis desde unha porta de entrada.**
- **Aprende ao longo do tempo — memoria, habilidades autoamelioradoras, recoñecemento transversal entre sesións**
- **Delegados e paraleliza — spawn subagentes para traballo paralelo.**
- **Automacións programadas — cron integrado para informes diarios, copias de seguridade, auditorías**
- **Corre en calquera lugar — local, Docker, SSH, nube, serverless.**

## Instalação Rápida

Windows (PoderShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Comezar a traballar

```bash
openamer              # Comezar a chamar
openamer setup        # Configura as tuas chaves API e o provedor.
openamer model        # Escolle o modelo.
openamer update       # **Actualización ao último versión**
```

## Actualización

OpenAmer checa as actualizacións automaticamente e mostra un aviso na bandeira de benvida. Executa openamer update para obter a versión máis recente — primeiro fai unha copia de seguridade dos datos.
