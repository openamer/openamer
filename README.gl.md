# OpenAmer Agent

**O axente de IA que se mellora a si mesmo: aprende da experiencia, crea habilidades, lembra as túas preferencias e traballa para ti en calquera lugar.**

Usa calquera modelo que queiras: OpenRouter, OpenAI, DeepSeek e máis. Cambia con `openamer model`, sen necesidade de cambiar o código.

## Características

- **Interface de terminal real — TUI completa con autocompletado, historial e saída de ferramentas en fluxo (streaming)**
- **Vive onde ti vives — Telegram, Discord, Slack, WhatsApp e máis dende unha única pasarela**
- **Aprende co tempo — memoria, habilidades de automellora, recordación entre sesións**
- **Delega e paralela — crea subaxentes para traballo en paralelo**
- **Automatizacións programadas — cron integrado para informes diarios, copias de seguridade e auditorías**
- **Execútase en calquera lugar: local, Docker, SSH, nube, serverless**

## Instalación rápida

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Primeiros pasos

```bash
openamer              # Comeza a chatear
openamer setup        # Configura as túas chaves de API e o provedor
openamer model        # Escolle o teu modelo
openamer update       # Actualizar á última versión
```

## Actualizando

OpenAmer busca actualizacións automaticamente e amosa un aviso no banner de benvida. Executa `openamer update` para obter a versión máis recente; primeiro fai unha copia de seguridade dos teus datos.
