# OpenAmer Agent

**L'agent IA auto-améliorant — apprend de l'expérience, crée des compétences, mémorise vos préférences et travaille pour vous partout.**

Utilisez le modèle de votre choix — OpenRouter, OpenAI, DeepSeek et bien d'autres. Basculez avec `openamer model` — sans modification de code.

## Fonctionnalités

- **Interface de terminal réelle — TUI complète avec autocomplétion, historique et flux de sortie d'outils en temps réel**
- **Là où vous vous trouvez — Telegram, Discord, Slack, WhatsApp et plus encore, via une seule passerelle**
- **Apprend au fil du temps — mémoire, compétences auto-améliorables, rappel d'une session à l'autre**
- **Délègue et parallélise — génère des sous-agents pour un travail parallèle**
- **Automatisations planifiées — cron intégré pour les rapports quotidiens, les sauvegardes et les audits**
- **S'exécute partout — local, Docker, SSH, cloud, serverless**

## Installation rapide

Windows (PowerShell) :
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS :
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Prise en main

```bash
openamer              # Commencer à discuter
openamer setup        # Configurez vos clés API et votre fournisseur
openamer model        # Choisissez votre modèle
openamer update       # Mettre à jour vers la dernière version
```

## Mise à jour

OpenAmer recherche automatiquement les mises à jour et affiche un avertissement dans la bannière d'accueil. Exécutez `openamer update` pour obtenir la dernière version — vos données sont sauvegardées au préalable.
