# OpenAmer Agent

**Agent AI ti kîrî-ye-ye — mûndê na experiênse, wîri’i ndê ti sîngî, mûndê na preference ti mo, na sara nzoni ti mo na ndo kue.**

Sôngö model koua kue wâ — OpenRouter, OpenAI, DeepSeek, na e gue. Sôngö model ayeke na `openamer model` — e ye të e chang code.

## Nguïndé

- **Interface ti terminal ti nzoni — TUI të kôkô pëke wâ autocomplete, history, na streaming ti output ti tool yo**
- **A yeke na ndo oko oko kue — Telegram, Discord, Slack, WhatsApp na e’ê kue, nzoni na gatway oko**
- **A mûndu na nzoni na nzoni — mémoire, kîrîmbe ti kîrîmbe ti kîrîmbe, kîrîmbe ti kîrîmbe ti kîrîmbe na kîrîmbe ti kîrîmbe ti kîrîmbe**
- **A délégué nzoni na a sélé ayé — a sélé bani ti subagents pouka ti sélé tëmbe na parallel**
- **Nga-ndu ti automations — cron ti nzoni ti reports ti oko nzoni, backups, ay audit**
- **A sê na nyïndö kue — na ndo, Docker, SSH, cloud, serverless**

## Sengili installation

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Sengili kobe

```bash
openamer              # Amëbë tî tongo
openamer setup        # Sigi ayé na ndo ti API keys wè na provider wè
openamer model        # Torongo model na zo.
openamer update       # Mise à jour na version ti nzoni ti kôkô
```

## Sengue

OpenAmer a hutingue ayeke wali ayeke huti na nzoni ndo na nzoni, tonga pëkö ayeke sô mbiro na banner ti welcome. Run `openamer update` pou ayeke wuti version ti nzoni pëkö — a yeke sô backup ti data ti mo pëkö.
