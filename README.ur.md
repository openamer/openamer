## تیزی سے نصب کریں

وِنڈوز (پاور شیل)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

لینکس / مېکس او ایس
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## شروعات

```bash
openamer              # شروع کرنے کے لئے بات چیت شروع کرنے کے لئے کیا ہے؟
openamer setup        # API کی کلیدوں کو ترتیب دوں اور پورٹلر
openamer model        # کسی ماڈل کو منتخب کریں
openamer update       # آپ کو latest version میں اپ ڈیٹ کرنا ہے
```
