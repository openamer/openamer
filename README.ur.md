# OpenAmer Agent

**خود کو بہتر بنانے والا AI ایجنٹ — تجربے سے سیکھیں، نئی مہارتیں پیدا کریں، آپ کی ترجیحات کو یاد رکھیں، اور ہر جگہ آپ کے لیے کام کرے۔**

اپنی پسند کا کوئی بھی ماڈل استعمال کریں — OpenRouter، OpenAI، DeepSeek، اور مزید۔ `openamer model` کے ذریعے تبدیل کریں — کوڈ میں کسی تبدیلی کی ضرورت نہیں۔

## خصوصیات

- **حقیقی ٹرمینل انٹرفیس — مکمل TUI جس میں autocomplete، ہسٹری، اور اسٹریمنگ ٹول آؤٹ پٹ شامل ہے**
- **وہیں موجود جہاں آپ ہیں — ٹیلی گرام، ڈسکارڈ، سلیک، واٹس ایپ اور بہت کچھ، صرف ایک گیٹ وے سے**
- **وقت کے ساتھ سیکھتا ہے — میموری، خود کو بہتر بنانے والی مہارتیں، سیشنز کے درمیان یادداشت (cross-session recall)**
- **تفویض اور متوازی کرتا ہے — متوازی کام کے لیے ذیلی ایجنٹس (subagents) تخلیق کرتا ہے**
- **شیڈولڈ آٹومیشنز — روزانہ کی رپورٹس، بیک اپس، اور آڈٹس کے لیے بلٹ-ان cron**
- **کہیں بھی چلتا ہے — لوکل، Docker، SSH، کلاؤڈ، سرور لیس**

## تیز انسٹالیشن

ونڈوز (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

لینکس / میک او ایس:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## آغاز کرنا

```bash
openamer              # گپ شپ شروع کریں
openamer setup        # اپنی API keys اور provider سیٹ اپ کریں
openamer model        # اپنا ماڈل منتخب کریں
openamer update       # تازہ ترین ورژن پر اپ ڈیٹ کریں
```

## اپ ڈیٹ ہو رہا ہے

OpenAmer خودکار طور پر اپ ڈیٹس چیک کرتا ہے اور ویلکم بینر میں وارننگ دکھاتا ہے۔ تازہ ترین ورژن حاصل کرنے کے لیے `openamer update` چلائیں — یہ پہلے آپ کے ڈیٹا کا بیک اپ لیتا ہے۔
