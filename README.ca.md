# OpenAmer Agent

**L'agent d'intel·ligència artificial autoreferencial —aprenent de l'experiència, crea habilitats, recorda les teves preferències i treballa per a tu en qualsevol lloc.**

**Traducció**

El meu model és capaç de traduir textos des de l'anglès fins al català. Podeu proporcionar-me un text en anglès i jo ho traduiré al català.

## Característiques

- **Interfície de terminal real — TUI completa amb autocompleció, història i sortida en directe dels eines**
- **Visca on hi faci des de aquí — Telegram, Discord, Slack, WhatsApp i molts més des d'una porta de sortida**
- **Aprenga a mesura que passa — memòria, habilitats que es millorin elles mateixes, recuperació entre sessions**
- **Delegants & paral·lelitzem — spawn subagències per treball en paral·lel**
- **Automatitzacions programades — cron integrat per a informes diaris, còpies de seguretat, auditoria**
- **Es executa en qualsevol lloc — local, Docker, SSH, cloud, sense servidor**

## Instal·lació Ràpida

Windows (PowerShell)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Començar

```bash
openamer              # Comencem a parlar.
openamer setup        # Configura les teves claus API & proveïdor
openamer model        # Sóc un traductor professional.
openamer update       # Actualitzar a la versió més recent
```

## Actualització

OpenAmer verifica actualitzacions automàticament i mostra una advertència al banner de benvinguda. Executa `openamer update` per obtenir la versió més recent — primer es fa una còpia de seguretat dels teus dades.
