# OpenAmer Agent

**தற்சகாப்தி மொடல் AI அகன்றான் — அனுபவத்திலிருந்து கற்க, திறமைகளை உருவாக்க, உங்கள் விருப்பங்களை நினைவில் வைத்துக் கொள்ளுங்கள் மற்றும் உங்களுக்கு எங்கும் உங்களுக்காக வேலை செய்க.**

எல்லாவரவு மொழிபெயர்ப்புக்கள் மட்டும்.

## வலைப்பாட்டுகள்

- **நிகழ்கால முகப்பரப்பு இடைமுகம் — முழுமையான TUI இடைமுகம் முடிவுக்குத் திரும்பும் பண்பு, வரலாறு மற்றும் ஓட்டம் செய்யும் கருவியின் வெளியீடு**
- **நீங்கள் இருக்கும் இடத்தில் — டெலிகிராம், டிஸ்கோர்ட், ஸ்லாக், வாட்ஸ்அப் போன்றவற்றை ஒரே கதவினால் இணைக்கலாம்.**
- **நேரடி கற்றல் — நினைவு, தன்னம்பிய திறமைகள், பதிப்புக்குறிப்பு நினைவாற்றல்**
- **நகர்த்துபவர்கள் & சாலைப்படுத்துகிறது — சாலைப்படுத்துக்கான துணைக் காரியங்கள் பலபடுத்தப்படுகின்றன**
- **தினசரி அறிக்கைகள், பாதுகாப்புகள், ஆதிக்கங்கள் ஆகியவற்றிற்கான உள்ளடக்கிய கிரான்**
- **ஏதாவது இடத்திலும் — உள்ளூர், Docker, SSH, நிலையான, சேவையில்லா**

## வேகவேகமாக நிறுவுதல்

வின்டோஸ் (பவர்ஷெல்)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

லினக்ஸ் / மேக் ஓஎஸ்
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## தொடக்கம்

```bash
openamer              # பேச ஆரம்பிக்க
openamer setup        # குறிப்பிட்ட API கியேசுகளையும் தரவரிசையாளரையும் அமைக்கவும்.
openamer model        # தேர்ந்தெடுக்கவும்
openamer update       # முதல் பதிப்பிலிருந்து இந்த பதிப்புக்கு பல மாற்றங்கள் செய்யப்பட்டுள்ளன. இந்த பதிப்பில் பின்வரும் முக்கிய மாற்றங்கள் உள்ளன:

*   **புதிய செயலிகள்**: இந்த பதிப்பில் புதிய செயலிகள் இருக்கின்றன, அவை பயனர் அனுபவத்தை மேம்படுத்துவதற்காக உருவாக்கப்பட்டுள்ளன.
*   **புதிய செயல்திறன்**: இந்த பதிப்பில் புதிய செயல்திறன் செயலிகள் இருக
```

## மாற்றம்

ஓப்பன்அமெர் அடியொற்றை பரிந்துரீதியாக நிகழ்வதும் வரவேற்பு பையரில் மெச்சம் காட்டுகிறது. ஓப்பன்அமெர் அப்டேட் செய்ய ஓப்பனமெர் அப்டேட் என்பதை நடத்துங்கள். அது முன்னரே உங்கள் தரவுகளை பாதுகாக்கிறது.
