# OpenAmer Agent

**ಸ್ವಯಂ-ಸುಧಾರಣೆಯ AI ಏಜೆಂಟ್ — ಅನುಭವದಿಂದ ಕಲಿಯುತ್ತದೆ, ಕೌಶಲಗಳನ್ನು ರೂಪಿಸುತ್ತದೆ, ನಿಮ್ಮ ಆದ್ಯತೆಗಳನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಎಲ್ಲೆಂದೂ ನಿಮಗಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.**

ನಿಮಗೆ ಬೇಕಾದ ಯಾವುದೇ ಮಾಡೆಲ್ ಅನ್ನು ಬಳಸಿ — OpenRouter, OpenAI, DeepSeek ಮತ್ತು ಇನ್ನೂ ಹಲವು. `openamer model` ಮೂಲಕ ಬದಲಾಯಿಸಿ — ಯಾವುದೇ ಕೋಡ್ ಬದಲಾವಣೆಗಳ ಅಗತ್ಯವಿಲ್ಲ.

## ವೈಶಿಷ್ಟ್ಯಗಳು

- **ನೈಜ ಟರ್ಮಿನಲ್ ಇಂಟರ್ಫೇಸ್ — ಆಟೋಕಂಪ್ಲೀಟ್, ಹಿಸ್ಟರಿ ಮತ್ತು ಸ್ಟ್ರೀಮಿಂಗ್ ಟೂಲ್ ಔಟ್‌ಪುಟ್ ಹೊಂದಿರುವ ಸಂಪೂರ್ಣ TUI**
- **ನೀವು ಇರುವಲ್ಲೇ ಲಭ್ಯ — Telegram, Discord, Slack, WhatsApp ಮತ್ತು ಇನ್ನೂ ಹೆಚ್ಚಿನವುಗಳು ಒಂದೇ ಗೇಟ್‌ವೇ ಮೂಲಕ.**
- **ಕಾಲಾನಂತರದಲ್ಲಿ ಕಲಿಯುತ್ತದೆ — ಸ್ಮರಣೆ, ಸ್ವಯಂ-ಸುಧಾರಣಾ ಕೌಶಲಗಳು, ಸೆಷನ್-ಗಳ ನಡುವಿನ ನೆನಪು (cross-session recall)**
- **ನಿಯುಕ್ತಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ಸಮಾನಾಂತರಗೊಳಿಸುತ್ತದೆ — ಸಮಾನಾಂತರ ಕೆಲಸಕ್ಕಾಗಿ ಉಪ-ಏಜೆಂಟ್‌ಗಳನ್ನು (subagents) ರಚಿಸುತ್ತದೆ**
- **ನಿಗದಿತ ಆಟೊಮೇಷನ್‌ಗಳು (Scheduled automations) — ದೈನಂದಿನ ವರದಿಗಳು, ಬ್ಯಾಕಪ್‌ಗಳು ಮತ್ತು ಆಡಿಟ್‌ಗಳಿಗಾಗಿ ಅಂತರ್ನಿರ್ಮಿತ ಕ್ರೋನ್ (built-in cron)**
- **ಎಲ್ಲೇ ಆಗಲಿ ರನ್ ಆಗುತ್ತದೆ — ಲೋಕಲ್, Docker, SSH, ಕ್ಲೌಡ್, ಸರ್ವರ್‌ಲೆಸ್**

## ತ್ವರಿತ ಸ್ಥಾಪನೆ (Quick Install)

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## ಪ್ರಾರಂಭಿಸುವುದು

```bash
openamer              # ಚಾಟ್ ಪ್ರಾರಂಭಿಸಿ
openamer setup        # ನಿಮ್ಮ API ಕೀಗಳು ಮತ್ತು ಪ್ರೊವೈಡರ್ ಅನ್ನು ಸೆಟ್ ಅಪ್ ಮಾಡಿ
openamer model        # ನಿಮ್ಮ ಮಾಡೆಲ್ ಅನ್ನು ಆರಿಸಿ
openamer update       # ಇತ್ತೀಚಿನ ಆವೃತ್ತಿಗೆ ಅಪ್‌ಡೇಟ್ ಮಾಡಿ
```

## ನವೀಕರಿಸಲಾಗುತ್ತಿದೆ

OpenAmer ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅಪ್‌ಡೇಟ್‌ಗಳಿಗಾಗಿ ಪರಿಶೀಲಿಸುತ್ತದೆ ಮತ್ತು ಸ್ವಾಗತ ಬ್ಯಾನರ್‌ನಲ್ಲಿ ಎಚ್ಚರಿಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. ಇತ್ತೀಚಿನ ಆವೃತ್ತಿಯನ್ನು ಪಡೆಯಲು `openamer update` ಅನ್ನು ರನ್ ಮಾಡಿ — ಇದು ಮೊದಲು ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಬ್ಯಾಕಪ್ ಮಾಡುತ್ತದೆ.

ಕೊಡುಗೆಗಳನ್ನು ಸ್ವಾಗತಿಸಲಾಗುತ್ತದೆ — ಓಪನ್ ಇಶ್ಯೂಗಳನ್ನು (open issues) ತಿಳಿಸಿ, ಪುಲ್ ರಿಕ್ವೆಸ್ಟ್‌ಗಳನ್ನು (pull requests) ಸಲ್ಲಿಸಿ ಅಥವಾ ಸಮುದಾಯವನ್ನು ಸೇರಿಕೊಳ್ಳಿ.
