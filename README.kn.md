# OpenAmer Agent

**ಸ್ವಯಂ ಸುಧಾರಿಸುವ ಎಚ್ಚರಿಕೆ ಕಂಪ್ಯೂಟರ್ ಅಗೆಂಟ್ — ಅನುಭವದಿಂದ ಕಲಿಯಿರಿ, ಕೌಶಲ್ಯಗಳನ್ನು ರಚಿಸಿ, ತಮ್ಮ ಪ್ರಿಯತೆಗಳನ್ನು ನೆನಪಿಸಿಕೊಳ್ಳಿ ಮತ್ತು ನಿಮಗಾಗಿ ಯಾವುದೇ ಸ್ಥಳದಲ್ಲಿ ಕೆಲಸ ಮಾಡಿ.**

ಕಾರ್ಯಾಚರಣೆಯನ್ನು ಪ್ರಾರಂಭಿಸಲು ನಾನು ಯಾವುದೇ ಮಾದರಿಯನ್ನು ಬಳಸಬಹುದು — OpenRouter, OpenAI, DeepSeek, ಮತ್ತು ಹೆಚ್ಚು. ಮಾದರಿಯನ್ನು ಬದಲಾಯಿಸಲು `openamer model` ಅನ್ನು ಬಳಸಿ.

## ಅಂಶಗಳು

- **ಅಸಲಿನ ಟರ್ಮಿನಲ್ ಇಂಟರ್ಫೇಸ್ — ಸಂಪೂರ್ಣ ಟಿಯುಐ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವಾ ಟರ್ಮಿನಲ್ ಯುಜಿಟಿ ಅಥವ**
- **ನೆಲೆಯಲ್ಲಿ ನೀವು ಇರುವ ಮಾತ್ರದಲ್ಲಿ — Telegram, Discord, Slack, WhatsApp ಮತ್ತು ಹೆಚ್ಚು ಇತರ ಗೇಟ್‌ವೇ ಇಂದ**
- **ಕಲಿಯುತ್ತಾನೆ — ಸ್ಮರಣೆ, ಸ್ವಯಂ-ಉತ್ತೇಜನೆ ಕೌಶಲ್ಯಗಳು, ದಿನಾಂತರ ಸ್ಮರಣೆ**
- **ನಿಯೋಜಿತರು ಮತ್ತು ಪರಾಲೆಲ್ ಆಗಿ — ಪರಾಲೆಲ್ ಕಾರ್ಯಕ್ಕಾಗಿ ಸಬ್ ಏಜೆಂಟ್ಗಳನ್ನು ಸ್ಪೌನ್ ಮಾಡಿ**
- **ನಿರ್ದಿಷ್ಟ ಆಟೋಮೇಷನ್ಗಳು — ದೈನಂದಿನ ನಿವೇದನೆಗಳು, ಬ್ಯಾಕ್ಯೂಪ್ಸ್, ಅಡ್ಯೂಟ್ಸ್**
- **ಯಾವುದೇ ಇಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ — ಸ್ಥಳೀಯ, Docker, SSH, ಗಾಳಿಯಲ್ಲಿ, ಸೇವಾಂತರ**

## ವೇಗವಾಗಿ ಸ್ಥಾಪಿಸಿ

ವಿಂಡೋಸ್ (ಪವರ್‌ಷೆಲ್)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

ಲಿನಕ್ಸ್ / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## ಪ್ರಾರಂಭಿಸಲು

```bash
openamer              # ಮಾತನಾಡಿ
openamer setup        # ಅಪ್ಲಿಕೇಷನ್‌ನಲ್ಲಿ ತಮ್ಮ API ಗುರಿಗಳು ಮತ್ತು ಸೇವಾ ನಿರ್ವಾಹಕರನ್ನು ಸೆಟ್ ಮಾಡಿ
openamer model        # ನಿಮ್ಮ ಮಾದರಿಯನ್ನು ಆಯ್ಕ್ಕಿಸಿ
openamer update       # ಅಪ್‌ಡೇಟ್ ಮುಂದಿನ ಆವೃತ್ತಿಗೆ
```

## ಸಂಪಾದನೆ

ಓಪನ್‌ಅಮೇರ್ ತನ್ನದೇ ಆಪತ್ತ ನವ್ರ್ಟ್ಸ್ ಕ್ಯಾಚ್ ಮಾಡುತ್ತದೆ ಮತ್ತು ಸ್ವಾಗತ ಬ್ಯಾನರ್‌ನಲ್ಲಿ ಸಾಕ್ಷ್ಯವನ್ನು ತೋರಿಸುತ್ತದೆ. ಆಪನ್‌ಅಮೇರ್ ನವ್ರ್ಟ್ ಪಡೆಯಲು ನಿಮ್ಮ ಡೇಟಾ ಮೊದಲಿಗೆ ಬ್ಯಾಕ್ ಅಪ್ ಮಾಡಿಸುತ್ತದೆ ಎಂದು ತಿಳಿಸಿಕೊಳ್ಳಿ.

## ಪ್ರದಾನ ಮಾಡುವಿಕೆ

ಸಹಕಾರವನ್ನು ಸ್ವೀಕರಿಸಲಾಗುತ್ತದೆ — ತೆರೆದ ಸಮಸ್ಯೆಗಳು, ಪುಲ್‌ಲ್ ಅನ್ನು ಸಲ್ಲಿಸಿ, ಸಮುದಾಯಕ್ಕೆ ಸೇರಿ.
