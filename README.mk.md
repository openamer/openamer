## Функции

- **Реален терминален интерфејс — целосна ТУИ со автокомплетирање, историја и стриминг на излез од инструментите.**
- **Живеејќи каде што живеееш — Telegram, Discord, Slack, WhatsApp и повеќе од еден врат.**
- **Учи со време — сеќавање, самосовршувачки вештина, споменица преку сесиите**
- **Делегати и паралелизира — создава подагенти за паралелно работување**
- **Аутоматизирани програми — интегриран крон за дневни извешаја, резервни копии, ревизии**
- **Работи на секое место — локално, Docker, SSH, во облакот, без сервер.**

## Брзо Усетство

```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Почеток

```bash
openamer              # Начни да разговарам
openamer setup        # Сетувајте ги вашите API-кејс и пружители
openamer model        # Изберете модел
openamer update       # Ажурирајте до најновата верзија.
```

## Ажурирање

OpenAmer автоматски проверува за апдати и ги покажува во барањето за добредојде. Изврши го openamer update за да добиеш најновата верзија — претходно се копираат податоците.
