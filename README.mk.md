# OpenAmer Agent

**Самосо подобрувачкиот AI агент — учи од искуството, создава вештини, ги памти вашите преференции и работи за вас одбиседе.**

Користете го секој модел што го сакате — OpenRouter, OpenAI, DeepSeek и повеќе. Префрлете се со `openamer model` — без промени во кодот.

## Карактеристики

- **Вистински терминалски интерфејс — целосен TUI со автопополнување, историја и стримирање на излезот од алатките**
- **Живее таму каде што и вие — Telegram, Discord, Slack, WhatsApp и многу други од еден gateway**
- **Учи со текот на времето — меморија, вештини за самоподобрување, припоменување меѓу сесиите**
- **Делегира и паралелизира — создава под-агенти за паралелна работа**
- **Закажани автоматизации — вграден cron за дневни извештаи, резервни копии, ревизии**
- **Работи било каде — локално, Docker, SSH, cloud, serverless**

## Брза инсталација

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Започнување

```bash
openamer              # Започни разговор
openamer setup        # Поставете ги вашите API клучеви и провајдер
openamer model        # Изберете го вашиот модел
openamer update       # Ажурирајте ја до најновата верзија
```

## Ажурирање

OpenAmer автоматски проверува за ажурирања и прикажува предупредување во банерот за добредојде. Извршете ја командата `openamer update` за да ја добиете најновата верзија — таа прво ќе ги направи резервни копии на вашите податоци.
