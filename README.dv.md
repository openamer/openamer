# OpenAmer Agent

**ތަަމަދު އ ramachވަރުގައި ކުރިއެރުމް ހޯރުވާ AI އެޖެންޓް — ތަޖުރިބާއިން သင်ယူކޮށް، ހުނަރުތައްສ້າງކޮށް، თქვენގެ விருப்பތައް ನೆನަކޮށް، އަދި ඕނෑම ތަނެއްမှ თქვენ වෙනුවෙන් މަސައްކަތް ކުރާނެ.**

ތިބާ ބޭނުންވާ އެންމެ ރަނގަޅު މޮޑެލް ހިង់ގާލާ — OpenRouter, OpenAI, DeepSeek އަދި އެހެން މޮޑެލްތައް. ކޯޑުގައި އެއްވެސް ބަދަލެއް ނު এনেރުމާ `openamer model` އާލާ ފަހިކުރާށެވެ.

## ޚާއްޞަ ސިފަތައް

- **ހަގީގީ ޓާމިނަލް އިންޓަފޭސް — އ އޯޓޯކޮމޕްލީޓް، ހިސްޓްރީ އަދި ސްޓްރީމިންގ ޓޫލް އައުޓްޕުޓްలతో އެކު ފުރިހަމަ TUI އެކެވެ.**
- **ތިޔަބޭނުންކުރާ ތަންތަނުން ހިԶަމްވާނެ — Telegram, Discord, Slack, WhatsApp އަދި އެހެން އެކިGetServiceތައް އެކި gateway އެކަކުން**
- **ވަގުތު and ވަގުތަށް އުނގެނޭ — މެމަރީ (memory)، އަމިއްލައަށް మెరుగుކުރެވޭ ހުނަރުތައް، އަދި ސެޝަންތަކާ ހުރިހުރި ހަނދާކުރުން**
- **ބަހަވައިލައި parallelize ކުރެއެވެ — އެކަހައި ވަގުތު މަސައްކަތްތައް ކުރިއަށް götަލަނިކޮށް ސަބް-އޭޖަންޓުން އުފ បង្កើតނެއެވެ**
- **ޝެޑިއުލްކޮށްފައިވާ އޮޓޯމޭޝަންތައް — ދުވަހުން ދުވަހަށް ފޮނުވާ ރިޕޯޓްތަކަށް، ބެކަޕްތަކަށް އަދި އޯޑިޓްތަކަށް ބޭނުންކުރެވޭ ބިލްޓް-އިން ކްރޯން (cron) ސިސްޓަމް**
- **ඕނෑම ތަނެއްގައި ހިނގާނެ — ލޯކަލް، Docker، SSH، ކްލައުޑް، ސާވަލެސް**

## দ্রুত އިންސްޓޯލްކުރުން

ވިންޑޯޒް (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

ލިނަކްސް / މެކް އޯއެސް:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## ފެށުން

```bash
openamer              # ޗެޓްކުރުމަށް ފެށޭ
openamer setup        # ਤੁਹਾਡੀ API ކީޒް އަ ਤੇ ਪ੍ਰޮވައިਡަރ સੈޓް އަޕް ކުރޭ
openamer model        # މޮޑެލް ఎކުލަހު ކުރޭ
openamer update       # ލേറ്റެސްޓް ቨერსަންއަށް އަޕްޑޭޓް ކުރޭ
```

## އັບޑޭޓްކުރަމެވެ

OpenAmer އިން އូតޯމެޓިކކޮށް އަޕްޑޭޓްތައް andޗެކްކޮށް، ވެލްކަމް ބެނަރީގައި ማስጠንبيهmarshalNަމެއް ދައްކަވާނެއެވެ. އެން nieuwަސްޓް ቨର୍ޝަން ހޯދުމަށް openamer update ރަން ކުރައްވާށެވެ — އެއިރުން އެންމެ ފުރst ތަފާސްމަޢުލޫމާތު ބެކަޕް ކުރާނެއެވެ.

## ބައިވެރުވުން

އިލާހިރާމްތައް މަރުހަބާ ކުރެއެވެ — އޯޕަން އިޝޫސް (open issues) ހިއްސާކުރޭ، ޕުލް ރިކުވެސްޓްސް (pull requests) ސަބްމިޓް ކުރޭ، ނުވަތަ ކޮމިއުނިޓީއަށް ގިނިގަނިވަމެވެ.
