# OpenAmer Agent

**ދިވެހިންގެ އާރިއަމްގެ ދައުސަރު - އުރުރަތުގައި ދެއްވަމަށް، ކުރިންގަންގެ ދައުސަރުކޮށް، އަމިނުގައި ދެއްވަމަށް، އައިސްފަރުގެ ދައުސަރުކޮށް، އައިސްފަރުގައި ދެއްވަމަށް.**

އައިލެކުންގެ ދިދައަކީ އައިލެކުންގެ ދައުވާތުގައި އައިލެކުންގެ ތެރަވެލައިގެ ފުރާވަސްތައް ދެއްވާ އައިލެކުންގެ ދިދައަކީ އައިލެކުންގެ ދައުވާތުގައި އައިލެކުންގެ ތެރަވެލައިގެ ފުރާވަސްތައް ދެއްވާ އައިލެކުންގެ ދިދައަކ

## ޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕްޕް

- **އިންސާނީ މައުލޫމުގެ ވައިގެ ވައިރަތެއް — އެންވެއްޖެހޭ TUI އާއިލާތަކާއި ވައިރަތުގެ ވައިރަތެއްގައި ވައިރަތުގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވައިރަތެއްގެ ވަ**
- **އައިލެކުންނާ އައިލެކުންނާ ފިލާވެލެވެ: މެޓްނިއަން, އައިލެކްސް, ސައްވަރސް, މާންޑަސް ނިޒާސްވެލެވެ.**
- **އައިލާމަތް ވަންދެން — ކުރިންތާން, އަރުގަޅުގެ ބަދަލުތައް, އަދާރަތުގެ ނުވަތުގެ ބަދަލުތައް**
- **ދިވެހި: ފުންވާންތައް އައުން އަދި ދައުރުވެހިން ކުރުމު**
- ****Kureyaa kaa kureyaa** — built-in cron for daily reports, backups, audits**
- **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައަކީ **އަންމާފުނައ**

## ޕައިމަން ނަންބައްދީން

ދިވެހި
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## ހަދާލައި ވާޖިލް

```bash
openamer              # ހަދާންވުން
openamer setup        # އާއިޒްތަންދެއްވާން **API ތަންތަންދެއްވާން އަދިއެވެސް** އަދިވެސް އަރުވާން
openamer model        # **އަންގަރުންގެ ފަރުބަލައިދެވެސް އަމާމީއަކީ އަންގަރުންގެ ފަރުބަލައިދެވުމުން އެންޖުރުޏަބައިއަކީ އަންގަރުންގެ ފަރުބަލައިދެވުމުގައި އަންގަރުންގެ ފަރުބަލައިދެވުމުން އަންގަރުންގެ ފަރުބަލައިދެވުމުގައި އަންގަރުންގެ ފ
openamer update       # ދައުރާމާއިން
```

## އަންހެވިސްޓްރިއްޕަންރިއްޕަން

OpenAmer **އިންހެންސްތަންގެންވާ** އަދިއްސަރަކުން އެންންތަންގެންވާ އަޅައިވަންދޭނެއިރު އެންންތަންގެންވާ އަޅައިވަންދޭން **openamer update** އިންހެންތަންގެންވާ އަދިއްސަރަކުން އެންންތަންގެންވާ އަޅައިވަންދޭން.
