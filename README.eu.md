## Ezaugarriak

- **Interfaze terminala — TUI osoa, autocompletatzea, historia eta emanketa itzultzailearen iragartzeko errekurtsoa.**
- **Eguneroko lekuan bizi denez — Telegram, Discord, Slack, WhatsApp eta gehiago batu gune batean**
- **Ikaskuntza denbora arikoa — memoria, gaitasunak hobetzeko, sesioen arteko oroimen**
- **Delegatuak eta paraleloa — subagentak paralelo lanerako sortzen**
- **Automazio erregularak — egutegi propioa eguneroko erreportajeak, erregezketa eta audituetarako**
- **Estatu guztietan funtzionatzen du — lokal, Docker, SSH, zulotzatua, serverless**

## Erabaki Azkarra

Windows (Powershell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Hasiera

```bash
openamer              # Egun on! (Hello!)
openamer setup        # Konfiguratu zure API gakoak eta zerbitzariak.
openamer model        # Aukeratu zure modeloa.
openamer update       # Eguneratu berritzailea azken bertsioan.
```

## Berrikusi ditzazu.

OpenAmer automatikoki berrikusketa egiten du eta ohartapena iragarki barnean erakusten du. Openamer berrikus berria lortzeko, openamer update komandoa exekutatu, eta datuak lehen aurreratzen ditu.
