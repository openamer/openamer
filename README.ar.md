# OpenAmer Agent

**الAGENT الذاتي المطور - تعلم من الخبرة، وإنشاء مهارات، وتذكر تفضيلاتك، ويعمل لك في أي مكان.**

**ترجمة** إلى العربية:

استخدم أي نموذج تريد - OpenRouter، OpenAI، DeepSeek، وما إلى ذلك. استبدل ب `openamer model` - لا تغير أي رمز.

## المميزات

- **واجهة النهاية الحقيقية — واجهة GUI تامة مع تكميل تلقائي، تاريخ، و输出 أداة بالتتابع**
- **حياتك في مكان واحد — تليجرام، ديسكورد، سلاك، واتساب وغيرها من المنافذ من خلال بوابة واحدة**
- **يتعلم عبر الزمن — الذاكرة، المهارات الذاتية للتطوير، التذكير بين الجلسات**
- **الممثلون و المتوازين - يولدان الوكلاء الفرعيون للعمل المتوازن**
- **التimers المجدولة — cron بنصي المعمول مع تقارير يومية، نسخة احتياطية، استعراضات**
- **يعمل في أي مكان — محلي، Docker، SSH، السحاب، بدون服务器.**

## إصدار سريع

الوينز (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

مايكروسوفت ويندوز / ماك أو إس:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## بدء العمل

```bash
openamer              # حسناً! كيف يمكنني مساعدتك؟
openamer setup        # **إعداد مفاتيح API & المزود**

إذا كنت ترغب في استخدام API الخاصة بنا، يجب عليك إعداد مفاتيح API أولاً. يمكنك الحصول على مفاتيح API من خلال تطبيق [أدخل](https://dashboard.cloud.google.com) أو من خلال [صفحة إعدادات API](https://console.cloud.google.com/apis/dashboard).

**خطوات إعداد مفاتيح API:**

1. **انقر على** [تطبيق أدخل](https://console.cloud.google.com) **وادخل إلى تطبيق Google Cloud**.
2. **اختر** **مخططات** من القائمة الجانبية.
3. **انقر على** **إضافة مشروع**.
4. **ادخل** اسم المشروع.
5. **انقر على** **إضافة حساب**.
6. **اختر** **مفتاح API**.
7. **اختر** **مفتاح API** الذي ترغب في استخدامة.
8. **انقر على** **إضافة مفتاح**.
9. **حصل على** مفتاح API الخاص بك.

**إعداد مزود API:**

1. **اختر** **مزود API** الذي ترغب في استخدامة.
2. **ادخل** معلوماتك الشخصية.
3. **انقر على** **تأكيد**.

**إعداد مفاتيح API:**

1. **انقر على** **مفاتيح API**.
2. **اختر** **مفتاح API** الذي ترغب في استخدامة.
3. **انقر على** **إضافة مفتاح**.
4. **حصل على** مفتاح API الخاص بك.

**استخدام مفاتيح API:**

1. **انقر على** **مفاتيح API**.
2. **اختر
openamer model        # اختر نموذجك
openamer update       # تحديث إلى الإصدار الأحدث
```

## تحديث

تتجدد OpenAmer تلقائياً وتظهر تحذير في لوحة الاستقبال. يُرجع تشغيل openamer update إلى الإصدار الأحدث — ينسخ البيانات قبل ذلك.
