# OpenAmer Agent

**وكيل الذكاء الاصطناعي القابل للتحسين الذاتي - يتعلم من التجارب، ويطور المهارات، ويتذكر تفضيلاتك، ويعمل من أجلك في أي مكان.**

استخدم أي نموذج تريده — OpenRouter، OpenAI، DeepSeek، والمزيد. قم بالتبديل باستخدام `openamer model` — دون الحاجة لتغييرات في الكود.

## ميزات

- **واجهة طرفية حقيقية — واجهة مستخدم نصية كاملة مع الإكمال التلقائي، والتاريخ، وإخراج أدوات البث**
- **يعيش حيث تعيش — تيليجرام، ديسكورد، سلاك، واتساب والمزيد من بوابة واحدة**
- **يتعلم مع مرور الوقت — الذاكرة، المهارات الذاتية التحسين، استرجاع المعلومات عبر الجلسات**
- **يفوض ويوازي — يطلق وكلاء فرعيين للعمل المتوازي**
- **الأتمتة المجدولة — كرون مدمج للتقارير اليومية، النسخ الاحتياطية، التدقيقات**
- **يعمل في أي مكان — محلي، Docker، SSH، سحابي، بدون خادم**

## التثبيت السريع

ويندوز (باور شيل):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

لينكس / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## البدء

```bash
openamer              # ابدأ الدردشة
openamer setup        # قم بإعداد مفاتيح API ومزود الخدمة الخاصة بك
openamer model        # اختر نموذجك
openamer update       # قم بتحديث إلى أحدث إصدار
```

## تحديث

يفحص OpenAmer التحديثات تلقائيًا ويظهر تحذيرًا في لافتة الترحيب. قم بتشغيل openamer update للحصول على أحدث إصدار - حيث يقوم بعمل نسخة احتياطية من بياناتك أولاً.
