# OpenAmer Agent

**Sumañatakipacha AI agentu — jach’añataki yatiqasi, yatiñanakapxat jach’añapa, juma munasiñanakapxat amtañapa, ukat jumanpajxa khatisinxa irnaqañapa.**

Kama nayra model kunataki munta — OpenRouter, OpenAI, DeepSeek, ukatwa wanti. `openamer model` uka qalluwan phawaliñäxi — jach'a k'utunaka (code) nayra qalluwanakaw qamañäni.

## Yatiyäwinaka

- **K'umsiñataki terminal interface — jach'a TUI autocomplete, history, ukatwa streaming tool output yanapawinakampi**
- **Jukampiw utjïwi — Telegram, Discord, Slack, WhatsApp ukatxa mayniwnakaw, mayni gatewaynaka ukanaka**
- **T'aqatpachaxa yatiqapxi — munachawi, jach'atäwi yatiyawi, qhawqha pachatxa amuyunaka.**
- **Delegaduki uka ukhamaru parallelizaki — parallel irnaqäwi uka ukhamaru subagentunaka uñt'ayaki**
- ****Amtawiyäta automatizacionis** — built-in cron uru-uru reportukut, backupukut, auditukut**
- **Kuna thakhinaki runakuna — local, Docker, SSH, cloud, serverless**

## Jaki Ch'amampi Altuqawi

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Qalltawi

```bash
openamer              # Qallayapxañani yatiqawi/parlaniwi
openamer setup        # API kllawinakasa (keys) ukat provider-asa amuyt’añani
openamer model        # Jach'añani modelayaxa
openamer update       # Juk’amp juk’amp nayra versionru mayachaña
```
