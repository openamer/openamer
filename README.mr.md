## वेगवेगळ्या प्रक्रियांमध्ये **Quick Install**

विंडोज (पॉवरशेल)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

लिनक्स / मॅकओएस
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## प्रारंभ करण्यासाठी

```bash
openamer              # श्रृंगार सुरू करा
openamer setup        # API कुंडके सेट करा आणि प्रदाता
openamer model        # तुमच्या मॉडेलची निवड करा
openamer update       # नवीनतम आवृत्ती वर्धापन
```

## नवीनीकरण

OpenAmer **अतिरिक्त** अद्यतनांसाठी स्वतःची पाहणी करत आहे आणि स्वागतसंदेशाच्या पट्ट्यात चेतावणी दाखवते. openamer update चा वापर करा जेणेकरून तुमच्या सर्वात नवीन आवृत्तीचा फायदा घ्याल.
