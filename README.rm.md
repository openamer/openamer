# OpenAmer Agent

**L'agent d'IA che s'amplora automaticament — impara da l'experienza, crea abilitads, remembers tgeis preferenzas e travalgia per te ovunque.**

Usa quai model che ti vuls — OpenRouter, OpenAI, DeepSeek, e pli ancora. Cambia cun `openamer model` — senza chaschun changiament da codi.

## Caratteristicas

- **Interfaccia da terminal real — TUI completa cun autocomplete, history e streaming da l'output da l'instrument**
- **Vivat uff l'endroit nua vus ei — Telegram, Discord, Slack, WhatsApp e pli anc via in unic gateway**
- **Apprende cun il temp — memoria, abilitads che s'improvran, rappell tra sessiuns**
- **Delegat e parallelisira — creascha subagents per lavur parallela**
- **Automaziuns programmas — cron integrà per rapports quotidians, backups, audits**
- **Curra ovunque — local, Docker, SSH, cloud, serverless**

## Installaziun rapida

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Cumenzar

```bash
openamer              # Cumenzia a chattar
openamer setup        # Configura tgias chlavs API e ti provider
openamer model        # Sceglia vossa model
openamer update       # Actualisà a la ultima versiun
```

## Actualisaziun

OpenAmer tschert automaticamain per updates e mostra ina avertisa in l'banner da benvegni. Ejecuta `openamer update` per recuntrar la nova versa — el fa prim ina backup da tiesas datas.
