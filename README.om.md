# OpenAmer Agent

**Ejentii AI of-fooyyessu — muuxannoo irraa barata, dandeettii uuma, filannoowwan kee yaadata, akkasumas bakka hundaa siif hojjeta.**

Moodeela kamiyyuu barbaaddu fayyadami — OpenRouter, OpenAI, DeepSeek, fi kanneen biroo. `openamer model` fayyadamtee jijjiiri — jijjiirama koodii hin barbaachisu.

## Amaloota

- **Interface terminal dhugaa — TUI guutuu kan autocomplete, seenaa (history), fi output meeshaalee streaming qabu**
- **Bakka ati jirtutti jira — Telegram, Discord, Slack, WhatsApp fi kanneen biroo hunda karaa tokkoon (gateway) fayyadami**
- **Yeroo darbuun barata — yaadannoo, dandeettii of-fooyyessu, yaadannoo seeshinoota adda addaa gidduu**
- **Hirmaattota qooda — hojii wal-faanaa (parallel) hojjetaniif hojjettoota (subagents) uuma**
- **Otomeeshiniiwwan sagantaa qaban — cron dabalataa gabaasoota guyyootaa, bakka-ka'iinsa (backups), fi sakatta'iifaa (audits) ijaaramu**
- **Bakka hunda irratti hojjeta — local, Docker, SSH, cloud, serverless**

## Hojirra Oolchuu Ariifaa

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Eegaluu

```bash
openamer              # Haasa'uu jalqabi
openamer setup        # Kiiyoota API fi dizaayinii (provider) kee qopheessi
openamer model        # Moodela kee filadhu
openamer update       # Gara versioniidha dhumbaa (haaraa) update godhi
```

## Harooguu

OpenAmer automatic-n update-oota ni sakatta'a, akkasumas beeksisa beekamtii (welcome banner) irratti akeekkachaa agarsiisa. Version haaraa argachuuf `openamer update` hojjedha — kun duraan dura ragaalee kee (data) backup godha.
