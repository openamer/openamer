## **Kuñaichvyry** (Getting started) **.**

```bash
openamer              # **Pukukuei**.
openamer setup        # **Configura tus claves de API & proveedor**

1. **Accede a la plataforma de tu proveedor de API** (e.g. [Twilio](https://www.twilio.com/), [Nexmo](https://www.nexmo.com/), etc.)
2. **Obtén tus claves de API** (e.g. **Account SID**, **Auth Token**, etc.)
3. **Configura tus claves de API en tu aplicación** (e.g. mediante un archivo de configuración, una variable de entorno, etc.)

**Nota:** Asegúrate de que tus claves de API estén seguras y no se compartan con nadie.
openamer model        # **Modelo de traducción**

**Avañe'ẽ** (también conocido como **Guarani** ) es una lengua nativa de Sudamérica, hablada principalmente en Paraguay y también en Argentina, Brasil y Bolivia.
openamer update       # **Kuéraite ojehechahá ojehechauka.** (Update to the latest version)
```
