# OpenAmer Agent

**Pehecha pe AI agentéva oñembo'e hikuái — ajuhúke tembi'u ñe'ẽndégui, ambo'e hékue tekotevẽ opaite mba'e, aikuaa pe reipyrũva ha amba'apo ndéve g̃uarã opaite hendápe.**

Eipota pe modelo opaite — OpenRouter, OpenAI, DeepSeek, ha ambue. Embozeve'ã `openamer model` ndaje — nderekoいva'erã peteĩ mba'e oñemoambue haguã pe kódigope.

## Tembiekuéra

- **Interface terminal tee — TUI complete autocomplete-ndive, history-ndive, ha tool output streaming-ndive**
- **Oiko upépe reiko haguã — Telegram, Discord, Slack, WhatsApp ha ambueve peteĩi gateway-gui**
- **Apyta ñandereko ñe'ẽ — memoria, ñe'ẽha'e ñandereko ñe'ẽ, ñe'ẽha'e ñandereko ñe'ẽ opaite rupi**
- **Omohenda ha omoambue — omoheka ha'e ñembo'eha'ã (subagents) oñembosako'i hag̃ua tembiapo**
- **Automaciones programadas — cron integrados para reportes diarios, backups ha auditorías**
- **Oñembo'e opaite hendápe — local, Docker, SSH, cloud, serverless**

## Kuaa'ãmbyrypy

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Ñepyrũmíme

```bash
openamer              # Añepyrãse ñañe'ẽ
openamer setup        # Emboguepýta ne API keys ha ne providór
openamer model        # Eiporã ne modelokuéra
openamer update       # Mbo'e ko'ápe pe tembi'u oñemboheréva pe mbyvota ikatúva opa

(Or more simply: **Moambiguáke pe mbyvota oñemboheréva**)
```

## Moambueha

OpenAmer ohecha automatically updates ha ome'ẽ petẽi avisa welcome banner-pe. Emoĩ `openamer update` ikatu hag̃ua rehecha pe versión latest — upéva ñembyaty mboyve omoĩ ne dato-kuéra backup-pe.
