# OpenAmer Agent

**Wakiilka AI-ga is-horumarinta — wax ka baro khibradda, abuuro xirfado, xusuuso doorashooyinkaaga, oo kuu shaqee meel kasta.**

Isticmaal moodal kasta oo aad rabto — OpenRouter, OpenAI, DeepSeek, iyo kuwo kale. Ku beddel `openamer model` — wax beddel xagga koodhka ah looma baahna.

## Astaamaha

- **Interface-ka rasmiga ah ee terminal-ka — TUI dhammaystiran oo leh autocomplete, taariikhda (history), iyo soo saarista qalabka oo ah qaab streaming ah**
- **Ku nooloow halka aad joogto — Telegram, Discord, Slack, WhatsApp iyo kuwo kaleba oo dhammaantood hal marin ah**
- **Wuxuu wax bartaa muddo dheer — xusuus, xirfado is-horumarinaya, iyo xusuusta kulammada kala duwan**
- **Wakiilaynaa & barbar-socodsiyaa — abuuraa wakiillo-hoosaadyo shaqooyinka barbar-socodka ah**
- **Otomaatigyada qorshaysan — cron-ka gudaha ugu jira ee warbixinnada maalinlaha ah, kaydinta (backups), iyo hantidhowrka (audits)**
- **Wuxuu ku shaqeeyaa meel kasta — local, Docker, SSH, cloud, serverless**

## Rakibaad Degdeg ah

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Sida loo bilaabo

```bash
openamer              # Bilow sheekada
openamer setup        # Habay your furayaasha API-ga & bixiyaha (provider)
openamer model        # Dooro moodalkaaga
openamer update       # Ku cusboonaysii nooca ugu dambeeyay
```

## Kusoo cusboonaysiin

OpenAmer si otomaatik ah ayay u hubisaa cusboonaysiimaha, waxayna digniin ku soo bandhigtaa banner-ka soo dhawaynta. Ku qor `openamer update` si aad u hesho noocii ugu dambeeyay — waxay marka hore kaydinaysaa (back up) xogtaada.
