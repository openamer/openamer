## **Dhanka Weeraraga**

**Installation**

1. **Ku qabsoo qaatay**: Download the latest version of the software from the official website.
2. **Dhanka weerar**: Run the installer and follow the instructions.
3. **Ku qabsoo qaatay**: Install the software on your computer.
4. **Dhanka weerar**: Launch the software and start using it.

**Ku qabsoo qaatay**: If you encounter any issues during installation, refer to the troubleshooting guide.

**Dhanka weerar**: For more information, visit the official website.

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Muuqaalka Awooda

```bash
openamer              # Ku xigasho, waxaad aad u baahantahay?
openamer setup        # **API Key Setup**

Waxbarashada API Keys & Provider

1. **API Key**: Waxbarashada API Key waa xidhiidhka muujinaha API ee xidhiidhkaaga.
2. **Provider**: Provider waa shirkadda ka tageera API Key.
3. **API Key Setup**: Waxbarashada API Key waa hawlaha u dhex maraynayo API Key iyo provider.

**API Key Setup Steps**

1. **Ku dhiho API Key**: Ku dhiho API Key ee shirkadda API provider.
2. **Ku dhiho Provider**: Ku dhiho provider ee shirkadda API.
3. **Ku dhiho API Key**: Ku dhiho API Key ee shirkadda API.

**API Key Setup Commands**

* `curl -X POST -H "Authorization: Bearer YOUR_API_KEY" https://api.example.com/endpoint`
* `curl -X GET -H "Authorization: Bearer YOUR_API_KEY" https://api.example.com/endpoint`

**API Key Setup URLs**

* `https://api.example.com/endpoint?api_key=YOUR_API_KEY`
* `https://api.example.com/endpoint?api_key=YOUR_API_KEY&param=value`
openamer model        # **Fadlan faa'iido karto model aad ugu magacaabay.**
openamer update       # **Kuugugalee ilaaliyaasha**
```

## **Kuugojinta**

OpenAmer yaa ka dhigaysa xidhiidhka xilligii dhaameynta iyo warqadda welwelka. Run openamer update inaad ka dhigaysid xilliga ugu danbeeya — wuxuu ku dhaamey xubin dhaameyntaaga.
