**Agènt AI sing ngandhulang — ngerti saking pengalaman, kawruh nyawèh, ingat prèferènsi, lan ngabdahi kéné nganti wong.**

## **Sifat**

- **Terminal asli — TUI purna dengan autocomplete, sejarah, lanjutan alat keluaran**
- **Wiwit sapa wong wong iki — Telegram, Discord, Slack, WhatsApp lan liyane saka siji pintu gerbang**
- **Kuwantuné wus-wus — ingkung, kasilé wiyos, ingkung sesi ingkang énggal**
- **Panggon **Delegates & parallelizes** — **spawn** **subagents** **saka** **nggih** **kerja** **paralel****
- **Kronologis otomatis — kron untuk laporan harian, cadangan, audit**
- **Kasilanap soko — soko, Docker, SSH, wengkon, tanpa wong**

## Panganggo Cepet

**Windows (PowerShell)**
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Lanang / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Miyosan

```bash
openamer              # Nggih! Sori, apa kabar?
openamer setup        # Ngaturaken kunci API lan provider
openamer model        # Pilih modelmu
openamer update       # **Pindhah dadi wong paling anyar**
```

## **Menggantikan**

Sokolahe OpenAmer ngisoraken update otomatis lan ngisoraken ingkang panggih ing banner sambutan. Tambah OpenAmer update supaya wis ana versi paling anyepun — iki ngisoraken data pisanan.
