# OpenAmer Agent

**Agen AI sing bisa ningkatake awake dhewe — sinau saka pengalaman, nggawe katrampilan, eling marang preferensi sampeyan, lan kerja kanggo sampeyan ing ngendi wae.**

Gunakake model apa wae sing sampeyan karepake — OpenRouter, OpenAI, DeepSeek, lan liya-liyané. Ganti nganggo `openamer model` — tanpa owah-owahan kode.

## Fitur-fitur

- **Antarmuka terminal nyata — TUI lengkap kanthi autocomplete, riwayat, lan output alat streaming**
- **Urip ing ngendi sampeyan — Telegram, Discord, Slack, WhatsApp lan liya-liyane saka siji gerbang**
- **Sinau sajrone wektu — memori, keterampilan mandiri sing saya apik, pangeling-eling lintas sesi**
- **Delegasi & paralel — ngasilake subagen kanggo kerja paralel**
- **Automasi terjadwal — cron bawaan kanggo laporan saben dina, cadangan, audit**
- **Mlaku ing ngendi wae — lokal, Docker, SSH, awan, tanpa server**

## Instalasi Cepat

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Miwiti

```bash
openamer              # Miwiti obrolan
openamer setup        # Atur kunci API lan penyedia sampeyan
openamer model        # Pilih model sampeyan
openamer update       # Nganyari menyang versi paling anyar
```

## Nganyari

OpenAmer mriksa pembaruan kanthi otomatis lan nuduhake peringatan ing spanduk sambutan. Jalankan openamer update kanggo entuk versi paling anyar — iki nyimpen data sampeyan dhisik.
