# OpenAmer Agent

**Özünü yaxşılaşdırma qabiliyyəti olan AI agent — təcrübədən öyrən, bacarıqlar yaradın, istəklərinizi xatırlayın və sizə hər yerdə çalışın.**

**Azerbaijanca (Azərbaycanca) tərcüməsi**

**Mənbə:** [https://github.com/](https://github.com/)

**Tərcümə:** [https://github.com/](https://github.com/)

**GitHub** - açıq mənbə kontrol sistemi, kompüter proqramları və istifadəçilərin işləmələri üçün bir nəqliyyat vasitəsidir. GitHub, Microsoft tərəfindən 2018-ci ildə alınmışdır.

## Xüsusiyyətlər

- ****Real terminal interfeysi — tam TUI ilə avtomat tamamlama, tarix və axan alət çıxışları****
- **Sən nə yerində yaşayırsan, Telegram, Discord, Slack və daha çoxu bir qovşaqdan.**
- **Zamana görə öyrənir — xatirə, özü-özləri yaxşılaşdırma qabiliyyəti, sessiya-aralıqlı xatirələrinin qaydası.**
- **Deleqatlar və paralelizəcə — paralel iş üçün subagentlər yaratmaq**
- **Məzannı avtomatları — gündəlik hesabatlar, backuplar, auditoriyalar üçün daxil edilmiş kron.**
- **Hər yerdə — lokal, Docker, SSH, cloud, serverless**

## Aşağıdakı əmrləri izləyin:

1. `git clone https://github.com/your-username/your-repo.git`
2. `cd your-repo`
3. `npm install`
4. `npm start`

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## İnişabat mərhələsi

```bash
openamer              # Müsahibə aparın
openamer setup        # **API Anaqlarını Quraşdırın və Tədarükçünü Təyin edin**

API anaqlarını quraşdırmaq və tədarükçünü təyin etmək üçün aşağıdakı addımları izləyin:

1. **API Anaqlarını Quraşdırın**
Əsasən, API anaqlarını quraşdırmaq üçün sizə müxtəlif tədarükçülərin saytlarında qeydiyyatdan keçmək və API anaqlarını aktivləşdirmək lazımdır. Məsələn:
 * **Google Cloud**: Google Cloud Platform saytında qeydiyyatdan keçin və API anaqlarını aktivləşdirin.
 * **AWS**: AWS Management Console-da qeydiyyatdan keçin və API anaqlarını aktivləşdirin.
 * **Microsoft Azure**: Microsoft Azure portalında qeydiyyatdan keçin və API anaqlarını aktivləşdirin.
2. **Tədarükçünü Təyin edin**
Tədarükçünü təyin etmək üçün sizə müxtəlif tədarükçülərin saytlarında qeydiyyatdan keçmək və API anaqlarını aktivləşdirmək lazımdır. Məsələn:
 * **Google Cloud**: Google Cloud Platform saytında qeydiyyatdan keçin və API anaqlarını aktivləşdirin.
 * **AWS**: AWS Management Console-da qeydiyyatdan keçin və API anaqlarını aktivləşdirin.
openamer model        # **Model seçin**
openamer update       # Sistemi yeniləşdirin
```
