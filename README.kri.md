## Instal fast

Winda (PowerShell)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## **Start**

```bash
openamer              # Wokam plesant yu?
openamer setup        # Set up yor API keys & provider.
openamer model        # **Krio**
openamer update       # Yu kama update to di latest version **[di latest version](https://www.example.com/latest-version)**.
```

## Wen deh update.

OpenAmer e checka update automaticali and show warnin in welcome banner. Run openamer update to get latest version - e backup data first.
