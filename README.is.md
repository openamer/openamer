# OpenAmer Agent

**Sjálfbættur gervigreindarframboð — lærið af reynslu, skapið nýja getni, munaðu eftir kostum þínum og vinnið fyrir þig hvar sem er.**

Notaðu hvaða líkan sem þú vilt — OpenRouter, OpenAI, DeepSeek og fleiri. Skiftaðu með `openamer model` — engar breytingar á kóða.

## Eiginleikar

- **Raunverulegt sníðmát fyrir tengilið — fullt TUI með sjálfvirkni, sögulegri yfirsýð og straumandi útskrift tóla**
- **Búir þar sem þú gerir — Telegram, Discord, Slack, WhatsApp og fleira frá einum gáttinni**
- **Lærir meðfram tímanum — minni, sjálfbættar getni, endurminning milliraðna**
- **Úsækir og samhleðar — býr til undirumboða fyrir samhleðis vinnu**
- **Forrituð sjálfvirknivinnslur — innbyggður cron fyrir daglega skýrslur, öryggirsafkopíur og endurskoðun**
- **Keyrir hvar sem er — staðlað, í Docker, yfir SSH, í skýjum eða serverless**

## Fljótupeningur

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Hvernig byrjar á

```bash
openamer              # Hefja spjall
openamer setup        # Stilltu API-lykla og söluaðila
openamer model        # Veldu líkan þitt
openamer update       # Uppfærið í nýjasta útgáfuna
```

## Uppfærsla

OpenAmer leitar sjálfkrafa að uppfærslum og sýnir viðvörun í velkomnutalningunni. Keyrðu `openamer update` til að fá nýjasta útgáfuna — kerfið tekur öryggunarafrit af gögnum þínum fyrst.
