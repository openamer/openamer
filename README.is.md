## Eigenskapir

- ****Réttu terminal-þjónn — fullt TUI með autofylling, sögulegu skrár og straumandi útkoma verkfæra****
- **Ég heldur þér þar sem þú heldur — Telegram, Discord, Slack, WhatsApp og fleiri frá einum porti.**
- **Lærir yfir tíma — minni, sjálfvirkir færir, skrefnaður skilríkur**
- **Delegatarar & samvirkar í röð — spöruðu undirverkfræði fyrir röðunarverk**
- **Tímabundiðar automatiskegir aðgerðir — byggt inni í króna fyrir daglega skýrslur, skráðar afritun, rannsóknir**
- **Rannsalar á öllum stöðum — lokalt, Docker, SSH, í fjölmörgum netþjónustum, óbundinn.**

## Rökkvænn Byrja

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Hvað er fyrstur að gera

```bash
openamer              # Hvað er að gera?
openamer setup        # Bætjið API lyklar þín og samskiptaverðlaun

**Veldu API lykla**
================

1. **Sækja API lykla**
   *   Veldu API lykla sem þú vilt nota, t.d. [Google Cloud](https://console.cloud.google.com/) eða [AWS](https://aws.amazon.com/).
2. **Búa til API lyklu**
   *   Fylla út formið fyrir API lyklu, eins og nafn, lýsing og lykilorð.
3. **Sækja API lyklu**
   *   Sækja API lyklu og gera það aðgengilegt fyrir aðferðir þínar.

**Bæta API lyklu í aðferð**
---------------------------

1. **Sækja API lyklu**
   *   Sækja API lyklu sem þú vilt bæta í aðferðinni.
2. **Bæta API lyklu**
   *   Bæta API lyklu í aðferðinni, eins og lýsing sýnir.
3. **Prúfa API lyklu**
   *   Prúfa API lyklu til að tryggja að það virkar rétt.
openamer model        # Veldu þinni þekkingarfræði
openamer update       # Nú er þetta á nýjusta útgáfu.
```

## Bætast.

OpenAmer skoðar sjálfkrafa eftir uppfærslum og sýnir varnarbönd í velkominu bannerinu. Keyrðu openamer update til að fá síðustu útgáfu — það varnar gögnin fyrst.
