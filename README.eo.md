# OpenAmer Agent

**La mempliboriganta AI-agento — lernu el’ de sperto, kreu kapablojn, memoru viajn preferojn, kaj laboru por vi ĉie.**

Uzu ajnan modelon, kiun vi volas — OpenRouter, OpenAI, DeepSeek, kaj pli multe. Ŝanĝu per `openamer model` — sen kodaj ŝanĝoj.

## Funkcioj

- **Veru terminala interfaco — plena TUI kun aŭtomatigo, historio, kaj fluanta elputo de iloj**
- **Vivantas tie, kie vi — Telegram, Discord, Slack, WhatsApp kaj pli, el unu gateway**
- **sanas kun tempo — memoro, mempliborigeblaj kapabloj, revoko tra sesioj**
- **Delegas & paraleligas — kreas subagentojn por paralela laboro**
- **Planitaj aŭtomatigoj — enigita cron por ĉiutagaj raportoj, sekurekopioj, revizoj**
- **Funkcias ĉie — loke, per Docker, SSH, nubo, senserviloj**

## Rapida Instalado

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Komenci

```bash
openamer              # Komencu babili
openamer setup        # Agordu viajn API-ŝlosilojn & provizanton
openamer model        # Elektu vian modelon
openamer update       # Aktualizu al la plej nova versio
```

## Aktualigado

OpenAmer kontrolas ĝisdatigojn aŭtomate kaj montras averton en la bonveniga bano. Pelu `openamer update` por ricevi la plej novan version — ĝi unue faras sekurkopion de viaj datumoj.
