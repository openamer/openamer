# OpenAmer Agent

**La memperfektiĝanta AI-agento — lernu el sperto, krei abelojn, memoru preferojn, kaj laboru por vi kie ajn.**

**Kiel funkciu la tradukilo?**

La tradukilo funkcias per la uzo de **neŭrala reto**. Ĝi estas tre rapida kaj preciza, kaj povas traduki tekston en diversaj lingvoj, inkluzive de Esperanto.

## Karakteroj

- **Reala termina interfaaco — kompleta TUI kun autokompleto, historio, kaj fluanta elirajxo de la ilo.**
- **Vivas kie vi faras — Telegram, Discord, Slack, WhatsApp kaj pli el unu portaĵo.**
- **Lernas dum la tempo — memorado, mem-plibonigaj kapabloj, intersesia memorado**
- **Delegitoj & paralelizas — lanĉas subagentojn por paralela laboro**
- **Programitaj automatiĝoj — interne integrita krono por tagaj raportoj, sekurigaj kopioj, aŭditoj**
- **Ĝuis kie ajn — lokale, Docker, SSH, en la nubo, senkoste.**

## Rapida Instalo

Windows (Povelskripto):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Lunixo / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Komenco

```bash
openamer              # Komencu la konversacion.
openamer setup        # Instalu vian API-ajn ŝlosilojn & provizantojn.
openamer model        # **Kiu modelon vi elektos?**
openamer update       # **Update al la plej lasta versio**
```

## **Aktualigo**

Aŭtomate, OpenAmer kontrolias aktualigojn kaj montras varmon en la bienvena bannero. Eksploru **openamer update** por ricevi la lastan versionon — ĝi unue savas vian datenaron.
