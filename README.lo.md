## **ສ້າງສະຫຼາດການຕິດຕວະຖານການສຳລາຍການ**

ສິວມຊານ (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

ລາວ: ລິນູຊີ / ມາກອສ
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## **ສະການກາງ** (phakhan khang)

```bash
openamer              # ສະບັບດີ
openamer setup        # **ພົວມາຕະກຳການຂອງ API ແລະສະຖາບານຂອງເພງ** (Setup API keys & provider)

1. **ຂໍ້ມັກ API ຂອງທ່ານ** (Get your API keys)
   - ທ່ານສາມາກຳການຂອງ API ໃນຂໍ້ມັກ API ຂອງທ່ານ (Get your API keys in your API dashboard)
   - ທ່ານຈາກການຂອງ API ຂອງທ່ານ (You can get your API keys from your API provider)

2. **ສະຖາບານຂອງເພງ** (Choose your provider)
   - ທ່ານສາມາກຳການຂອງ API ໃນຂໍ້ມັກ API ຂອງທ່ານ (Get your API keys in your API dashboard)
   - ທ່ານຈາກການຂອງ API ຂອງທ
openamer model        # ກະລຸນາກະຕັກ ເຮືອນ
openamer update       # ການສະຫຼາດການລະບາດ
```
