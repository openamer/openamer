Šomiša modelo le gotše ye o e ratago — OpenRouter, OpenAI, DeepSeek, le tše dingwe. Fetola ka `openamer model` — ga go na diphetolo tša khoutu.

## Dika tša go kgethega

- **Interface ya terminal ya nnete — TUI ye telele ka autocomplete, history, le streaming ya tšwaetšo ya tool**
- **Dula moo o lego gona — Telegram, Discord, Slack, WhatsApp le tše dingwe go tšwa gateway e tee**
- **E ithuta ka nako — kgopolo, bokgoni bja go ikutla, go gopola dilo go tloga go dipulelo tša go fapafapana**
- **E a šupa le go šomiša ditsela tše ntši ka nako e tee — e hlama ba thuši ba go šoma ka go tšweletša mešomo e mentši ka nako e tee**
- **Dithalo tšeo di rulagantšego — cron ya ka gare bakeng sa ditaelo tša letsatsi le letsatsi, go boloka dintlha (backups), le ditshekatsheko**
- **E šoma gotlhe — go lebeletše, Docker, SSH, cloud, serverless**

## Beala ka Peloko

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Thomo ya go thoma

```bash
openamer              # Thoma go boledišana
openamer setup        # Beaka dika tša API le moforaganyi wa gago
openamer model        # Kgetha mohlala wa gago
openamer update       # Ntlafatsa go ya go mofuta wa latest
```

## Go ntšha tše dingwa

OpenAmer e hlahloba diphetogo ka boyona gomme e bontšha temošo ka banere ya kamogelo. Tšweletša **openamer update** gore o hwetše mohlala wo o latest — e rwala datha ya gago pele.
