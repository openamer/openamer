## Whakapāwhiti Tāpua

**Whakaputaina i te Windows (PowerShell)**
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Rīpene / Whakairohia macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Whakapau kaha ki te mahi

```bash
openamer              # **Tēnā koe**. Ka tata ki a koe? (Hello. How are you?)
openamer setup        # **Whakauru i ngā pātene API me te kaiwhakamahi**

Ka taea e koe te whakauru i ngā pātene API me te kaiwhakamahi ka tika ai ngā kōrero e pā ana ki a koe.
openamer model        # Ko wai tēnei model?
openamer update       # **Tūhono ki te rārangi whakamutunga tōrangapū**.
```

## **Tāpiri ake** i te **reo Māori**:

- **Update** → **Tāpiri ake**
- **Updating** → **Tāpiri ake**
