# OpenAmer Agent

**L'agent di intellighjenza auturizzante — apprisce da l'esperienza, crea abilità, ricorda i tue preferenze, e travaglia per te ovunque.**

**Traduttione in Corsu**

Semplicemente clicca sul pulsante "Switch" e scegli il modello che desideri utilizzare. I modelli disponibili includono:

*   OpenRouter
*   OpenAI
*   DeepSeek
*   e molti altri

Per cambiare modello, utilizza il comando `openamer model`.

## Caratterìstichi

- **Interfaccia di terminali di tipo reale — TUI completu a pieno, con storia e output di strumientu in tempo reale.**
- **Vivete indè, da u gateway unu: Telegram, Discord, Slack, WhatsApp e più.**
- **Apprendi uffizziamenti uffizziamenti — memoria, abilità auto-miglioranti, ricorda s'impresa di s'assessu**
- **Deleghe & parallelize — sparghe subagenti pàrallu lavoru**
- **Automazioni prevedute — cron internu pà a i reporti ghjurnalistici, i backup, i auditi**
- **Funziona ovunque — locali, Docker, SSH, cloud, serverless.**

## Instalazzione Rapida

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Cumincà u Corsu

* Prima di ogni cosa, assicurati di avere installato u software necessario per tradurre.
* Scegli u software di traduzione che preferisci (ad esempio, Google Translate, Microsoft Translator, etc.).
* Assicurati di avere una buona connessione internet per utilizzare i servizi di traduzione online.
* Se desideri tradurre un testo, copia e incolla il testo da tradurre nella finestra di input del software di traduzione.
* Seleziona la lingua di partenza e la lingua di arrivo (Corsu).
* Clicca sul pulsante "Traduci" per iniziare la traduzione.
* Leggi e verifica la traduzione per assicurarti che sia corretta.
* Se necessario, puoi fare clic sul pulsante "Ritraduci" per correggere eventuali errori.

Nota: se desideri tradurre un testo da file, puoi utilizzare i seguenti formati: .docx, .pdf, .txt, ecc.

```bash
openamer              # Chjattà !
openamer setup        # Stabbica a API chiavi è & furnidore.
openamer model        # **Scegli tu il modello**
openamer update       # Aghjicca a l'ultima versione.
```

## **Aggiornamento**

Ameru apertu verifica l'aggiornamenti automaticamenti e mostra un avvisu in a banniera di benvenitu. Runa openamer update accatturari a versione più nova — si fa prima una còpia di sicurezza di i dati.
