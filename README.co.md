# OpenAmer Agent

**L'agent d'IA chì si migliora da solu — imparate da l'esperienza, create cumpetenze, ricordate i vostri preferenzi è travagliate per voi in ogni locu.**

Utilizate quale mudellu vulete — OpenRouter, OpenAI, DeepSeek, è altri ancora. Cambiate cù `openamer model` — senza cambià u codice.

## Caratteristiche

- **Interfaccia di terminale reale — TUI cumpleta cù autocompletamentu, storia è output di l'instrumentu in streaming**
- **Vive induve vive voi — Telegram, Discord, Slack, WhatsApp è altri ancore da un sol gateway**
- **Impara cù u tempu — memoria, cumpetenze chì s'improvinghenu sole, ricordu trà sessioni**
- **Delega & parallelizza — crea sub-agenti per u travagliu in parallelu**
- **Automatisazioni pianificate — cron integratu per i rapurtu quotidiani, i backup, l'audits**
- **Gjire ovunque — locale, Docker, SSH, cloud, serverless**

## Installazione rapida

Windows (PowerShell) :
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS :
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Cumincia à utilizà

```bash
openamer              # Cumincia à chattà
openamer setup        # Configurate i vostri chjave API & u pruvidore
openamer model        # Scegli u to mudellu
openamer update       # Aggiorna à a versione più recinte
```

## Aggiornamentu

OpenAmer verifica l'aggiornamenti in modu automaticu è mostra un avvisu in u banner di benvenuta. Esegu `openamer update` per avè l'ultima versione — questu fa prima un backup di i vostri dati.
