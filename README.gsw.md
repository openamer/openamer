# OpenAmer Agent

**Sälbschtverbesserndi AI-Agent — lerni vum Erlebnis, schaffi Fähigeit, erinneri diini Vorliebe, und arbeti fir di überall.**

**Willst du ehe di Alemannisch übersetze?** (Would you like me to translate into Alemannic?)

**I hänge ab von em Model, wo du wüschtsch** (I depend on the model you want)

**OpenRouter, OpenAI, DeepSeek, und anderi** (OpenRouter, OpenAI, DeepSeek, and others)

**Schwitzer em Model, wo du wüschtsch:** (Switch to the model you want)

* `openamer model OpenRouter`
* `openamer model OpenAI`
* `openamer model DeepSeek`
* `openamer model` (default model)

**Übersetzig:** (Translation)

**Ich hänge ab von em Model, wo du wüschtsch.** (I depend on the model you want.)

**I schwitzer em Model, wo du wüschtsch:** (I switch to the model you want.)

**Di Übersetzig erfolgt, wie du wüschtsch.** (The translation is done as you want.)

## Funktione

- ****Interaktivi Terminal — vollständige TUI mit Autocomplete, Historie und Streaming-Tool-Output****
- **Läbst wu du bist — Telegram, Discord, Slack, WhatsApp und mehri voar emeim Gateway**
- **Lernt über dä Zit — Gedächtnis, sich verbessrende Fähigkeiten, Übertragbarkeit zwüscht Sessione**
- **Delegiert & parallelisiert — Subagenten spawn für parallele Arbeit**
- **Gschäftliche Automatisierunge — eige Cron für tägliche Berichte, Backups, Audits**
- **Gilt alli, lokal, Docker, SSH, Cloud, serverlos.**

## Schnäll installiere

Windows (PowerShell): **[PowerShell](https://docs.microsoft.com/de-de/powershell/)**
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## **Aanfängs**

*   **Wos du brauchst**:
    *   **Ei Computer** oder **ei Smartphone** mit **Internet**-Zugang
    *   **Ei Browser** (z. B. **Google Chrome** oder **Mozilla Firefox**)
    *   **Ei Texteditor** (z. B. **Notepad** oder **TextEdit**)
*   **Wos du tue**:
    1.  **Ei Internet**-Verbindung herstellen
    2.  **Ei Browser** öffne
    3.  **Ei Texteditor** öffne
    4.  **Ei Text** in **Ei Texteditor** schreibe
    5.  **Ei Text** in **Ei Browser** eingebe

```bash
openamer              # Wännä du möchtäst, chännä z'mal a Gschächt anzefange!
openamer setup        # **API-Schlüssel einrichte & Provider**

Um die Funktionen von [OpenWeatherMap](https://openweathermap.org/) zu nutzen, benötigst du einen API-Schlüssel. Du kannst ihn auf der Website von OpenWeatherMap beantragen.
openamer model        # Wäi Model wottsch?
openamer update       # **Aktualisierig zum letschte Version**
```

## Aktualisierend

OpenAmer üscht automatisch für Aktualisierunge sche. Ei wärschins in de Begrüssigsbanner. Run openamer update, um dä letzte Version zuehalte — dä schützt eure Daten vorher.
