# OpenAmer Agent

**L'agente di intelligenza artificiale che si autoimprove — impara dall'esperienza, crea abilità, ricorda le tue preferenze e lavora per te ovunque.**

**Traduzione**

Ti prego, utilizza qualsiasi modello vuoi, come ad esempio OpenRouter, OpenAI, DeepSeek, ecc. Esegui il cambio con `openamer model` — non è necessario alcun codice modificato.

## **Caratteristiche**

- **Interfaccia di terminale reale — interfaccia TUI completa con completamento automatico, storia e output in streaming**
- **Vivi dove vivi — Telegram, Discord, Slack, WhatsApp e altro da un gateway**
- **Apprende nel tempo — memoria, abilità che si migliorano da soli, ricordo tra sessioni**
- **Delega e parallelizza — avvia sottoservizi per lavoro parallelo**
- **Automazioni programmate — cron integrato per rapporti giornalieri, backup, audit**
- **Eseguibile in ogni luogo — locale, Docker, SSH, cloud, serverless**

## Installazione rapida

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Iniziare

```bash
openamer              # Inizia a chattare.
openamer setup        # Impostare le tue chiavi API e il fornitore
openamer model        # Scegli il modello
openamer update       # Aggiornare alla versione più recente
```

## Aggiornamento

OpenAmer controlla automaticamente gli aggiornamenti e mostra un avviso nella barra di benvenuto. Esegui openamer update per ottenere la versione più recente — si fa una copia di backup dei dati prima.
