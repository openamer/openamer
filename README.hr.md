## **Osnovne značajke**

*   **Leksikon**: Leksikon sadrži detaljne informacije o različitim temama, uključujući definicije, primjere i reference.
*   **Pretraživanje**: Možete pretraživati leksikon prema riječima ili frazama, kao i po kategorijama i temama.
*   **Kategorije**: Leksikon je organiziran po kategorijama, što vam omogućava brzo pristup informacijama vezanim uz određenu temu.
*   **Referenciranje**: Svaki članak u leksikonu sadrži referenciranje izvora, što vam omogućava da proširite svoje znanje i istražite teme dalje.
*   **Dinamičko ažuriranje**: Leksikon je dinamički ažuriran, što znači da će se novije informacije i dopune ubrzo pojaviti u leksikonu.
*   **Interaktivni dijalozi**: Leksikon podržava interaktivne dijaloze, što vam omogućava da razgovarate s leksikonom i dobijate odgovore na vaša pitanja.
*   **Poveznice**: Leksikon sadrži poveznice na druge relevantne resurse, što vam omogućava da proširite svoje znanje i istražite teme dalje.
*   **Koristite našu mobilnu aplikaciju**: Možete koristiti našu mobilnu aplikaciju za pristup leksikonu i informacijama na bilo kojem

- **Puni terminalni interfejs — potpuni TUI s autouzučavanjem, istorijalom i streamovanim izlazom alata**
- **Živi gdje god si — Telegram, Discord, Slack, WhatsApp i još od jednog vratila**
- **Učio je kroz vrijeme — pamćenje, samopreparativne vještine, preko-sesija spominjanje**
- **Predstavnici & paralelizira — pokreće podagenčke za paralelno rješenje**
- **Planirane automatske radnje — izgrađeni cron za dnevne izvještaje, sigurnosne kopije, audite**
- **Raditi se gdje god želiš — lokalno, Docker, SSH, u oblaku, bez servera.**

## Brzo instalirajte

Windows (Powershell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Početak rada

```bash
openamer              # Počni razgovor.
openamer setup        # Postavite API ključeve & pružatelja
openamer model        # **Model izbira**

Kliknite na model koji želite koristiti:
openamer update       # Ažurirajte na najnoviji verziju.
```

## **Aktualizacija**

OpenAmer provjerava automatski ažuriranja i prikazuje upozorenje u uvodnom trakžnici. Pokreni openamer update za najnoviji verziju — prije toga će se automatizirano sprečavati vaša podatka.
