## **Iniziare**

```bash
openamer              # Comincia a parlar!
openamer setup        # **Configura i tui chiavi API & fornitor**

*   **API keys**: configura i tui chiavi API in base a le tue esigenze.
*   **Provider**: scegli un provider che si adatti a le tue esigenze.
openamer model        # **Scelesti el modelo!**
Scei el modelo che ti convien. **[Clicca qui per vèneto](https://www.google.com/url?q=https://en.wikipedia.org/wiki/Venetian_language&sa=D&usg=AFQjCNH4QwzPj8s5cQ2x7kQ8x4OxQx6p9Q)**
openamer update       # Agnoto a l'ùltima version.
```

## Agjornamento

OpenAmer el xe el che verifega automaticamente le novità e el mostra un avviso inte el banner de benvenuto. Runa openamer update par aver la version più nova – el fa prima un backup dei tuoi dati.
