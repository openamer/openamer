# OpenAmer Agent

**L'agente de IA che se migliora da solo — impara dall'esperiença, crea abilidà, se ricorda le tue preferense e lavora par ti ovunque.**

Usa el modello che te vol — OpenRouter, OpenAI, DeepSeek, e altri ancora. Cambia co `openamer model` — senza cambiar el codice.

## Caratteristiche

- **Interfasa de terminal vero — TUI completa co autocomplete, cronologia e output de i strumenti in streaming**
- **Vive dove vivi ti — Telegram, Discord, Slack, WhatsApp e altri ancora da un solo gateway**
- **Impara col tempo — memoria, capacità de migiorarse da solo, ricordo tra na sessione e l'altra**
- **Delega e paraleliza — crea sub-agenti par lavorar in paralelo**
- **Automasioni programàe — cron integrà par reporti quotidian, backup e audit**
- **Gira ovunque — local, Docker, SSH, cloud, serverless**

## Instalasion Rapida

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Come scominsiar

```bash
openamer              # Komesemose a ciacolar
openamer setup        # Configura le to keys de l'API e el provider
openamer model        # Scegli el to model
openamer update       # Sbilòca l'ultima version
```

## Agiornamento

OpenAmer controlla i novelty automaticamente e mostra un aviso nel banner de benvenù. Fà girar `openamer update` par aver l'ultima version — fa na copia de backup dei to dati prima de scominsiar.
