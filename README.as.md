# OpenAmer Agent

**আত্ম-উন্নয়নশীল AI এজেন্ট — অভিজ্ঞতাৰ পৰা শিকক, দক্ষতা সৃষ্টি কৰক, আপোনাৰ পছন্দসমূহ স্মৰণ কৰক, আৰু যিকোনো ঠাইত আপোনাৰ বাবে কাম কৰক।**

আপুনি যিকোনো মডেল ব্যৱহাৰ কৰিব পাৰে — OpenRouter, OpenAI, DeepSeek, আৰু অধিক। `openamer model` ব্যৱহাৰ কৰি সলনি কৰক — কোডৰ কোনো পৰিৱৰ্তন নকৰাকৈ।

## বৈশিষ্ট্যসমূহ

- **বাস্তৱ টাৰ্মিনেল ইণ্টাৰফেচ — সম্পূৰ্ণ TUI য'ত অটোকমপ্লিট, ইতিহাস, আৰু ষ্ট্ৰিমিং টুল আউটপুট আছে**
- **আপোনাৰ সৈতে থকা জীৱন — Telegram, Discord, Slack, WhatsApp আৰু একাধিকৰ পৰা এটা গেটৱেৰ পৰা**
- **সময়ৰ সৈতে শিকিছে — স্মৃতি, আত্ম-উন্নয়নশীল কৌশল, আন্তঃসেশন স্মৰণ**
- **ডেলিগেট আৰু পেৰালেলাইজ — পেৰালেল কৰ্মৰ বাবে উপএজেন্ট সৃষ্টি কৰক**
- **নিয়মিত স্বয়ংক্ৰিয়তা — দৈনিক প্ৰতিবেদন, ব্যাকআপ, অডিটৰ বাবে অন্তৰ্নিহিত ক্রন**
- **য'ত খোজে — স্থানীয়, Docker, SSH, মেঘ, ছাৰ্ভাৰলেছ**

## দ্ৰুত স্থাপন

উইণ্ডোজ (পাৱাৰশেল):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

লিনাক্স / মেকঅছ:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## শুরু কৰা

```bash
openamer              # চেটিং আৰম্ভ কৰক
openamer setup        # আপোনাৰ API কী আৰু প্ৰদানকাৰী স্থাপন কৰক
openamer model        # আপোনাৰ মডেল বাচনি কৰক
openamer update       # সৰ্বশেষ সংস্কৰণত আপডেট কৰক
```

## আপডেট কৰা হৈছে

OpenAmer স্বয়ংক্ৰিয়ভাৱে আপডেটৰ বাবে পৰীক্ষা কৰে আৰু স্বাগতম বেনাৰত এটা সতর্কতা দেখুৱায়। সৰ্বশেষ সংস্কৰণ পাবলৈ openamer update চলাও — ই প্ৰথমে তোমাৰ ডাটা বেকআপ কৰে।
