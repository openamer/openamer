## সুবিধা

- **সমার্ট টার্মিনাল ইন্টারফেস — পূর্ণ TUI সহ অটোমেটিক কম্পলিট, ইতিহাস, এবং স্ট্রিমিং টুল আউটপুট**
- **আপনার যে ঠিকানাতে থাকুক না কেন — Telegram, Discord, Slack, WhatsApp এবং আরো একই গেটওয়ে থেকে**
- **শিখে যায় সময়ের সাথে — মেমোরী, স্ব-উন্নত দক্ষতা, ক্রস-সেশন স্মৃতি**
- **ডেলিগেট এবং পারলেলাইজ করে — পারলেল কাজের জন্য সাব-এজেন্ট স্পাওন করুন**
- **সচল অটোমেশন — দৈনিক রিপোর্ট, ব্যাকআপ, অডিট সহ নির্ভরযোগ্য ক্রন**
- **সবুকায় চলে — স্থানীয়, ডকাৰ, SSH, বুলুকা, সার্ভাৰলেছ**

## তাৰুণ্য ইনষ্টলেশ্যন

ৱিণ্ডোজ (পাওৱারশেল)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

লিনাক্স / ম্যাকোস
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## শুরু করা

```bash
openamer              # আপনার সাথে কথা বলা শুরু করা যাক
openamer setup        # আপিকেয় চাপুৰা আৰু পৰবৈদ
openamer model        # অসমীয়া
openamer update       # আপডেট করুন সবচেয়ে নতুন সংস্করণে
```

## আপডেট করা

অপেনঅমের আপডেট সম্পর্কে স্বয়ংক্রিয়ভাবে চেক করে এবং স্বাগত বারে একটি চেতনাবোধ দেখায়। অপেনঅমের আপডেট করুন যাতে সবচেয়ে নব সংস্করণ পেতে পারেন — এটি প্রথমে আপনার ডেটা ব্যাকআপ করে।
