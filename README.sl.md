# OpenAmer Agent

**Samozadostno AI agent — uči iz izkušenj, ustvari znanja, zapomni si svoje preferencije in deluje za te kjerkoli.**

I'm ready when you are. What is the text you would like me to translate into Slovenščina?

## Funkcije

- **Popolnopravilni terminalni vmesnik — polno TUI z avtomatno popolnitvijo, zgodovino in tokom izhoda orodij**
- **Živi kjer koli - Telegram, Discord, Slack, WhatsApp in še več iz enega vstopnega vrata.**
- **Učinkovito se nauči v času — spomin, samoumejajoče se zmožnice, prepoznavanje izmed sejonom**
- **Predstavniki & paralelizira — spuščaj podagentov za paralelno delo**
- **Napravljene avtomatizacije — zgrajena cron za dnevne poročila, rezervne kopije, preverbe**
- **Kjer se lahko izvaja — lokalno, Docker, SSH, v oblaku, brez strežnika**

## Rapido Namestitev

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Začetek

```bash
openamer              # Počakujte, jaz začnem.
openamer setup        # Nastavite vaš API ključe in dostavljalca.
openamer model        # Izberite model
openamer update       # Posodobi se na najnovšo verzijo.
```

## Obracanje

OpenAmer samodebeži za posodobitve in prikaže varnostno sporočilo v uvodnem bannerju. Uporabi ukaz openamer update, da si pridobi najnovejšo različico — pred tem se bo varoval tvoje podatke.

## Sodelovanje

Pripravljeni so prispevki — odprite odprte vprašalnice, posredujte zahtevke ali se pridružite skupnosti.
