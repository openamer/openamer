# OpenAmer Agent

**स्व-परिवर्तनीय एआई एजेंट - अनुभव से सीखें, कौशल बनाएं, पसंदीदा विकल्पों को याद रखें, और आप के लिए कहीं भी काम करें।**

**हिन्दी में अनुवाद**

आप किसी भी मॉडल का उपयोग कर सकते हैं - ओपनरूटर, ओपनएआई, डीपसीक, और अधिक। स्विच करने के लिए `openamer model`

## विशेषताएँ

- **पूर्ण टर्मिनल इंटरफ़ेस — पूर्ण TUI साथ में ऑटोकम्प्लीट, हिस्ट्री और स्ट्रीमिंग टूल आउटपुट**
- **आपके जैसे जिंदगी **— टेलीग्राम**, **डिस्कोर्ड**, **स्लैक**, **व्हाट्सएप** और अधिक एक गेटवे से**
- **समय के साथ सीखता है — स्मृति, आत्म-सुधार कौशल, सत्र-आधारित स्मृति**
- **विभागित करें और साथ में - पारितंत्रित करें - स्वतंत्र एजेंटों के लिए स्पॉउन करें जो परस्पर परिचालित कार्य करें**
- **निर्धारित ऑटोमेशन्स — निर्मित क्रॉन दैनिक रिपोर्ट, बैकअप, ऑडिट**
- **किसी भी स्थान पर चले — स्थानीय, डॉक्टर, SSH, cloud, serverless**

## **त्वरित स्थापना**

विंडोज़ (पॉवरशेल)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

लिनक्स / मैकओएस:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## शुरुआत करना

```bash
openamer              # बात करना शुरू करें
openamer setup        # API कुंजियों और प्रदाता को सेट करें
openamer model        # कृपया मॉडल चुनें
openamer update       # अपडेट करें नवीनतम संस्करण तक
```

## अपडेट करना

ओपनअमेर स्वचालित रूप से अपडेट की जांच करता है और प्रारंभिक बैनर में चेतावनी दिखाता है। ओपनअमेर अपडेट करें चलाएं ताकि नवीनतम संस्करण प्राप्त किया जा सके - यह आपके डेटा की प्रतिलिपि बनाता है।
