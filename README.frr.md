## Snel Installeeren

Wint (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Begjinnen

```bash
openamer              # **Hallo!** Wann bist du frei fer skriewen?
openamer setup        # **Sätje dina API-sleutels & anbieter**

*   **API-sleutels**: [https://api-keys.example.com](https://api-keys.example.com)
*   **Anbieter**: [https://anbieter.example.com](https://anbieter.example.com)
openamer model        # I'm ready to translate into North Frisian (Nordfriisk). What would you like me to translate?
openamer update       # **Nieuwer Update**
```
