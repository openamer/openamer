# OpenAmer Agent

**De sälf-förbetterende AI-agent — larn ut erfaring, skap skills, remember di preferensen, ånd wurk för di iäwär allet.**

Brûk hüt an model as dü wult — OpenRouter, OpenAI, DeepSeek, an mîr. Wîksel mî `openamer model` — uton kood-Ändrings.

## Egenskapen

- **Riel terminal-interfais — fulle TUI mäd autocomplete, historik unt streaming tool-utput**
- **Liiu thêr, hu thêr liiu — Telegram, Discord, Slack, WhatsApp an mear ut iin gateway**
- **Lärn over tide — minne, sälf-forbetterende fähigkeiten, recall over sessions hinweg**
- **Delegiert & parallelisiert — spawnet Sub-Agenten för parallel Arbaid**
- **Plante Automatisierungen — iinbaute cron för daalige Berichte, Backups, Audits**
- **Löpt ållweer — lokal, Docker, SSH, cloud, serverless**

## Snel installiern

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Beginnen

```bash
openamer              # Begin chatten
openamer setup        # Richte di API-klevis & provider ii
openamer model        # Wähl dîn Modell
openamer update       # Updaat tå di lätst version
```

## Aktualisiern

OpenAmer tjekt automatyk för updates ånd wiset en warnung in der welcome-banner. Run `openamer update` för di latest version — dat bakup’t di data först.
