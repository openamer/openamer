# OpenAmer Agent

**Ինքնաբերող ԱԻ գործընկալը — սովորի փորձից, ստեղծի մասնագիտություններ, հիշի ձեզ նախընտրականությունները և աշխատի ձեզ համար որտեղ էլ։**

Հայերեն թարգմանությունը կարող եք կատարել հետևյալ մոդելներից մեկով՝ OpenRouter, OpenAI, DeepSeek և այլն։ Մոդելների միջերեսը փոխելու համար կարող եք օգտնվել `openamer model` հրամաններից։

## Հատկանիշներ

- **Միջատեսակային տերմինալ ինտերֆեյս — լիացիոն TUI հետ ավտոմատիզացված տեքստային մուտք, պատմություն և հոսանի գործիքների դուրսերկրում**
- **Մնում է որտեղ դու ես — Telegram, Discord, Slack, WhatsApp և ավելինչ մի դարպասով**
- **Արձագային սովորում — հիշողություն, ինքնուսուցման կարողություններ, մի նստարկից մյուսը հիշելու կարողություններ**
- **Տեղադրիչներ են ու զուգահեռացնում — սեփական գործակալներ են ստեղծում զուգահեռ աշխատանքների համար**
- **Ավտոմատ ծրագրեր՝ կրոնի համար կիրառվող միջկրոնային հավելված, օրական հաշվետվություններ, պահպանումներ, հաշվառումներ**
- **Տեղայաց միշեն — տեղայաց, Docker, SSH, բանկային, ծառայությանը անվճար ծառայությանը**

## Հայտնվել է Անվեհոն Հայերեն

Վինդովս (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Սկսելիս

```bash
openamer              # Սկսել խոսակցությունը
openamer setup        # Միացնել ձեր  API հատկանիշները եվ տրեատորը
openamer model        # Մոդել ընտրեք
openamer update       # Մինիմալ տարբերակի վերամշակումը կատարվում է ավտոմատ։
```

## Միջքաղաքային

OpenAmer-ն ավտոմատիկորեն ստուգում է թարմ տարբերակները և հայտնի է լուսաբառում։ OpenAmer-ը թարմ տարբերակը ստանալու համար կատարեք openamer update հրամանը՝ այն կստուգի տվյալները և պահելու դրանք։

## Մասնակցություն

Գրանցված են նոր ներդրումները — բաց խնդիրներ, ներումներ ներկայացնել կամ միանալ համայնքին։
