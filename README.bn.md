# OpenAmer Agent

**স্ব-উন্নয়ী AI এজেন্ট — অভিজ্ঞতা শিক্ষা করুন, দক্ষতা তৈরি করুন, আপনার পছন্দ স্মরণ করুন এবং আপনার জন্য যেখানেই কাজ করুন।**

আপনার প্রয়োজনীয় সমস্ত সম্পাদনা করা হয়েছে।

## বৈশিষ্ট্য

- ****প্রকৃত টার্মিনাল ইন্টারফেস** — **পূর্ণ TUI সহ অটোমেটিক কম্পিট, ইতিহাস এবং স্ট্রিমিং টুল আউটপুট****
- **আপনি যেখানে থাকেন তার জন্য থেকে — Telegram, Discord, Slack, WhatsApp এবং আরও অনেক এক গেটওয়েতে**
- **শিখে যায় সময়ের সাথে — মেমরি, স্ব-উন্নত দক্ষতা, ক্রস-সেশন স্মৃতি**
- **উপদেশক এবং পারমিত্ব করে — স্পর্শকারী উপদেশক প্রতিষ্ঠা করে পারমিত্ব কাজ**
- **স্কিডুলড আটোমেশনস — বিল্ট-ইন ক্রন দিনের রিপোর্ট, ব্যাকআপ, অডিট**
- **যেখানেই চলে — স্থানীয়, Docker, SSH, বাণিজ্যিক, অপ্রচলিত স্থানে**

## তাড়াতাড়ি স্থাপন

উইন্ডোজ (পাওয়ারশেল)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

লিনাক্স / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## শুরু করা

```bash
openamer              # আপনার সাথে কথা বলতে শুরু করতে চান?
openamer setup        # আপনার API কী সেট আপ করুন এবং প্রদাতা
openamer model        # আপনার মডেল বেছে নিন
openamer update       # আপডেট করুন সবচেয়ে নতুন সংস্করণে
```

## আপডেট করা হচ্ছে

ওপেনামার আপডেট সহজেই অটোমেটিকভাবে চেক করে এবং স্বাগতিক ব্যানারে একটি সতর্কতা দেখায়। ওপেনামার আপডেট করুন নতুন সংস্করণ পেতে — এটি আপনার ডেটা প্রথমে ব্যাকআপ করে।
