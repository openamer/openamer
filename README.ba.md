# OpenAmer Agent

**Үҙен үҙе камилләтеүче ИИ-агент — тәжрибәҙән өйрәнә, яҡылыштар ҡурасауҙарын ҡураса, һиҙүҙәрегеҙе иҫтелә һәм һиҙгә һәр урында хезмәт ителә.**

Истегеҙ модельҙе ҡулланығыҙ — OpenRouter, OpenAI, DeepSeek һәм башҡалар. `openamer model` командой алмаштырығыҙ — кодны үҙгәртергә кентеләмәй.

## Мөһиме characteristic-тар

- **Рәл терминал интерфейсы — тулы TUI автозаполнение, тарих һәм инструменттарының нәтижәләрен стримингҙән тормоҡ ҡабул ҡылыуҙың килеле साथ**
- **Яшәй һинең һөйөгән урындарыңда — Telegram, Discord, Slack, WhatsApp һәм башҡалар бер шлюз аша**
- **Ваҡыт alonga өйрәнә — иҫтә kiләсәк, үҙен-үҙе бетереүшәй skills, сессиялар араһында иҫтә ҡаҙырыу**
- **Делегирует һәм параллельлештерә — параллель эш aһтарын үҙәлеп сығара**
- **Планирулаған автоматизациялар — көйендегелеcron көндәлек отчеттар, бэкаплар, аудиттарҙы pelaksanaan kanggo**
- **Һәр урында эшләй — локаль, Docker, SSH, булт, serverless**

## Тез ҡурултыу

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Башлау

```bash
openamer              # Сөйләшәйек
openamer setup        # API киллектәрегеҙҙен һәм sağlayиуҙы (provider) ҡуруығыҙ
openamer model        # Модельҙе һайлағыҙ
openamer update       # Соңғы версияғагәйен яңыртыңыз
```

## Яңырлау

OpenAmer автоматик рәүеһен яңыlaşуларҙы тикшеру һәм ҡабуллау баннерендә һаваҡландыру күрһәтә. Соңғы версияны алыу kanggo `openamer update` командаһын эшемтеләң — ул иң алғаш თქვენің мәlumatығыҙы резерв копиялай.
