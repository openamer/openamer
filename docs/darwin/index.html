🧬 Darwin Engine

The self-evolving skill ecosystem for OpenAmer. No other agent framework lets its skill population evolve itself.

Natural selection, applied to agent capability

Skills are scored on real usage signals. The fittest breed mutated children. Children compete against their parents live in production cron jobs — the winner decided by real exit codes, not benchmarks. Dead weight is quarantined, reversibly. Every step of the family tree is preserved forever.

The 5 phases

1

Fitness

Real signals: session usage, cron health, stagnation penalty.

2

Live Trials

Child replaces parent in a real cron job. executions.db decides.

3

Autopilot

Semantic mutations, quarantine with rollback, zero human input.

4

Lineage

Mermaid family tree + portable genomes for fleet evolution.

5

Tournament

Auto-trials the best candidates, max 2 concurrent, double-book safe.

One command runs the whole cycle

python scripts/darwin_engine.py --autopilot
# [autopilot] fitness computed for 9 skills
# [autopilot] 5 mutations generated
# [autopilot] trial self_rewriter_6h: waiting {'completed': 0, 'error': 0}
# [autopilot] tournament: trialing `auto-env-checker__mutadd_pitfall`
# [autopilot] report -> reports/darwin-report.md

Real output from a live system — the trial you see above is running in production right now.

Guarantees

  • Never deletes — parents archived, quarantined skills restorable
  • Never guesses — every promotion backed by real execution evidence
  • Never breaks cron — job-referenced skills are protected from pruning
  • Reproducible — fixed seed mutations, fully auditable
  • Fleet-ready — genomes merge across machines, highest W/L wins

Why it matters

Every other agent framework curates skills by hand — humans deciding what stays, what goes, what improves. Darwin removes the human from the loop: improvement pressure comes from actual usage, selection from actual failures, and the lineage of every improvement is kept forever.
