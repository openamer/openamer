# OpenAmer Agent

**Ang self-improving AI agent — makakat-on gikan sa kasinatian, makahimo og mga kahanas, makahinumdom sa imong mga gusto, ug motrabaho alang kanimo bisan asa.**

Gamita ang bisan unsang modelo nga imong gusto — OpenRouter, OpenAI, DeepSeek, ug uban pa. Pagbalhin gamit ang `openamer model` — walay usbon sa code.

## Mga Kinaiya

- **Tinuod nga terminal interface — kompleto nga TUI nga adunay autocomplete, history, ug streaming tool output**
- **Nagpuyo kung asa ka — Telegram, Discord, Slack, WhatsApp ug uban pa gikan sa usa ka gateway**
- **Nagkat-on sa paglabay sa panahon — memorya, mga kahanas nga nag-uswag sa kaugalingon, paghinumdom taliwala sa mga session**
- **Nag-delegate & nag-parallelize — nag-spawn og mga subagent para sa dungan nga trabaho**
- **Mga naka-iskedyul nga automation — built-in cron alang sa mga adlaw-adlaw nga report, backup, ug audit**
- **Modagan bisan asa — local, Docker, SSH, cloud, serverless**

## Dali nga Pag-install

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Pagsugod

```bash
openamer              # Sugod na sa pag-chat
openamer setup        # I-set up ang imong mga API key & provider
openamer model        # Pilia ang imong modelo
openamer update       # I-update sa pinakabag-ong bersyon
```

## Nag-update

Ang OpenAmer awtomatikong nagsusi alang sa mga update ug nagpakita og pasidaan sa welcome banner. Pagdagan og `openamer update` aron makuha ang pinakaulahing bersyon — i-back up una niini ang imong mga datos.
