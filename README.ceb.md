## Magsugat ka! (Let's get started!)

```bash
openamer              # Magsugat ta sa iya! (Let's start chatting!)
openamer setup        # Pakiusab ang imong API keys ug provider.
openamer model        # Kining model, nagamit ko sa pagtan-aw ug paghunahuna sa mga tan-awaon ug mga katan-awon.
openamer update       # Nag-update ka sa pinakabag-ohan nga bersyon.
```

## Pagsulbad sa Pagbalhin

Ang OpenAmer nag-check sa mga update sa automated ug nagpakita sa pagkubkob sa banner sa pag-abot. Mag-una sa openamer update aron makakuha sa latest version — sa unang pagkita, nagbabalik sa imong data.
