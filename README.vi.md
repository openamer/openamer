# OpenAmer Agent

**Tác nhân AI tự cải thiện — học hỏi từ trải nghiệm, tạo lập kỹ năng, ghi nhớ sở thích của bạn và làm việc cho bạn ở mọi nơi.**

Sử dụng bất kỳ mô hình nào bạn muốn — OpenRouter, OpenAI, DeepSeek, và nhiều mô hình khác. Thay đổi bằng lệnh `openamer model` — không cần thay đổi mã nguồn.

## Tính năng

- **Giao diện terminal thực thụ — TUI đầy đủ với tính năng tự động hoàn tất, lịch sử và hiển thị đầu ra công cụ theo thời gian thực**
- **Hiện diện nơi bạn hiện diện — Telegram, Discord, Slack, WhatsApp và nhiều hơn nữa từ một cổng kết nối duy nhất**
- **Học hỏi theo thời gian — bộ nhớ, kỹ năng tự cải thiện, khả năng nhớ lại giữa các phiên làm việc**
- **Ủy thác & song song hóa — khởi tạo các subagent để làm việc song song**
- **Tự động hóa theo lịch trình — tích hợp sẵn cron cho báo cáo hàng ngày, sao lưu và kiểm tra**
- **Hoạt động ở mọi nơi — local, Docker, SSH, cloud, serverless**

## Cài đặt nhanh

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Bắt đầu sử dụng

```bash
openamer              # Bắt đầu trò chuyện
openamer setup        # Thiết lập khóa API & nhà cung cấp của bạn
openamer model        # Chọn mô hình của bạn
openamer update       # Cập nhật lên phiên bản mới nhất
```

## Đang cập nhật

OpenAmer tự động kiểm tra các bản cập nhật và hiển thị cảnh báo trong biểu ngữ chào mừng. Hãy chạy lệnh `openamer update` để cập nhật phiên bản mới nhất — hệ thống sẽ sao lưu dữ liệu của bạn trước khi thực hiện.
