# OpenAmer Agent

**თვის სარგებლობრივი აი აგენტი — გაიგე გამოცდილებისგან, შექმენი უნარები, დაიცავი თვის სურვილები და მუშაობის მისამართი თვისთვის.**

როგორჩა გვესაუბლებთ საკუთარ თავს, შეგიძლია გამოიყენო როგორც OpenRouter, ასევე OpenAI, DeepSeek და სხვა მოდელები. გვესაუბლებთ მოდელზე, გადასვლა შეიძლება მოდელის სახელით: `openamer model` — კოდი გამოიცვლება.

## თვისებისები

- **რეალური ტერმინალური ინტერფეისი — სრული TUI ავტომატიზირებული სიტყვიერება, ისტორია და სტრიმინგი ინსტრუმენტების გამოტანა.**
- **ბედით ისახება თუ თითოთი გემრთყვება თუ თუ ერთ გვიგვიდან თელეგრამი, დისკორდი, სლეკი, ვასტაბლი და მეტი.**
- **იყენებს ისტორიაში მისი განვითარებას, მეხსობრობა, თავისთვნ საკუთრი უნარი, სესიებს შორს წაკითხვა**
- **სამართავი და პარალელური მართლება — პარალელური სამუშაოსთვის სამართლების სამართლოს სამართლების სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლოს სამართლო**
- **ავტომატული განრიგებები — ინტეგრირებული cron დღისითი ანგარები, ბეკაპი, აუდიტები.**
- **არსებობს საშუალება სამუშაო ადგილზე როგორც ლოკალურად, ისე დოკერში, SSH, მართვის უფლების გარეშე, მედიატორებში.**

## სწრაფი მონტაჟება

ვინდოსი (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

ლინუქსი / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## საწყისი ნაბიჯები

```bash
openamer              # დაწყნარებით დაიწყეთ კომუნიკაცია.
openamer setup        # ახალი API სახელები და მიწოვნების დასახელება.
openamer model        # აირჩიეთ მოდელი
openamer update       # განახარია უკვე უზურპირებული ვერსია.
```

## განახლება

ახალი ვერსია ავტომატურად ინახევს OpenAmer-ში და მისასალანგვარებად მობილათაა საუბარის ბარში. ახალი ვერსიათვეს მოინახევს openamer update მეთოდით — ისინი პირველი იწინასვეს დატას.
