# OpenAmer Agent

**თვითგადმaméliორებელი AI აგენტი — სწავლობს გამოცდილებით, ქმნის უნარებს, იმახსოვრებს თქვენს პრეფერენციებს და მუშაობს თქვენთვის ყველგან.**

გამოიყენეთ ნებისმიერი მოდელი, რომელიც გსურთ — OpenRouter, OpenAI, DeepSeek და სხვა. გადაირთვეთ `openamer model`-ით — კოდის შეცვლა საჭირო არ არის.

## ფუნქციები

- **ნამდვილი ტერმინალის ინტერფეისი — სრული TUI ავტocomplete-ით, ისტორიითა და ხელსაწყოების რეალურ დროში გამომავალი მონაცემებით (streaming output)**
- **იცხოვრეთ იქ, სადაც თქვენ — Telegram, Discord, Slack, WhatsApp და სხვა კიდევ ბევრი, ერთი Gateway-ს მეშვეობით**
- **სწავლობს დროთა განმავლობაში — მეხსიერება, თვითგაუმჯობესებელი უნარები, სესიებს შორის ინფორმაციის აღდგენა**
- **ააგირებს და პარალელურებს — ქმნის სუბაგენტებს პარალელური მუშაობისთვის**
- **დაგეგმილი ავტომატიზაციები — ჩაშენებული cron ყოველდღიური რეპორტების, სარეზერვო ასლებისა და აუდიტებისთვის**
- **მუშაობს ყველგან — ლოკალურად, Docker-ში, SSH-ით, ღრუბლოვან სისტემებში, serverless რეჟიმში**

## სწრაფი ინსტალაცია

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## დასაწყისი

```bash
openamer              # დაიწყეთ ჩატინგი
openamer setup        # გამართეთ თქვენი API გასაღებები და პროვაიდერი
openamer model        # აირჩიეთ თქვენი მოდელი
openamer update       # განაახლეთ უახლეს ვერსიამდე
```

## განახლება

OpenAmer ავტომატურად ამოწმებს განახლებებს და გამაფრთხილებელ შეტყობინებას menampilkan მისალმების ბანერში. ბოლო ვერსიის მისაღებად გაუშვით `openamer update` — ის პირველ რიგში თქვენს მონაცემებს სარეზერვო ასლად შეინახავს.
