# OpenAmer Agent

**Samoošćavajući agent za AI — učij od iskustva, stvori vještine, zapamti svoje preferencije, i radi za vas bilo gdje.**

**Pregledajte ove opcije:**

*   **OpenRouter**: nije dostupan
*   **OpenAI**: dostupan
*   **DeepSeek**: nije dostupan

**Koje će model koristiti?**

Korisnik može odabrati koji će model koristiti za prevođenje. Ako se korisnik nije odabrao nikakav model, odabere se **OpenAI** kao defaultni model.

## Karakteristike

- ****Puni terminalni interfejs — potpuni TUI sa autoumjetanjem, historijom i streamovanjem izlaza alata**

[Terminal](https://en.wikipedia.org/wiki/Terminal_(computing))**
- **Živi gdje god si — Telegram, Discord, Slack, WhatsApp i više iz jednog vratila**
- **Učio se tokom vremena — pamćenje, samopopravljački umijeća, prenos memorije između sesija**
- **Predstavnici & paralelizira — pokrene podagenti za paralelno rad.**
- **Aplikovani automatizmi — građeno kalendar za dnevne izvještaje, kopije, auditiranje**
- **Radno na bilo kojem mestu — lokalno, Docker, SSH, oblak, bezserver**

## Brzo Ustanoviti

Windows (Powershell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Pokretanje

```bash
openamer              # Počni razgovor.
openamer setup        # Postavi API ključeve i provajdera
openamer model        # Koji model izaberete?
openamer update       # Ažurirajte na najnoviju verziju.
```

## Ažuriranje

OpenAmer provjerava ažuriranja automatski i prikazuje upozorenje u uvodnom baneru. Pokreni openamer update da bi ste dobili najnoviju verziju — prvo će se sakupiti vaša podataka.
