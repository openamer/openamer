**Agens intelligentia se ipsa meliorans — discere ex experientia, creare facultates, recordare tuae voluntates, et operari pro te ubicumque.**

**Translation Model:** OpenAI

Use any model you want — OpenRouter, OpenAI, DeepSeek, and more. Switch with `openamer model` — no code changes.

## **Características**

- ****Interficies terminalis realis — TUI plena cum autocompletione, historia, et output instrumentorum in fluxu****
- ****Ubique habitat ubi tu** — Telegram, Discord, Slack, WhatsApp et plura a uno portae.**
- **Docet per tempus — memoria, aptus artes, recollectio inter sessiones**
- **Delegati & parallelizant — subagentes generant in operam parallelos**
- **Automatizatioe temporales — cron inbuiltus quotidianus ad relationes, copias, auditores.**
- **Ubique currat — in loco, Docker, SSH, nube, serverless**

## Instalatio Velox

**Windows (PowerShell)**: Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Initiatio

```bash
openamer              # Salve!
openamer setup        # **Configura tus claves de API y proveedor**

`api_key` = **Clave de API**
`api_provider` = **Proveedor de API**
openamer model        # Elegi modello.
openamer update       # **Nova versione** [https://www.example.com/latest-version](https://www.example.com/latest-version) nunc est disponibilis.
```

## **Actualizatio**

Amer Opena **vigilat** automatice pro novissimis versionibus et ostendit in banner salutis monitum. **Run openamer update** ad accipiat novissimam versionem — **primum** datam tuam **servabit**.
