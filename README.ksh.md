# OpenAmer Agent

**De selvslevvelende KI-Agent — us Erfarung lere, Fähikeite schaffe, sich dinge Vorliebe merke un überall för dich schaffe.**

Nimm dir dat Modell, dat de wells — OpenRouter, OpenAI, DeepSeek un noch vill mehr. Wechsel einfach mit `openamer model` — ohne dat de am Code rumfummele muss.

## Funksjone

- **Richtiges Terminal-Interface — volle TUI mit Autocomplete, History un streaming Tool-Output**
- **Levt durt, wo du och bist — Telegram, Discord, Slack, WhatsApp un mehr us enem Gateway**
- **Läärt mit dä Zeit — Gedächtnis, Fähigkeite die sich selver verbessere, Erinnere an frühere Sitzunge**
- **Delegiert & parallelisiert — spawn Sub-Agenten för parallelle Arbeit**
- **Jeplante Automatisierungen — ingebaute Cron för täjeliche Berichte, Backups un Audits**
- **Löppt überall — lokal, Docker, SSH, Cloud, serverless**

## Schnell-Installatshun

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Loss et loss goon

```bash
openamer              # Fang an schwade
openamer setup        # Richte dinge API-Keys un dinge Provider ein
openamer model        # Söck der dinge Modell us
openamer update       # Update op die neuveste Version
```

## Op d'r Neuste Stand bringe

OpenAmer luekt automatisch noh Updates un zockt e Warnung im Welcome-Banner an. Maach `openamer update`, om die neuveste Version ze kriege — dat Programm mäht dervor erst e Backup vun dine Date.
