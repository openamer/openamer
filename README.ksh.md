```bash

openamer update       # **Updat op de letzte Version**
```

## **Dat Ändere**

**OpenAmer** checkt automatisch nach Updates und zeigt eine Warnung im Willkommensbanner an. **OpenAmer update** läufst, um die aktuellste Version zu kriegen — das schont eure Daten.
