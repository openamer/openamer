# OpenAmer Agent

**Savęs paprastymuoju AI agentas — mokytis iš patirties, kurti savo gebėjimus, prisiminti savo preferencijas ir dirbti jūsų atžvilgiu bet kur.**

**Lietuvių vertimas**

Jeigu norite pakeisti modelį, naudokite komandą `openamer model`.

## Savybės

- **Tikras terminalio sąsaja — pilnas TUI su atitarnavimu, istorija, ir strimiškojo darbo priemonės išvedimo galimybe**
- **Žmonės, kur jūs gyvenate — Telegram, Discord, Slack, WhatsApp ir daugiau iš vieno gateway**
- **Mokosiama iš tolaika — atmintis, pažįstamųjų savo savybių, atsiskyrimas po sesijų**
- **Atstovai & paralelinis - atstovų subagentų spalvų užsakymai paraleliniam darbui**
- **Automatiniai užduotys — įdiegiamas cron dieninių ataskaitų, atsargųjų, auditooseių užduotys.**
- **Darbinau visur — vietiniu, Docker, SSH, nukrypčiuose, bešalinėje**

## Greita Instalacija

**Windows (PowerShell)**
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Pradžia

```bash
openamer              # Prasidedami pokalbiame.
openamer setup        # Nustatykite savo API raktus & tiekėjas
openamer model        # Pasirinkite modelį.
openamer update       # Atnaujinti iki paskutiniųjų versijų.
```

## Atnaujinimas

Atsisiuntinėja OpenAmer automatiškai ir rodo pranešimą apie atnaujinimą welcome banner. Atlikite komandą `openamer update` siekite naujausios versijos, ji pirmiausia išsaugo savo duomenis.

## Sukauptis

Prisidėjimai sveiki! — atidarytos uždavinys, paskyrai siuntos, ar prisijunkite prie bendruomenės.
