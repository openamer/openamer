# OpenAmer Agent

**Agent laj pou imiliman — aprann nan eksperyans, kreye talant, rete preferans ou, e travay pou ou nan tout lò.**

**Kreyòl Ayisyen**:

Nou bezwen tradui sa a nan Kreyòl Ayisyen:

* "Use any model you want — OpenRouter, OpenAI, DeepSeek, and more. Switch with `openamer model` — no code changes."

**Tradiksyon:**

Nou bezwen chwazi yon model ki ou vle — OpenRouter, OpenAI, DeepSeek, ak plis. Chwazi avèk `openamer model` — pa chanje kòd la.

## Instale rapidman

Windows (Pouèlshel)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Komen nan! (Komen nan! - Let's get started!)

```bash
openamer              # Chalè konte! (Let's chat!)
openamer setup        # Sètèlman kek klè nan API yo ak pwovayè a.
openamer model        # Chwazi yon model la
openamer update       # Kouvé a lèt la ki pi rekòmande.
```

## Mennen aktyalize

OpenAmer chache mòtèl pou mizikasyon epi montre yon warnin nan bannè ase. Kòmanse openamer mizikasyon pou konnen ki pi re. Li sevè premye ki gen dat.
