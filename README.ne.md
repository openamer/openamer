# OpenAmer Agent

**स्व-सुधार गर्ने AI एजेन्ट — अनुभवबाट सिक्नुहोस्, सीपहरू सिर्जना गर्नुहोस्, तपाईंका प्राथमिकताहरू सम्झनुहोस्, र जहाँसुकै तपाईंको लागि काम गर्नुहोस्।**

तपाईंले चाहेको कुनै पनि मोडेल प्रयोग गर्नुहोस् — OpenRouter, OpenAI, DeepSeek, र अन्य। `openamer model` प्रयोग गरेर परिवर्तन गर्नुहोस् — कुनै कोड परिवर्तन गर्नु पर्दैन।

## विशेषताहरू

- **वास्तविक टर्मिनल इन्टरफेस — अटो-कम्प्लिट, हिस्ट्री, र स्ट्रिमिङ टुल आउटपुट सहितको पूर्ण TUI**
- **तपाईं जहाँ हुनुहुन्छ, त्यहीँ उपलब्ध — Telegram, Discord, Slack, WhatsApp र अन्य धेरै, एउटै गेटवेबाट**
- **समयसँगै सिक्छ — स्मृति, आत्म-सुधार गर्ने सीपहरू, र विभिन्न सत्रहरू बीचको स्मरण क्षमता**
- **प्रतिनिधित्व र समानान्तरिकरण गर्दछ — समानान्तर कार्यका लागि उप-एजेन्टहरू (subagents) सिर्जना गर्दछ**
- **निर्धारित अटोमेसनहरू — दैनिक रिपोर्ट, ब्याकअप र अडिटका लागि बिल्ट-इन cron**
- **जहाँ पनि चल्छ — लोकल, Docker, SSH, क्लाउड, सर्भरलेस**

## छिटो जडान (Quick Install)

विन्डोज (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

लिनक्स (Linux) / म्याक ओएस (macOS):
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## सुरुवात गर्दै

```bash
openamer              # कुराकानी सुरु गर्नुहोस्
openamer setup        # तपाईंको API keys र provider सेटअप गर्नुहोस्
openamer model        # तपाईंको मोडेल छान्नुहोस्
openamer update       # नवीनतम संस्करणमा अपडेट गर्नुहोस्
```

## अपडेट गर्दै

OpenAmer ले स्वचालित रूपमा अपडेटहरू जाँच गर्छ र स्वागत ब्यानरमा चेतावनी देखाउँछ। नवीनतम संस्करण प्राप्त गर्न `openamer update` चलाउनुहोस् — यसले पहिले तपाईंको डाटा ब्याकअप गर्दछ।
