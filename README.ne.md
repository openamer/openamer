## स्थिर स्थापना

विंडोज (पावरशेल)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

लिनक्स / मैकओएस:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## प्रारम्भ गर्नु

```bash
openamer              # चालू भइरहेको
openamer setup        # API को सेट अप गर्नुहोली | API को स्थिति
openamer model        # चयन गर्नुहोस
openamer update       # अपडेट करे प्राथमिक संस्करणमा संगति गरि नवीनतम संस्करणमा पार्नुहोस्।
```

## अपडेट कर्दै

अनलाइन हेरचेक करतै आफ्नो अपडेट र स्वागत ब्यानरमा चेतावनी देखाउँछ । **openamer update** चलाउँदा आफ्नो डेटा सुरक्षित गरी नवीनतम संस्करण प्राप्त गर्नुहोस ।
