# OpenAmer Agent

**자기 개선 가능한 AI 에이전트 — 경험에서 배움, 기술을 만들기, 선호하는 것을 기억하고, 어디에서나 당신을 위해 일합니다.**

**OpenRouter**

## **기능**

- ****실시간 터미널 인터페이스** — 완전한 TUI(텍스트 사용자 인터페이스)로 자동 완성, 기록, 스트리밍 도구 출력이 가능합니다.**
- **하나의 게이트웨이를 통해 Telegram, Discord, Slack, WhatsApp 및 더 많은 곳에서 살고 있습니다.**
- **시간이 지날수록 학습 — 메모리, 자체 개선된 기술, 세션 간의 회상**
- **델리게이트 & 병렬화 — 서브 에이전트를 병렬 작업을 위해 스폰합니다**
- **일정 자동화 — 내장된 크론을 사용한 일일 보고서, 백업, 감사**
- **어디서든 작동합니다 — 로컬, Docker, SSH, 클라우드, 서버리스**

## 빠른 설치

윈도우즈 (PowerShell)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

리눅스 / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## 시작하기

```bash
openamer              # **대화 시작**
openamer setup        # API 키 및 제공자 설정
openamer model        # **한국어**
openamer update       # 최신 버전으로 업데이트 하세요.
```

## 업데이트 중입니다.

OpenAmer은 자동으로 업데이트를 확인하고 환영 배너에 경고를 표시합니다. 최신 버전을 받기 위해 `openamer update`를 실행하세요 — 데이터 백업이 먼저 이루어집니다.

## **Contributing**
===============

**Getting Started**
---------------

### 1. Fork the repository

*   [GitHub](https://github.com/your/repository)에서 fork를 클릭합니다.
*   로컬에 fork한 repository를 clone합니다.

### 2. Branching

*   `git checkout -b <branch-name>` 명령어를 사용하여 새로운 branch를 생성합니다.
*   `git branch` 명령어를 사용하여 현재 branch를 확인합니다.

### 3. Commit

*   `git add <file>` 명령어를 사용하여 변경한 파일을 stage합니다.
*   `git commit -m "<commit message>"` 명령어를 사용하여 커밋합니다.

### 4. Push

*   `git push origin <branch-name>` 명령어를 사용하여 원격 저장소에 push합니다.

### 5. Pull Request

*   fork한 repository에 push한 후, [GitHub](https://github.com/your/repository)에서 pull request를 생성합니다.
*   pull request를 review하고, merge합니다.
