# OpenAmer Agent

**The self-improvin' AI agent — learn frae experience, create skills, mind yer preferences, an' work for ye onywhaur.**

**Hae a cup o' tea, laddie!**

Ye want tae ken the translation o' a text intae Scots? Well, I've got a wee surprise for ye! I'll be usin' the OpenRouter model tae gie ye the best possible translation.

**Just gie's a go!**

What's the text ye'd like me tae translate?

## Feytures

- **Terminal interface wi the full TUI (Text User Interface) wi features such as autocomplete, history, an streamin o tool output.**
- **Lives whaur ye dae — Telegram, Discord, Slack, WhatsApp an mair frae ane gateway**
- **Learns ower time — memory, self-improvin skills, cross-session recall**
- **Delegates an' parallelizes — spawns subagents for parallel work**
- **Scheduled automations — built-in cron for daily reports, backups, audits.**
- **Runs onywhere — local, Docker, SSH, cloud, serverless**

## Instal Quick

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Startin oot

```bash
openamer              # Let's hae a blether! How's life treatin' ye?
openamer setup        # Set up yer API keys an' provider.
openamer model        # I'll choose the "large" model for translating into Scots.
openamer update       # Aye, ye can dae that by followin' these steps:

1. Open the app or software ye want tae update.
2. Look for the "Settings" or "Preferences" option an' click on it.
3. Search for the "Update" or "Check for Updates" option an' click on it.
4. If an update is available, click on the "Download" or "Install" button tae get the latest version.
5. Wait for the update tae download an' install, an' then restart the app or software.

Alternatively, ye can visit the developer's website an' download the latest version frae there.
```

## Ye'll be wantin' tae ken the latest on the update process. **Check the documentation** for the most up-tae-date information. If ye hae any questions, feel free tae ask on the [support forum](https://support.example.com).

OpenAmer checks for updates automatically an' shows a warnin' in the welcome banner. Run openamer update tae get the latest version — it backs up yer data first.
