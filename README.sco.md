# OpenAmer Agent

**The self-improvin AI agent — learn frae experience, mak skills, mind yer preferences, an work for ye onywhaur.**

Use ony model ye fancy — OpenRouter, OpenAI, DeepSeek, an mair. Switch wi' `openamer model` — nae code changes.

## Featurs

- **Rael terminal interface — fuill TUI wi' autocomplete, history, an streaming tool ootpit**
- **Bides whaur ye dae — Telegram, Discord, Slack, WhatsApp an mair frae wan gateway**
- **Learns ower time — memory, self-improvin skills, cross-session recall**
- **Delegates & parallelizes — spawn sub-agents for parallel wark**
- **Scheduled automations — built-in cron for daily reports, backups, audits**
- **Runs onywhaur — local, Docker, SSH, cloud, serverless**

## Quicken Install

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Gettin started

```bash
openamer              # Start bletherin
openamer setup        # Set up yer API keys & provider
openamer model        # Pick yer model
openamer update       # Update tae the latest version
```

## Updatin

OpenAmer checks for updates automatically an' shows a warnin' in the welcome banner. Run openamer update tae get the latest version — it backs up yer data first.
