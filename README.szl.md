# OpenAmer Agent

**Śmiyntny AI agent - nauczy se z doświadczyń, stwórz umiejętności, pamietaj Twoje preferencje, a robijaj dla Ciebie w każym miejscu.**

Ślōnskŏ gŏdka:

Śełamy używać dowolny model, jak np. OpenRouter, OpenAI, DeepSeek itp.

## Funkcje

- **Ścieńkowŏ terminalowŏ powierzchniŏ — pełny TUI z autocompletą, historią, a wyjścia z narzędziom streamującymi.**
- **Żyjesz tam, gdzie ty — Telegram, Discord, Slack, WhatsApp i wiele inkszych z jednego bramki.**
- **Naukaŏ sie w czasie — pamĕć, samodzielne umiejętności, przypomnienie między sesjami**
- **Dyplōmaty & paralelizujō — wyrōzniyajō poddzielōncych agentōw do paralelnego praczōwaniŏ**
- **Automatyzowane zadań - wbudowany cron dla dziennych raportōw, kopii bezpieczeństwa, audytōw**
- **Światło się świeci, w każdej scyni - lokalnie, w Dockerze, przez SSH, w chmurze, bezserwerowo**

## Rozpoczęcie

```bash
openamer              # Rozpoczęć rozmowę
openamer setup        # Nastawaće klawisze API a dostawcōw
openamer model        # Wybierz model
openamer update       # **Aktualizuj do najnowszego wersji**
```

## Aktualizujōc

Otwōrz OpenAmer a sam sprawia, że szukŏ aktualizacyjōm automatycznie a pokazuje przestrogi w banerze powitalnym. Uruchom polecenie openamer update, by dostać najnowszōm wersjōm - zawsze zabezpiecza dane.
