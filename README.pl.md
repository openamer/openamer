# OpenAmer Agent

**Agent samonaprawiający się — ucz się z doświadczenia, twórz umiejętności, zapamiętaj swoje preferencje, i pracuj dla ciebie w dowolnym miejscu.**

**Tłumaczenie:** 

Użyj dowolnego modelu - OpenRouter, OpenAI, DeepSeek, itp. Zamiana na `openamer model` - żadne zmiany w kodzie.

## **Opcje**

- ****Interaktywny terminal** — pełny **TUI** z **autocompletem**, **historią** i **streamingiem** wyjścia narzędzi**
- **Żyjesz tam, gdzie mieszkasz - Telegram, Discord, Slack, WhatsApp i wiele innych z jednego bramy.**
- **Nauczy się w czasie — pamięć, samodzielnie doskonalące umiejętności, przypominanie z sesji do sesji**
- **Deleguje & równoleglezuje — uruchamia podagentów do pracy równoległej**
- **Zarządzanie automatyzacjami — wbudowany cron dla codziennych raportów, kopii zapasowych, audytów**
- **Uruchamia się w każdym miejscu — lokalnie, w kontenerze Docker, za pomocą SSH, w chmurze, bezserwerowo**

## Szybkie Zainstalowanie

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Rozpoczęcie

```bash
openamer              # Rozpocznij rozmowę.
openamer setup        # Ustaw swoje klucze API & dostawców.
openamer model        # Wybierz swój model.
openamer update       # Aktualizuj do najnowszej wersji.
```

## Aktualizacja

OpenAmer sprawdza automatycznie aktualizacje i wyświetla ostrzeżenie w banerze powitalnym. Uruchom polecenie openamer update, aby pobrać najnowszą wersję — zapisuje dane przed aktualizacją.
