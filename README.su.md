## Fitur-fitur

- **Terminal Interaktif Asli — TUI Purna Wujudan Dengan Autocomplete, Sejarah, sarta Output Aliran**
- **Aya di tempat kamu — Telegram, Discord, Slack, WhatsApp jeung salila ngeunaan gateway**
- **Manggala ngaliwetan dina — kawasanan, kawasanan nu ngaliwetan, pangawasan nu kawasanan di antaréngan**
- **Delegasi jeung parallelisasi — ngabentuk subagen pikeun ngalaksanakeun kerja paralel**
- **Automatisasi jadwal — cron bawaan untuk laporan harian, cadangan, audit**
- **Tiasa dilaksanakeun di mana-mana — lokal, Docker, SSH, awan, tanpa server.**

## Tutumpukna Instalasi

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Kurang tiasa ngadahay

```bash
openamer              # Ngobrol aya! (Let's chat!)
openamer setup        # Tetep, nganuhur **API** kunci jeung **provider**
openamer model        # Pilih modelmu
openamer update       # **Update ke versi terbaru**
```

## Manggala

OpenAmer nganjangkeun update otomatis jeung ngabogaan peringatan dina banner selamat datang. Jalankan openamer update pikeun ngaraikeun versi anyar — sabalik data anjeun dulu.
