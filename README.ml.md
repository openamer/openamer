# OpenAmer Agent

**സ്വയം മെച്ചപ്പെടുന്ന ഐ ഏജന്റ് — അനുഭവം നിന്ന് പഠിക്കുക, നൈപുണ്യം സൃഷ്ടിക്കുക, നിങ്ങളുടെ ആഗ്രഹങ്ങൾ ഓർമ്മിക്കുക, നിങ്ങളുടെ സേവനത്തിനായി എല്ലായിടത്തും പ്രവർത്തിക്കുക.**

ഒരു പ്രൊഫഷണൽ വിവരണക്കാരനായിരിക്കുക. മലയാളത്തിലേക്ക് മാറ്റുക (നാട്ടിൽ: മലയാളം). ഇന്ലൈൻ മാർക്ഡൗൺ ( **, ലിങ്ക് വിഴ്ച് ടെക്സ്റ്റ്) സംരക്ഷിക്കുക, കമാൻഡ്‌സ്/യുആർഎൽ‌സ് വെറും വിട്ടുകളിൽ വയ്ക്കുക. മാത്രം മനോരഥം കുറിപ്പ്/ഫോർസ് മാറ്റുക.

## സവിശേഷതകൾ

- **ആസൂത്രണ പരിപാടി — പൂർണ്ണ ടിയുഐ ഉണ്ടായിരിക്കുന്ന ആട്ടോകമ്പ്ലീറ്റ്, ചരിത്രം, സ്ട്രീമിംഗ് ടൂൾ പുറപ്പെടുപ്പിക്കൽ.**
- **നിങ്ങളുടെ സ്ഥലത്തുതന്നെ ജീവിക്കുന്നു - ടെലഗ്രാം, ഡിസ്കോർഡ്, സ്ലാക്ക്, വ്യാപാരം എന്നിവയുടെ ഒരു ഗേറ്റ്വേ മുതൽ**
- **കാലാനുസൃതമായി പഠിക്കുന്നു — ഓർമ്മകൾ, സ്വയം മെച്ചപ്പെടുന്ന നൈപുണ്യം, സെഷനുകളുടെ തിരിച്ചെടുത്തൽ**
- **ഡെലിഗേറ്റുകൾ & പാരലൽ ചെയ്യുന്നു — പാരലൽ പ്രവർത്തനത്തിനായി സബ്‌ജെന്റുകൾ സ്പോൺ**
- **സൂചിത ഓട്ടോമേഷനുകൾ — ഡേലി റിപ്പോർട്ടുകൾ, ബാക്കപ്പുകൾ, അഡിറ്റുകൾക്കായി ഇന്നേറ്റഡ് ക്രോൺ**
- **ഏതിലും പ്രവർത്തിക്കുന്നു — ലോകൽ, ഡോക്കർ, SSH, ക്ലൗഡ്, സേവര്‍ലെസ്**

## വേഗ സ്ഥാപനം

വിൻഡോസ് (പൗവർഷെൽ)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

ലിനക്സ് / മാക്ഒഎസ്
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## ആരംഭിക്കുക

```bash
openamer              # ആരംഭിക്കാം ചർച്ച
openamer setup        # നിർദ്ദേശിക്കാത്ത കീ
openamer model        # എന്റെ മോഡൽ തിരഞ്ഞെടുക്കുക: **വിവരണരഹിത മാതൃക**
openamer update       # പുതുക്കിയെടുക്കുക ലെയ്റ്റസ്റ്റ് വേർഷനിലേക്ക്
```

## പുതുക്കൽ

ഓപ്പൺ അമേഴ്സ് ആപ്ലിക്കേഷൻ പുതുക്കിയത് ആവശ്യമാണെങ്കിൽ അത് തന്നെ ആത്യന്തികമായി പരിശോധിക്കുന്നു. ഓപ്പൺ അമേഴ്സ് പിന്തുണ പതിപ്പ് നേടുന്നതിന് ഓപ്പൺ അമേഴ്സ് പിന്തുണ ചെയ്യുക എന്ന് ക്ലയന്റ് ബാനറിൽ ഓപ്പൺ അമേഴ്സ് വാർനിംഗ് കാണിക്കുന്നു. ഡാറ്റ ബാക്കപ്പ് ചെയ്ത് എടുക്ക

## സഹകരണം

അനുകൂലനങ്ങൾ സ്വീകരിക്കാം — തൊട്ടുകൂടിയ അടച്ചില്ലാത്ത പ്രവർത്തകരുടെ പ്രവർത്തനങ്ങൾ സമർപ്പിക്കുക, അനുകൂലനങ്ങൾ തൊട്ടുകൂടിയിരിക്കുന്ന സമൂഹത്തിൽ ചേരുക.
