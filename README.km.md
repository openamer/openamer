# OpenAmer Agent

**អ្នកបណ្តុះបណ្តាលអ្នកបណ្តុះបណ្តាលបណ្តុះបណ្តាលដែលផ្លាស់ប្តូរខ្លួនព្រមទាំងបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលដែលបណ្តុះបណ្តាលបណ្តុះបណ្តាលដែលបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលដែលបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលបណ្តុះបណ្តាលប**

បន្ទាប់ពីការប្រឡូកទៅលើម៉ូដអូប៉េនអាយី បានបានបង្កើតបានដោយសារការប្រើប្រាស់វិធីសារផ្លូវការរបស់ខ្លួនដើម្បីបង្កើតរូបរាងដ៏សំខាន់ៗនៃប្រព័ន្ធវិទ្យាសាស្ត្រដែលមានប្រភពពីរដ្ឋបាលនៅក្នុងប្រទេសចិននិងប្រទេសអាមេរិក ដែលមានប្រភពពីសង្គមសាស្ត្រាចារ្យបុរាណសាស្ត្រនិងបុរាណវត្ថ

## ប្រភពទំនាក់ទំនាយ

ប្រភពផ្លូវការ: [Features (software)](https://en.wikipedia.org/wiki/Features_(software))

- **វេទិការជួរដែលពិតប្រាកដ — វេទិការជួរដែលមានប្រព័ន្ធបង្ហាញពិតប្រាកដជាមួយការបង្ហាញពិតប្រាកដ, ប្រវត្តិសាស្ត្រះនិងការបង្ហាញពិតប្រាកដនៃវិធីបង្ហាញពិតប្រាកដ**
- **បងបំរើងដូចមិនគួរស្រុកស្រើងដល់កូនសុខស្រីដែលរស់នៅក្នុងទូរស252ទាំងពួកសាមគ្គីនៅក្នុង Telegram, Discord, Slack, WhatsApp និងទូរស័ក្ដិផ្សេងទាំងពួកសាមគ្គីចំនួនពួកសាមគ្គីមួយកូនស្រុកស្រើងដល់កូនសុខស្រីដែលរស់នៅក្នុង Telegram, Discord, Slack, WhatsApp និងទូរស័ក្ដិផ្សេងទាំងពួកសាមគ្គីចំនួនពួកសាមគ្គីមួយក**
- **សម្គាលប្រពៃណីពេលវេវេះ — សមត់កាយបន្ទាប់ពេលវេវេះ, សមត៵សមត់បន្ទាប់ពេលវេវេះ, សមត់សម្គាលប្រពៃណីបន្ទាប់ពេលវេវេ៼**
- **បញ្ចិញនិងផ្ទាល់ជួសផ្តល់ជីវចុងផ្លូវសមកនិងផ្ទាល់ជួសផ្តល់ជីវចុងផ្លូវ**
- **ការសំរាប់បន្ថែមដែរ — ក្រុងដែរសមសពសមសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពសពស**
- **អាចដើរបានពីលើការប្រើប្រាស់ទាំងស្រុង ឬការប្រើប្រាស់ដែលត្រូវបានដោះលើកដែលបានតភ្ជាប់ទៅកាន់ Docker, SSH, បណ្តាញខ្លះ, ការដោះលើកដែលមិនមានការពារសម្រាប់**

## ការដកដកបន្ថែម

សម្រាប់គុកវិញដ៍ (PowerShell):


## កែប្រវះកែប្រឡាយ

បើបានបង្កើតបានបង្កើត OpenAmer វាក៏បានបង្កើតការពិនិត្យបន្ថែមទៀតបានដោយខ្លួនឯងផងដែរ ហើយបង្ហាញការសម្រេចចិត្តនៅក្នុងបាវចនាសញ្ញាស្វាគមន៍។ ដើរការបង្កើត openamer update ដើម្បីទទួលបានការផ្គត់ផ្គង់ដែលថ្មីបំផុត — វាក៏បានរក្សាទិន្នន័យរបស់អ្នកប្រើប្រាស់ទាំងមូលផងដែរ។

## ការចូលរួម

ចូលរួមការបញ្ចូលគម្រោង — បញ្ជីបញ្ហាកើតឡើង ចូលបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជីបញ្ជី
