# OpenAmer Agent

**ភ្នាក់ងារ AI ដែលកែលម្អខ្លួនឯង — រៀនពីបទពិសោធន៍, បង្កើតជំនាញ, ចងចាំចំណូលចិត្តរបស់អ្នក និងធ្វើការឱ្យអ្នកនៅគ្រប់ទីកន្លែង។**

ប្រើប្រាស់ម៉ូដែលណាមួយដែលអ្នកចង់បាន — OpenRouter, OpenAI, DeepSeek និងម៉ូដែលផ្សេងៗទៀត។ ប្តូរដោយប្រើ `openamer model` — ដោយមិនចាំបាច់ផ្លាស់ប្តូរកូដ។

## លក្ខណៈពិសេសៗ

- **ចំណុចប្រទាក់ Terminal ពិតប្រាកដ — TUI ពេញលេញដែលមាន autocomplete, ប្រវត្តិ (history), និងការបង្ហាញលទ្ធផលឧបករណ៍តាមរយៈ streaming**
- **មានវត្តមាននៅគ្រប់ទីកន្លែងដែលអ្នកប្រើប្រាស់ — Telegram, Discord, Slack, WhatsApp និងកម្មវិធីផ្សេងៗទៀត តាមរយៈច្រកចេញចូលតែមួយ**
- **រៀនសូត្រតាមពេលវេលា — ការចងចាំ, ជំនាញកែលម្អខ្លួនឯង, ការរំលឹកឡើងវិញឆ្លង session**
- **ប្រគល់ភារកិច្ច និងដំណើរការជាស្របគ្នា — បង្កើត subagents សម្រាប់ការងារស្របគ្នា**
- **ស្វ័យប្រវត្តិកម្មដែលបានកំណត់ពេល — cron ក្នុងប្រព័ន្ធសម្រាប់របាយការណ៍ប្រចាំថ្ងៃ ការចម្លងទុក (backups) និងការធ្វើសវនកម្ម (audits)**
- **ដំណើរការបានគ្រប់ទីកន្លែង — ក្នុងម៉ាស៊ីនផ្ទាល់ (local), Docker, SSH, cloud, serverless**

## ការដំឡើងរហ័ស

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## ការចាប់ផ្ដើមដំបូង

```bash
openamer              # ចាប់ផ្តើមជជែកគ្នា
openamer setup        # រៀបចំ API keys និងអ្នកផ្តល់សេវាកម្ម (provider) របស់អ្នក
openamer model        # ជ្រើសរើសម៉ូដែលរបស់អ្នក
openamer update       # ធ្វើបច្ចុប្បន្នភាពទៅកាន់កំណែចុងក្រោយបំផុត
```

## កំពុងធ្វើបច្ចុប្បន្នភាព

OpenAmer ត្រួតពិនិត្យមើលការធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិ និងបង្ហាញការព្រមាននៅក្នុងបដាស្វាគមន៍។ សូមដំណើរការ `openamer update` ដើម្បីទទួលបានកំណែចុងក្រោយបំផុត — វាជួយចម្លងទុកទិន្នន័យរបស់អ្នកជាមុនសិន។
