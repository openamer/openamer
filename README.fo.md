# OpenAmer Agent

**Sjálvbetrandi AI-agenturin — lær av royndum, skapa abil, minnist tínarn ynskju og arbeið fyri teg hvar sum helst.**

Brúka hvar sum helst tú vilt — OpenRouter, OpenAI, DeepSeek, og fleiri. Skifta við `openamer model` — eingin broytingar í kódanum.

## Eigenskapir

- **Veruligt terminal-viðmót — fullt TUI við sjálvvirðari fullendingar, søgu og streymandi útgávu frá tólum**
- **Búr í tíðnum rúmum — Telegram, Discord, Slack, WhatsApp og fleiri frá einum einasta gáttari**
- **Lærir viðtíðini — minni, sjálvbetrandi førleikar, minni millisessiónir**
- **Delegereur & paralleliserað — skapar undiragentar til parallellt arbeiði**
- **Skemaðar automatiseringar — innbyggd cron til dagligar frágreiðingar, tryggingar og eftirlit**
- **Koyrist allsaraðir staðir — lokalt, Docker, SSH, skýið, serverless**

## Snaðstovningur

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Kom gjógv

```bash
openamer              # Byrja at prata
openamer setup        # Stilla API-lyklarnar og providerin upp
openamer model        # Vel til Panasonic-modellu sína
openamer update       # Uppðati til nýggjastu útgávuna
```

## Uppdatering

OpenAmer leitar sjálvvirkt eftir uppdateringum og vísir ein ávaring í welcome-bannerinum. Keyr `openamer update` fyri at fáa nýgastu útgávuna — tað tekur ein backup av tínum dátum fyrst.
