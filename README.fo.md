## Snarri Útvísingur

Vindur (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Fyri at byrja

```bash
openamer              # Hvaða tíð eru tú?
openamer setup        # Stovnaðu ykkar API-leydar og leygdir.
openamer model        # Velkomin! (Welcome!)
openamer update       # Fyri síðan uppdateringum
```

## Teytandi

OpenAmer røyrir sjálvstøttandi umsjónir og vívarar varnarísku í velkominabrétti. Trygg OpenAmer update til at fáa síttuversión — tað varðar fyrstuferða døma.
