## በማክሰል ለአስፈልግሽን

የአማን ባልስ (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

አላስኩስ / ማካስ:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## በቅንብል

```bash
openamer              # እንዳን እንዳን እንዳን
openamer setup        # አስተውልግም አንድንትር አንተርንትር አስተውልግም
openamer model        # እንዳላይን አማርኛ ትርጉትን ለማግግን እንዴት
openamer update       # እንዴት አገናሎት
```
