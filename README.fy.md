# OpenAmer Agent

**De selsferbetterjende AI-agent — lear út ûnderfaring, meitsje vaardichheden, onthou dyn foarkeures en wurkje foar dy oeral.**

Brûk it model dat jo mar wolle — OpenRouter, OpenAI, DeepSeek, en mear. Witskje mei `openamer model` — gjin feroarings yn de koade.

## Kenmerken

- **Wierlike terminal-ynterface — folledige TUI mei autocomplete, skiednis en streaming tool-útput**
- **Libbet dêr’tst dy ek befinnet — Telegram, Discord, Slack, WhatsApp en mear fan ien gateway ôf**
- **Learet mei de tiid — ge 기억, selsferbetterjende vaardichheden, herinnering oer sesjes hinne**
- **Delegearret & paralleliseart — spawn sub-agenten foar parallel plak**
- **Plande automatisearings — ynboude cron foar dejlikse rapporten, backups, audits**
- **Rint oeral — lokal, Docker, SSH, cloud, serverless**

## Snelle ynstallaasje

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Beginje

```bash
openamer              # Begin mei chatten
openamer setup        # Stel dyn API-kaays & provider yn
openamer model        # Kies dyn model
openamer update       # Update nei de lêste ferzje
```

## Kridere

OpenAmer kontrolearret automatysk op updates en toant in waarskôging yn de welcome-banner. Ryn `openamer update` om de lêste ferzje te kriegen — it makket earst in backup fan dyn gegevens.
