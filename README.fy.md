```powershell

```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## It begjint mei yn it meitsjen fan in nije taalsetting.

```bash
openamer              # Sokkele mei me! (Let's chat!)
openamer setup        # Setje de API-sleutels en provider op.
openamer model        # Saw ik de keuze fan 'e model.
openamer update       # **Nije weromkeare nei de lêste ferzje**
```

## Ita lêst ite bylden op de lêste stân.

OpenAmer sjocht automatysk updates oan en toant in it de banner fan welkome. Rinn openamer update om de lêste ferzje te krijen – it makket earst in backup fan it data.
