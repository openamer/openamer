# OpenAmer Agent

**De zelfverbeterende AI-agent — leer van de ervaring, creëer vaardigheden, herinner je voorkeuren en werk voor je overal.**

Ik ben klaar om te vertalen. Wat wil je vertaald hebben?

## Kenmerken

- **Echte terminal interface — volledige TUI met autocompleter, geschiedenis en streamen van tooloutput**
- **Leef waar je bent — Telegram, Discord, Slack, WhatsApp en meer vanuit één poort**
- **Lerend over tijd — geheugen, zelfverbeterende vaardigheden, herinneringen over sessies heen**
- **Delegaten & paralleliseert — start subagents voor parallel werk**
- **Geplande automatiseringen — ingebouwde cron voor dagelijkse rapporten, backups, audits**
- **Werkt overal — lokaal, Docker, SSH, cloud, serverless**

## Snel installeren

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Aan de slag

```bash
openamer              # Beginnen met praten
openamer setup        # Stel uw API-sleutels & provider in.
openamer model        # Ik heb verschillende vertaalmodellen beschikbaar. Kies een van onderstaande opties:

* **Neural**: Gebruik van een neuraltaalmodel voor een meer natuurlijke vertaling.
* **Rule-based**: Gebruik van regelgebaseerde vertaaltechnologie voor een meer traditionele vertaling.
* **SMT (Statistische Machinevertaling)**: Gebruik van statistische machinevertaling voor een vertaling die gebaseerd is op statistische patronen in de teksten.

Kies je model:
openamer update       # Updaten naar de meest recente versie
```

## Updaten

OpenAmer controleert automatisch op updates en laat een waarschuwing zien in de welkomstbalk. Voer openamer update uit om de meest recente versie te installeren — het slaat eerst je gegevens op.
