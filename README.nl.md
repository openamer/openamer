# OpenAmer Agent

**De zelfverbeterende AI-agent — leer van ervaringen, creëer vaardigheden, onthoud je voorkeuren en werk voor jou, overal.**

Gebruik elk model dat je wilt — OpenRouter, OpenAI, DeepSeek en meer. Schakel over met `openamer model` — zonder codeaanpassingen.

## Kenmerken

- **Echte terminalinterface — volledige TUI met autocomplete, geschiedenis en streaming tool-output**
- **Leeft waar jij dat doet — Telegram, Discord, Slack, WhatsApp en meer vanuit één gateway**
- **Leert na verloop van tijd — geheugen, zelfverbeterende vaardigheden, recall over sessies heen**
- **Delegeert & paralleliseert — start subagenten op voor parallel werk**
- **Geplande automatiseringen — ingebouwde cron voor dagelijkse rapporten, back-ups, audits**
- **Werkt overal — lokaal, Docker, SSH, cloud, serverless**

## Snelle installatie

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Aan de slag

```bash
openamer              # Beginnen met chatten
openamer setup        # Stel je API-sleutels & provider in
openamer model        # Kies uw model
openamer update       # Update naar de nieuwste versie
```

## Bijwerken

OpenAmer controleert automatisch op updates en toont een waarschuwing in de welkomstbanner. Voer `openamer update` uit om de nieuwste versie te downloaden — er wordt eerst een back-up van je gegevens gemaakt.
