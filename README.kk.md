## **Сипаттамалар**

- **Түсінікті терминал интерфейсі — толық ТУИ және автокомплект, тарихы және сағыныштың құралымы.**
- **Қалыпыңызда тұрған жерде — Telegram, Discord, Slack, WhatsApp және көптеген басқа бір gatewayден.**
- **Қалып шығу кезеңі — есеп, өзін-өзі жақсару қабілеттері, сессия аралығында есеп алу.**
- **Ағымдастырылады және параллельділеу — параллель жұмыс үшін ағымдастырылатын субагенттер.**
- **Құжаттардың күнделікті шұғылары, резервдік көшірмелері, аудиттері үшін жылжымалы автоматика.**
- **Қолдануы біркелкі — локалды, Docker, SSH, cloud, serverless.**

## Қысқа құрастыру

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Құрастыру

```bash
openamer              # Бастау шығарыңыз.
openamer setup        # Қосылымдардың API көрсеткіштерін құрайыңыз.
openamer model        # Қалаға өзгерісі
openamer update       # Қазіргі версияға жаңарту.
```

## **Құрылтайшылардың көрсеткіштері**

OpenAmer автоматтық тұрақталыққа тірек және көшірмеге көрсетілген қаржылық сақтауын көрсетеді. OpenAmerдің қазіргі нұсқасын алу үшін openamer update командасын іске қоюға төртсін, ол алдын ала деректерді сақтайды.
