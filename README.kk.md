# OpenAmer Agent

**Өзін-өзі жетілдіретін AI агенті — тәжірибеден үйрену, дағдыларды қалыптастыру, сіздің қалауларыңызды есте сақтау және сіз үшін кез келген жерде жұмыс істеу.**

Қалаған моделіңізді пайдаланыңыз — OpenRouter, OpenAI, DeepSeek және тағы басқалар. `openamer model` командасымен ауыстырыңыз — код өзгерістерінсіз.

## Ерекшеліктер

- **Нағыз терминал интерфейсі — толық TUI автотолтыру, тарих және ағынды құрал шығаруымен**
- **Сіз тұратын жерлер — Telegram, Discord, Slack, WhatsApp және тағы басқалары бір шлюзден.**
- **Уақыт өте келе үйренеді — есте сақтау, өзін-өзі жетілдіру дағдылары, сессиялар арасындағы еске түсіру**
- **Делегаттар мен параллелизация — параллель жұмыс үшін қосымша агенттерді іске қосу**
- **Жоспарланған автоматтандыру — күнделікті есептер, резервтік көшірмелер, аудиттер үшін кірістірілген cron**
- **Кез келген жерде жұмыс істейді — локалдық, Docker, SSH, бұлтта, серверсіз**

## Жылдам орнату

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Бастау үшін

```bash
openamer              # Сөйлесуді бастаңыз
openamer setup        # API кілттеріңіз бен провайдеріңізді орнатыңыз
openamer model        # Модельді таңдаңыз
openamer update       # Соңғы нұсқаға жаңартыңыз
```

## Жаңарту

OpenAmer жаңартуларды автоматты түрде тексереді және қош келдіңіз баннерінде ескерту көрсетеді. Соңғы нұсқасын алу үшін openamer update командасын іске қосыңыз — ол алдымен деректеріңізді резервтік көшірмесін жасайды.

## Қатысу

Қосымшаларға қош келдіңіз — ашық мәселелер, пул сұрауларын жіберу немесе қауымдастыққа қосылу.
