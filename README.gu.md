# OpenAmer Agent

**આત્મ-સુધારક એઆઈ એજન્ટ - અનુભવોથી શીખો, કુશળતા બનાવો, તમારી પસંદગીઓને યાદ રાખો, અને તમારા માટે કામ કરો ક્યાંય.**

**ગુજરાતી અનુવાદક**


ગુજરાતી અનુવાદક તમામ પ્રકારના ભાષાઓને ગુજરાતીમાં અનુવાદ કરે છે. તે તમામ પ્રકારના માહિતી અને પ્રક્રિયાઓ માટે તૈયાર છે, જેમ કે:


તમામ પ્રકારના ભાષાઓનો અનુવાદ કરો
અનુવાદ કરો તમામ પ્રકારના માહિતી અને પ્રક્રિયાઓ
તમામ પ્રકારન

## ફેચર્સ

- **રિયલ ટર્મિનલ ઇન્ટરફેસ — પૂર્ણ TUI સાથે અટોકોમેટિક સાર્વજનિક, ઇતિહાસ, અને સ્ટ્રીમિંગ ટૂલ આઉટપુટ**
- **તમારી જેમ જ તમે જ્યાં રહો છો ત્યાં તમે ટેલેગ્રામ, ડિસ્કોર્ડ, સ્લેક અને વ્હાટ્સાપ જેવી વધુ સેવાઓને એક જ ગેટવે થી જોડાશો**
- **સમયથી શીખે છે — સંજોગ, આત્મ-સુધારક કુશળતા, ક્રોસ-સેશન સંબંધિત સમાધાન**
- **નિયામકો અને સમાંતર કાર્યોને સ્પર્શિત કરે છે — સમાંતર કાર્યો માટે ઉપાધિકારી એજન્ટ્સ સ્પર્શિત કરે છે**
- **સ્કેચ્યુલેટેડ એક્ઝેક્યુટિયન્સ — દરરોજના રિપોર્ટ્સ, બેકઅપ્સ, અડિટ્સ**
- **કોઈ પણ સ્થળે ચાલે છે — સ્થાનિક, Docker, SSH, દૂરસ્થ અને સર્વસામાન્ય સેવા**

## સાર્વજનિક સ્થાપન

વિન્ડોઝ (પાવરશેલ)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

લિનક્સ / મેકઓએસ:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## શરૂઆત કરવા માટે

```bash
openamer              # શરૂ કરો ચાતરણી
openamer setup        # સેટ આપ તમારા API કી અને સપ્લાયર
openamer model        # મોડેલ ચૂંટો
openamer update       # આપણે તમારા સાર્વજનિક પ્રોફાઇલને સુધારવા માટે સુધારાઓ અને નવી લક્ષણો જોવા માટે આ પૃષ્ઠે જાઓ.
```

## આપડેટિંગ

ઓપનામર આટલે નવી કાર્યરૂપે જોવાય તેને સ્વયંચાલીત રીતે જોવાય છે અને સ્વાગત બેનરમાં ચેતાવણી કરવામાં આવે છે. નવી કાર્યરૂપે મળવા માટે ઓપનામર આપડેટ કરો તો તે પહેલા આપની ડેટાનું બેકઅપ કરે છે.

## સંપર્કિત

આપનું યોગદાન આવશ્યક છે — ખુલ્લી સમસ્યાઓ, પુલ અર્જન સમર્પિત કરો, અથવા સમાજ સાથે જોડાઓ.
