# OpenAmer Agent

**સ્વ-સુધારણા કરતું AI એજન્ટ — અનુભવ પરથી શીખો, કૌશલ્યો બનાવો, તમારી પસંદગીઓને યાદ રાખો, અને ગમે ત્યાં તમારા માટે કામ કરે.**

તમે કોઈપણ મોડેલનો ઉપયોગ કરી શકો છો — OpenRouter, OpenAI, DeepSeek, અને અન્ય. `openamer model` દ્વારા સ્વિચ કરો — કોડમાં કોઈ ફેરફાર કરવાની જરૂર નથી.

## વિશેષતાઓ

- **વાસ્તવિક ટર્મિનલ ઇન્ટરફેસ — ઓટોકમ્પ્લીટ, હિસ્ટ્રી અને સ્ટ્રીમિંગ ટૂલ આઉટપુટ સાથે સંપૂર્ણ TUI**
- **તમે જ્યાં રહો છો ત્યાં જ ઉપલબ્ધ — ટેલિગ્રામ, ડિસ્કોર્ડ, સ્લેક, વોટ્સએપ અને ઘણું બધું, માત્ર એક જ ગેટવે દ્વારા**
- **સમય જતાં શીખે છે — મેમરી, સ્વ-સુધારણા કૌશલ્યો, સત્રો વચ્ચેની યાદશક્તિ (cross-session recall)**
- **ડેલિગેટ્સ અને પેરેલેલાઇઝ કરે છે — સમાંતર કામ માટે સબ-એજન્ટ્સ (subagents) બનાવે છે**
- **શેડ્યૂલ કરેલી ઓટોમેશન્સ — દૈનિક રિપોર્ટ્સ, બેકઅપ્સ અને ઓડિટ્સ માટે બિલ્ટ-ઇન ક્રોન (cron)**
- **ગમે ત્યાં ચાલે છે — લોકલ, Docker, SSH, ક્લાઉડ, સર્વરલેસ**

## ઝડપી ઇન્સ્ટોલેશન

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## શરૂઆત કરવી

```bash
openamer              # ચેટિંગ શરૂ કરો
openamer setup        # તમારી API કી અને પ્રોવાઇડર સેટ કરો
openamer model        # તમારું મોડેલ પસંદ કરો
openamer update       # નવીનતમ સંસ્કરણમાં અપડેટ કરો
```

## અપડેટ કરી રહ્યું છે

OpenAmer આપમેળે અપડેટ્સ માટે તપાસ કરે છે અને વેલકમ બેનરમાં ચેતવણી દર્શાવે છે. લેટેસ્ટ વર્ઝન મેળવવા માટે `openamer update` રન કરો — તે પહેલાં તમારા ડેટાનો બેકઅપ લેશે.
