# OpenAmer Agent

**Allpa-allpachaq AI yanapaq — experienciamanta yachay, yachyniykunata ruray, munayniykunata yuyaray, hinaspa maymanpas qampaq llank'ay.**

Imayna modeltapas munaspa kanki — OpenRouter, OpenAI, DeepSeek, chaymanta wañuypas. Tukunayta `openamer model` nispa tukunayki — manan imayman kawsayta (code) cambiykuna kanchu.

## Imaymanakuna

- **Chaypiqan terminal interface — tukuy TUI autocomplete-wan, history-wan, hinaspa streaming tool output-wan**
- **Kaypi kawsan — Telegram, Discord, Slack, WhatsApp hinaspa wañuchasqa hukllapuni qichwa pampamanta**
- **Tiempo pasaypi yachakunku — yuyay, kawsayman allichaymanay, mana kutichispa yuyay**
- **Delegada kawsachinmi — suk’ay yachayniykunata rurachin parallelllapi llank'anankupaq**
- **Sapa p’unchay reportokuna, backupkuna, auditokunapaq — allichasqa automatizasyunkuna, built-in cronwan**
- **Maypichina llanka — local, Docker, SSH, cloud, serverless**

## Utqaylla Allichiy

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Qallariy

```bash
openamer              # Rimayta qallariy
openamer setup        # Sapaq API llavekunaykitapas provider-niykitaq allichay
openamer model        # Akllay qawayqayniykita
openamer update       # Kunan pachaman aktualizay
```

## Sapa kutim sutichyaspa

OpenAmer automaticallyy qhawan imayna aktualisaykuna kanchu hinaspa huk qhawachiyta rikuchin welcome bannerpi. Run `openamer update` latest versionta qhwanapaq — payqa ñawpaqta datokunata backupyachin.
