# OpenAmer Agent

وكيل ذكاء اصطناعي يحسّن نفسه، من [مشروع OpenAmer](https://openamer.com). الوكيل الوحيد بحلقة تعلّم مدمجة — ينشئ مهارات من الخبرة، ويحسّنها أثناء الاستخدام، ويدفع نفسه إلى حفظ المعرفة، ويبني نموذجًا أعمق عن من أنت عبر الجلسات.

## التثبيت

### Windows أو macOS

لتثبيت سطر الأوامر وتطبيق سطح المكتب بسهولة، [نزّل مثبّت OpenAmer Desktop](https://openamer-agent.openamer.com/) وشغّله.

### بدون OpenAmer Desktop:

لتثبيت سطر الأوامر فقط بدون OpenAmer Desktop:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://openamer-agent.openamer.com/install.sh | bash
```

#### Windows (native)

```powershell
iex (irm https://openamer-agent.openamer.com/install.ps1)
```

راجع **[دليل التثبيت](/getting-started/installation)** الكامل لمعرفة ما يفعله المثبّت، وتخطيط لكل مستخدم مقابل root، وملاحظات Windows. مصفوفة المنصات الكاملة في **[دعم المنصات](/getting-started/platform-support)**.

:::tip أسرع طريق إلى وكيل يعمل
بعد التثبيت شغّل `openamer setup --portal` — مصادقة OAuth واحدة تغطي نموذجًا وأدوات Tool Gateway الأربع (البحث على الويب، توليد الصور، TTS، المتصفح). انظر [مزوّدك المستضاف](/integrations/openamer-portal).
:::

## ما هو OpenAmer Agent؟

ليس مساعد برمجة مربوطًا ببيئة تطوير، ولا روبوت محادثة حول واجهة واحدة. إنه **وكيل مستقل** يزداد قدرة كلما طال تشغيله. يعيش حيث تضعه — خادم VPS بخمسة دولارات، أو عنقود GPU، أو بنية بلا خوادم (Daytona، Modal) تكاد لا تكلّف شيئًا عند الخمول. تحدّث معه من Telegram بينما يعمل على جهاز سحابي لا تدخله بنفسك أبدًا. غير مربوط بحاسوبك المحمول.

## أهم الميزات

- **حلقة تعلّم مغلقة** — ذاكرة يديرها الوكيل مع تنبيهات دورية، وإنشاء مهارات مستقل، وتحسين ذاتي أثناء الاستخدام، واسترجاع بين الجلسات عبر FTS5 مع تلخيص بواسطة LLM
- **يعمل في أي مكان، لا على حاسوبك فقط** — 6 خلفيات طرفية: محلي، Docker، SSH، Daytona، Singularity، Modal. تقدّم Daytona وModal استمرارية بلا خوادم: ت hibernation البيئة عند الخمول وتكاد لا تكلّف شيئًا
- **يعيش حيث تعيش** — CLI وTelegram وDiscord وSlack وWhatsApp وSignal وMatrix وMattermost والبريد وSMS وغيرها: أكثر من 20 منصة من بوابة واحدة
- **بناه مدرّبو نماذج** — طوّرته [مشروع OpenAmer](https://openamer.com). يعمل مع [مزوّدك المستضاف](https://portal.openamer.com) و[OpenRouter](https://openrouter.ai) وOpenAI أو أي نقطة نهاية
- **أتمتة مجدولة** — cron مدمج مع تسليم إلى أي منصة
- **يفوّض ويوازي** — وكلاء فرعيون معزولون لمسارات عمل متوازية؛ Programmatic Tool Calling عبر `execute_code` يختصر خطوط الأنابيب متعددة الخطوات في نداء استدلال واحد
- **مهارات بمعيار مفتوح** — متوافقة مع [agentskills.io](https://agentskills.io)؛ قابلة للنقل والمشاركة ومساهمات المجتمع
- **تحكم كامل بالويب** — البحث والاستخراج والتصفح والرؤية وتوليد الصور وTTS: اشتراك واحد يجمعها

## لنماذج LLM ووكلاء البرمجة

نقاط دخول قابلة للقراءة آليًا إلى هذا التوثيق:

- **[`/llms.txt`](/llms.txt)** — فهرس منسّق لكل صفحة مع وصف قصير. ~17 كيلوبايت، آمن للتحميل في سياق LLM.
- **[`/llms-full.txt`](/llms-full.txt)** — كل الصفحات مدمجة في ملف markdown واحد للاستيعاب دفعة واحدة. ~1.8 ميغابايت.

الملفان متاحان أيضًا على `/docs/llms.txt` و`/docs/llms-full.txt`. يُنشآن من جديد عند كل نشر.
