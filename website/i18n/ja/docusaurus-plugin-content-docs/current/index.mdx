## インストール

### Windows または macOS

コマンドラインとデスクトップアプリを簡単にインストールするには、[OpenAmer Desktop インストーラーをダウンロード](https://openamer-agent.openamer.com/)して実行してください。

### OpenAmer Desktop を使わない場合:

OpenAmer Desktop なしでコマンドラインのみをインストールするには:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://openamer-agent.openamer.com/install.sh | bash
```

#### Windows (native)

```powershell
iex (irm https://openamer-agent.openamer.com/install.ps1)
```

インストーラーの動作、ユーザーごとと root の配置、Windows 固有の注意点は **[インストールガイド](/getting-started/installation)** を参照してください。対応プラットフォームの一覧は **[プラットフォーム対応](/getting-started/platform-support)** にあります。

:::tip 動くエージェントまでの最短ルート
インストール後に `openamer setup --portal` を実行してください。1 回の OAuth でモデルと Tool Gateway の 4 ツール（ウェブ検索、画像生成、TTS、ブラウザ）がすべてまかなえます。[ホスト型プロバイダー](/integrations/openamer-portal) を参照。
:::

## OpenAmer Agent とは

IDE に縛られたコーディング副操縦士でも、単一 API を包んだチャットボットでもありません。長く動かすほど能力が上がる **自律エージェント** です。5 ドルの VPS、GPU クラスタ、アイドル時にはほぼ無料のサーバーレス基盤（Daytona、Modal）など、置いた場所で動きます。自分では SSH しないクラウド VM 上で作業している間、Telegram から話しかけられます。ノート PC に縛られません。

## 主な機能

- **閉じた学習ループ** — エージェントが管理するメモリと定期的な促し、自律的なスキル作成、使用中の自己改善、FTS5 によるセッション横断検索と LLM 要約
- **ノート PC 以外でも動く** — 6 つのターミナルバックエンド（ローカル、Docker、SSH、Daytona、Singularity、Modal）。Daytona と Modal はサーバーレス永続化で、アイドル時は休止しほぼ無料です
- **あなたのいる場所で動く** — CLI、Telegram、Discord、Slack、WhatsApp、Signal、Matrix、Mattermost、メール、SMS など、1 つのゲートウェイから 20 以上のプラットフォーム
- **モデル訓練者が開発** — [OpenAmer プロジェクト](https://openamer.com) 製。[ホスト型プロバイダー](https://portal.openamer.com)、[OpenRouter](https://openrouter.ai)、OpenAI、任意のエンドポイントで動作
- **スケジュール自動化** — どのプラットフォームにも配信できる組み込み cron
- **委任と並列化** — 並行作業用の隔離サブエージェント。`execute_code` による Programmatic Tool Calling で多段パイプラインを 1 回の推論呼び出しに圧縮
- **オープン標準スキル** — [agentskills.io](https://agentskills.io) 互換。移植可能で共有でき、コミュニティが提供
- **ウェブ完全制御** — 検索、抽出、閲覧、視覚、画像生成、TTS を 1 つのサブスクリプションに集約
