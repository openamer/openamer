## Instalação

### Windows ou macOS

Para instalar facilmente a linha de comando e o aplicativo desktop, [baixe o instalador do OpenAmer Desktop](https://github.com/openamer-max/desktop/releases/latest/download/OpenAmer-Setup.exe) e execute-o.

### Sem o OpenAmer Desktop:

Para uma instalação apenas de linha de comando, sem o OpenAmer Desktop:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

#### Windows (native)

```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Veja o **[Guia de instalação](/getting-started/installation)** completo para saber o que o instalador faz, o layout por usuário vs root e as notas específicas do Windows. A matriz completa de plataformas está em **[Suporte a plataformas](/getting-started/platform-support)**.

:::tip O caminho mais rápido para um agente funcionando
Depois de instalar, execute `openamer setup --portal`: um único OAuth cobre um modelo e as quatro ferramentas do Tool Gateway (busca web, geração de imagens, TTS, navegador). Veja [seu provedor hospedado](/integrations/openamer-portal).
:::

## O que é o OpenAmer Agent?

Não é um copiloto de código preso a uma IDE nem um chatbot em volta de uma única API. É um **agente autônomo** que fica mais capaz quanto mais tempo roda. Ele vive onde você o colocar: um VPS de 5 dólares, um cluster de GPU ou infraestrutura serverless (Daytona, Modal) que custa quase nada ociosa. Fale com ele pelo Telegram enquanto trabalha numa VM na nuvem em que você nunca entra por SSH. Ele não depende do seu notebook.

## Recursos principais

- **Ciclo de aprendizado fechado** — memória curada pelo agente com lembretes periódicos, criação autônoma de habilidades, autoaperfeiçoamento durante o uso, recuperação entre sessões com FTS5 e resumo por LLM
- **Roda em qualquer lugar, não só no seu notebook** — 6 backends de terminal: local, Docker, SSH, Daytona, Singularity, Modal. Daytona e Modal oferecem persistência serverless: seu ambiente hiberna ocioso e custa quase nada
- **Vive onde você vive** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, e-mail, SMS e mais: mais de 20 plataformas a partir de um único gateway
- **Feito por treinadores de modelos** — desenvolvido por [o projeto OpenAmer](https://openamer.com). Funciona com [seu provedor hospedado](https://portal.openamer.com), [OpenRouter](https://openrouter.ai), OpenAI ou qualquer endpoint
- **Automações agendadas** — cron integrado com entrega em qualquer plataforma
- **Delega e paraleliza** — subagentes isolados para fluxos paralelos; Programmatic Tool Calling com `execute_code` reduz pipelines de várias etapas a uma única chamada de inferência
- **Habilidades em padrão aberto** — compatível com [agentskills.io](https://agentskills.io); portáveis, compartilháveis e contribuídas pela comunidade
- **Controle web completo** — busca, extração, navegação, visão, geração de imagens, TTS: uma assinatura agrupa tudo

- **[`/llms-full.txt`](/llms-full.txt)** — todas as páginas concatenadas num único arquivo markdown para ingestão de uma vez. ~1,8 MB.

Ambos os arquivos também respondem em `/docs/llms.txt` e `/docs/llms-full.txt`. Gerados novamente a cada deploy.
