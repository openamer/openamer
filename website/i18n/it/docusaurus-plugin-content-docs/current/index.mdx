## Installazione

### Windows o macOS

Per installare facilmente la riga di comando e l'app desktop, [scarica l'installer di OpenAmer Desktop](https://github.com/openamer/openamer/releases/latest/download/OpenAmer-Setup.exe) ed eseguilo.

### Senza OpenAmer Desktop:

Per un'installazione solo da riga di comando senza OpenAmer Desktop:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

#### Windows (native)

```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Consulta la **[Guida all'installazione](/getting-started/installation)** completa per sapere cosa fa l'installer, la disposizione per utente vs root e le note specifiche di Windows. La matrice completa delle piattaforme è in **[Supporto piattaforme](/getting-started/platform-support)**.

:::tip La via più rapida a un agente funzionante
Dopo l'installazione esegui `openamer setup --portal`: un solo OAuth copre un modello e tutti e quattro gli strumenti Tool Gateway (ricerca web, generazione immagini, TTS, browser). Vedi [il tuo provider ospitato](/integrations/openamer-portal).
:::

## Che cos'è OpenAmer Agent?

Non è un copilota di codice legato a un IDE né un chatbot attorno a una singola API. È un **agente autonomo** che diventa più capace più a lungo gira. Vive dove lo metti: un VPS da 5 dollari, un cluster GPU o infrastruttura serverless (Daytona, Modal) che costa quasi nulla da inattiva. Parlaci da Telegram mentre lavora su una VM cloud in cui non entri mai tu. Non è legato al tuo portatile.

## Funzioni principali

- **Ciclo di apprendimento chiuso** — memoria curata dall'agente con richiami periodici, creazione autonoma di competenze, auto-miglioramento durante l'uso, richiamo tra sessioni con FTS5 e riassunto LLM
- **Funziona ovunque, non solo sul tuo portatile** — 6 backend di terminale: locale, Docker, SSH, Daytona, Singularity, Modal. Daytona e Modal offrono persistenza serverless: l'ambiente va in ibernazione da inattivo e costa quasi nulla
- **Vive dove vivi tu** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, email, SMS e altro: oltre 20 piattaforme da un unico gateway
- **Creato da chi addestra modelli** — sviluppato da [il progetto OpenAmer](https://openamer.com). Funziona con [il tuo provider ospitato](https://portal.openamer.com), [OpenRouter](https://openrouter.ai), OpenAI o qualsiasi endpoint
- **Automazioni pianificate** — cron integrato con consegna su qualsiasi piattaforma
- **Delega e parallelizza** — subagenti isolati per flussi paralleli; Programmatic Tool Calling con `execute_code` riduce pipeline multi-fase a una singola chiamata di inferenza
- **Competenze standard aperto** — compatibili con [agentskills.io](https://agentskills.io); portabili, condivisibili e fornite dalla community
- **Controllo web completo** — ricerca, estrazione, navigazione, visione, generazione immagini, TTS: un abbonamento raggruppa tutto

## Per LLM e agenti di codice

Punti di ingresso leggibili dalle macchine a questa documentazione:

- **[`/llms.txt`](/llms.txt)** — indice curato di ogni pagina con breve descrizione. ~17 KB, sicuro da caricare in un contesto LLM.
- **[`/llms-full.txt`](/llms-full.txt)** — tutte le pagine concatenate in un unico file markdown per l'ingestione in un colpo. ~1,8 MB.

Entrambi i file rispondono anche su `/docs/llms.txt` e `/docs/llms-full.txt`. Rigenerati a ogni deploy.
