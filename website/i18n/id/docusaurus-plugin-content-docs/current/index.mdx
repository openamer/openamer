## Instalasi

### Windows atau macOS

Untuk memasang command-line dan aplikasi desktop dengan mudah, [unduh installer OpenAmer Desktop](https://github.com/openamer/openamer/releases/latest/download/OpenAmer-Setup.exe) dan jalankan.

### Tanpa OpenAmer Desktop:

Untuk instalasi command-line saja tanpa OpenAmer Desktop:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

#### Windows (native)

```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Lihat **[Panduan Instalasi](/getting-started/installation)** lengkap untuk tahu apa yang dilakukan installer, tata letak per pengguna vs root, dan catatan khusus Windows. Matriks platform lengkap ada di **[Dukungan Platform](/getting-started/platform-support)**.

:::tip Jalur tercepat menuju agen yang berjalan
Setelah instalasi jalankan `openamer setup --portal` — satu OAuth mencakup satu model plus keempat alat Tool Gateway (pencarian web, pembuatan gambar, TTS, browser). Lihat [penyedia terkelola Anda](/integrations/openamer-portal).
:::

## Apa itu OpenAmer Agent?

Bukan kopilot koding yang terikat IDE, bukan chatbot yang membungkus satu API. Ini **agen otonom** yang makin mampu semakin lama berjalan. Ia hidup di mana pun Anda menempatkannya — VPS 5 dolar, kluster GPU, atau infrastruktur serverless (Daytona, Modal) yang hampir tanpa biaya saat menganggur. Bicaralah lewat Telegram saat ia bekerja di VM cloud yang tidak pernah Anda masuki sendiri. Ia tidak terikat laptop Anda.

## Fitur utama

- **Lingkaran pembelajaran tertutup** — memori yang dikurasi agen dengan dorongan berkala, pembuatan skill otonom, perbaikan diri saat dipakai, pengingatan antar sesi dengan FTS5 dan ringkasan LLM
- **Berjalan di mana saja, bukan hanya laptop Anda** — 6 backend terminal: lokal, Docker, SSH, Daytona, Singularity, Modal. Daytona dan Modal memberi persistensi serverless: lingkungan Anda hibernasi saat menganggur dan hampir tanpa biaya
- **Hidup di tempat Anda hidup** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, email, SMS dan lainnya: lebih dari 20 platform dari satu gateway
- **Dibuat oleh pelatih model** — dikembangkan oleh [proyek OpenAmer](https://openamer.com). Bekerja dengan [penyedia terkelola Anda](https://portal.openamer.com), [OpenRouter](https://openrouter.ai), OpenAI, atau endpoint apa pun
- **Otomasi terjadwal** — cron bawaan dengan pengiriman ke platform apa pun
- **Mendelegasikan dan memparalelkan** — subagen terisolasi untuk alur kerja paralel; Programmatic Tool Calling lewat `execute_code` memadatkan pipeline banyak langkah jadi satu panggilan inferensi
- **Skill standar terbuka** — kompatibel dengan [agentskills.io](https://agentskills.io); portabel, bisa dibagikan, dan kontribusi komunitas
- **Kendali web penuh** — pencarian, ekstraksi, penjelajahan, visi, pembuatan gambar, TTS: satu langganan mencakup semuanya
