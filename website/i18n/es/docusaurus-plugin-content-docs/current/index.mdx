# OpenAmer Agent

El agente de IA que se mejora a sí mismo, creado por [el proyecto OpenAmer](https://openamer.com). El único agente con un bucle de aprendizaje integrado: crea habilidades a partir de la experiencia, las mejora mientras las usa, se empuja a sí mismo a guardar conocimiento y construye un modelo cada vez más profundo de quién eres.

## Instalación

### Windows o macOS

Para instalar fácilmente la línea de comandos y la aplicación de escritorio, [descarga el instalador de OpenAmer Desktop](https://github.com/openamer/openamer/releases/latest/download/OpenAmer-Setup.exe) y ejecútalo.

### Sin OpenAmer Desktop:

Para una instalación solo de línea de comandos sin OpenAmer Desktop:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

#### Windows (native)

```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Consulta la **[Guía de instalación](/getting-started/installation)** completa para saber qué hace el instalador, el diseño por usuario frente a root y las notas específicas de Windows. La matriz completa de plataformas está en **[Soporte de plataformas](/getting-started/platform-support)**.

:::tip La vía más rápida a un agente funcionando
Después de instalar, ejecuta `openamer setup --portal`: un solo OAuth cubre un modelo y las cuatro herramientas de Tool Gateway (búsqueda web, generación de imágenes, TTS, navegador). Ver [tu proveedor alojado](/integrations/openamer-portal).
:::

## ¿Qué es OpenAmer Agent?

No es un copiloto de código atado a un IDE ni un chatbot envuelto alrededor de una sola API. Es un **agente autónomo** que se vuelve más capaz cuanto más tiempo funciona. Vive donde lo pongas: un VPS de 5 dólares, un clúster de GPU o infraestructura sin servidor (Daytona, Modal) que casi no cuesta nada en reposo. Habla con él por Telegram mientras trabaja en una VM en la nube a la que nunca entras por SSH. No depende de tu portátil.

## Funciones principales

- **Bucle de aprendizaje cerrado** — memoria curada por el agente con recordatorios periódicos, creación autónoma de habilidades, mejora de habilidades durante el uso, recuperación entre sesiones con FTS5 y resumen por LLM
- **Funciona en cualquier lugar, no solo en tu portátil** — 6 backends de terminal: local, Docker, SSH, Daytona, Singularity, Modal. Daytona y Modal ofrecen persistencia sin servidor: tu entorno hiberna en reposo y cuesta casi nada
- **Vive donde tú vives** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, correo, SMS y más: más de 20 plataformas desde un solo gateway
- **Creado por entrenadores de modelos** — desarrollado por [el proyecto OpenAmer](https://openamer.com). Funciona con [tu proveedor alojado](https://portal.openamer.com), [OpenRouter](https://openrouter.ai), OpenAI o cualquier endpoint
- **Automatizaciones programadas** — cron integrado con entrega a cualquier plataforma
- **Delega y paraleliza** — subagentes aislados para flujos de trabajo paralelos; Programmatic Tool Calling con `execute_code` reduce pipelines de varios pasos a una sola llamada de inferencia
- **Habilidades de estándar abierto** — compatible con [agentskills.io](https://agentskills.io); portables, compartibles y aportadas por la comunidad
- **Control web completo** — búsqueda, extracción, navegación, visión, generación de imágenes, TTS: una suscripción lo agrupa todo
