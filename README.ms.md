# OpenAmer Agent

**Agent AI yang memperbaiki diri sendiri — belajar dari pengalaman, mencipta kemahiran, ingatkan preferensi anda, dan bekerja untuk anda di mana-mana.**

Tidak dapat menemukan teks untuk diterjemahkan.

## Ciri-ciri

- **Antara pautan terminal yang sebenar — TUI penuh dengan pilihan automatik, sejarah, dan keluaran alat streaming**
- **Hidup di mana kamu tinggal — Telegram, Discord, Slack, WhatsApp dan lebih dari satu pintu masuk**
- **Belajar secara berterusan — memori, kemahiran memperbaiki diri, ingatan antiseksi**
- **Wakil-wakil & paralelkan — melancarkan subagensi untuk kerja paralel**
- **Automasi yang dijadualkan — kron dalam teras untuk laporan harian, buntu, audit**
- **Boleh digunakan di mana-mana — tempatan, Docker, SSH, awan, tanpa server**

## Pemasang Instalasi Cepat

Windows (Powershell)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Mula-Mula

```bash
openamer              # Mulakan perbincangan.
openamer setup        # Sediakan kunci API & penyedia
openamer model        # Pilih modelmu
openamer update       # Sila kemaskini ke versi terkini.
```

## Mengemaskinikan

OpenAmer memeriksa pembaruan secara automatik dan menunjukkan peringatan di banner selamat datang. Jalankan perintah openamer update untuk mendapatkan versi terbaru — ia akan menyimpan data anda terlebih dahulu.
