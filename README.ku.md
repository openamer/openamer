# OpenAmer Agent

**Ajanê AI yê ku xwe pêş dixist — ji ezmûnê hîn bibe, şarezayiyan biafirîne, tercîhên te bi bîr bîne, û li her derê ji bo te bixebite.**

Her modelekî ku tu bixwazî bikar bîne — OpenRouter, OpenAI, DeepSeek, û hîn zêdetir. Bi `openamer model` guherîne — bêyî guhertina kodê.

## Taybetmendî

- **Navbergeha rastîn a termînalê — TUI ya temam bi autocomplete, dîrok, û derxistina amûrên streaming**
- **Li wê derê dijî ku tu dijî — Telegram, Discord, Slack, WhatsApp û hîn zêdetir ji dergehekî tenê**
- **Bi borî wextê fêr dibe — bîranîn, şiyanan ku xwe pêş dixe, bîranîna navbeva rastkirinên (sessions)**
- **Delegasyon û paralelîzekirinev — ji bo xebatên paralel sub-ajan (nûnerên binav) çêdike.**
- **Otomasyonên plankirî — cron-a navxweyî ji bo raporên rojane, yedekkirin (backups) û revizyonan**
- **Li her derê dixebite — local, Docker, SSH, cloud, serverless**

## Xizmetkirina Lez/Sazkirina Lez

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Destpêkirin

```bash
openamer              # Dest bi axaftinê bike
openamer setup        # Kîleyên API û daberkarê xwe saz bike
openamer model        # Modela xwe hilbijêre
openamer update       # Nû bikeyeye vêersiyona herî dawî
```

## Nûkirin

OpenAmer bi şêweyekî otomatîk li nûhataşan digere û di banner-a pêşwazîde de hişyariyekê nîşan dide. Ji bo gihîştina herî nû, `openamer update` bimeşîne — ew berî her tiştî own dreyan (back-up) ya daneyên te digire.
