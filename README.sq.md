# OpenAmer Agent

**Agjenti i AI që përmirëson veten — mëson nga përvoja, krijon aftësi, mban mend preferencat tuaja dhe punon për ju kudo.**

Përdorni çdo model që dëshironi — OpenRouter, OpenAI, DeepSeek dhe të tjerë. Ndërroni me `openamer model` — pa ndryshime në kod.

## Karakteristikat

- **Ndërfaqe reale terminali — TUI e plotë me autocomplete, histori dhe streaming të output-it të veglave**
- **Jeton aty ku jeton ti — Telegram, Discord, Slack, WhatsApp dhe më shumë nga një gateway i vetëm**
- **Mëson me kalimin e kohës — kujtesa, aftësi vetë-përmirësuese, rikujtesa ndërmjet sesioneve**
- **Delegon dhe paralelizon — krijon nëjagjentë për punë paralele**
- **Automatizime të planifikuara — cron i integruar për raportet e përditshme, backup-et, auditimet**
- **Ekzekutohet kudo — lokalisht, Docker, SSH, cloud, serverless**

## Instalim i Shpejtë

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Fillimi

```bash
openamer              # Filloni bisedën
openamer setup        # Konfiguro çelësat e API-së & provajderin tuaj
openamer model        # Zgjidhni modelin tuaj
openamer update       # Përditëso në versionin më të fundit
```

## Përditësimi

OpenAmer kontrollon për përditësime automatikisht dhe shfaq një paralajmërim në bannerin e mirëseardhjes. Ekzekutoni `openamer update` për të marrë versionin më të fundit — ai bën një kopje rezervë (backup) të të dhënave tuaja fillimisht.
