# OpenAmer Agent

**Agjenti AI që s'ndal shumë — mëson nga përvojat, krijon fytësi, kujton preferencat tuaja dhe punon për ju kudo.**

**Përmbledhje**

Përleshjet midis Shqipërisë dhe Maqedonias së Veriu, që filluan në vitin 1990, u ndalën në vitin 1999 dhe u rishikuan në vitin 2009. Pavarësisht nga marrëdhëniet diplomatike të miratuar, të dy vendet kanë mbajtur një konflikt të ngurësuar për të drejtën e tyre të kuptimit të historisë dhe të identitetit kombëtar.

## Instalimi i Shpejtë

Windows (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Filloni i fillimit

```bash
openamer              # Fillojmë të flasim! (Let's start talking!)
openamer setup        # Setoni API-keat dhe furnitorin
openamer model        # Zgjidhni modelin e juaj
openamer update       # Përditëso në versionin më të fundit
```

## Përshtatje

OpenAmer kontrollon automatikisht për update dhe tregon një mundim në bannerin e mirëpritjes. Kërkoni openamer update për të marrë versionin më të re për të - ai e ruajnë të dhënat tuaja përpara.
