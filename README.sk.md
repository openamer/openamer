# OpenAmer Agent

**Samozberný AI agent – učiť sa z skúseností, vytvárať zručnosti, pamätaj si vaše preferencie a pracuj pre vás kdekoľvek.**

Preložím text do slovenčiny.

## **Funkcie**

- **Pôvodný terminálový rozhranie — plný TUI s automatickou doplnenou, históriou a tokom výstupu nástroja**
- **Žiješ kde si — Telegram, Discord, Slack, WhatsApp a ďalšie z jedného gateway.**
- **Učí sa počas času — pamäť, self-improvizačné zručnosti, prenesenie skúseností medzi súborom**
- **Delegáti & paralelizujú — spustiaj subagentov pre paralelné práce**
- **Rozpísalé automaty — vstavaná cron pre denné správy, zálohy, auditáže.**
- **Prebeháva kdekoľvek — lokálne, Docker, SSH, cloud, bezserverov.**

## Rýchla Inštalácia

Windows (Powershell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Začiatok

```bash
openamer              # Pochváľam, začneme. (Let's get started.)
openamer setup        # Nastavte vaše API kľúče & poskytovateľa.
openamer model        # Vyberte váš model.
openamer update       # Aktualizujte na poslednú verziu.
```

## Aktualizovanie

OpenAmer automaticky kontroluje aktualizácie a zobrazuje upozornenie v uviteľnej lišce. Spustiť openamer update, aby ste získali najnovšiu verziu — automaticky získať vaše dáta.
