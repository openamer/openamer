# OpenAmer Agent

**अपन आप ला सुधारय वाला AI एजेंट — अनुभव ले सीखय, नवा कौशल बनाय, आप मन के पसंद ला याद रखय, अउ हर जगह आपके बर काम करय।**

जे कोनो मॉडल के उपयोग करव — OpenRouter, OpenAI, DeepSeek, अउ अउर। `openamer model` के मदद से बदलव — कोड मा कोनो बदलाव नई करना पड़ही।

## विशेषता मन

- **असली टर्मिनल इंटरफेस — पूरा TUI जेमा ऑटोकम्प्लीट, हिस्ट्री, अउ स्ट्रीमिंग टूल आउटपुट हे**
- **ओइकरन ले जुड़ो जहाँ आप रहथौ — Telegram, Discord, Slack, WhatsApp अउ अउर घलो, सब एकी गेटवे ले**
- **समय के साथ सीखथे — याददाश्त, अपने आप सुधरे वाला कौशल, अउ पिछला सत्र मन के बात याद रखना**
- **प्रतिनिधि बनाथे अउ समानांतर काम करथे — समानांतर काम बर उप-एजेंट मन ला जनमाथे**
- **नियत समय के ऑटोमेशन — डेली रिपोर्ट, बैकअप अउ ऑडिट बर इन-बिल्ट क्रोन (cron)**
- **कहुं भी चलथे — लोकल, Docker, SSH, क्लाउड, सर्वरलेस**

## झटपट इंस्टाल (Quick Install)

विंडोज (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## शुरुआत करना

```bash
openamer              # गोठियाना सुरु करव
openamer setup        # अपन API की (keys) अउ प्रोवाइडर (provider) ला सेट करें
openamer model        # अपन मॉडल चुनव
openamer update       # नवा वर्जन मा अपडेट करव
```

## नवा करत हन

OpenAmer अपने आप अपडेट चेक करथे अउ वेलकम बैनर मा चेतावनी देखाथे। सबले नवा वर्जन पावे बर **openamer update** चलाव — ये पहिली आपके डेटा के बैकअप ले लेथे।
