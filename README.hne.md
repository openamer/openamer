## शुरुआत करना

```bash
openamer              # कहानी शुरू करें
openamer setup        # **API Key Setting Up** 
API Key का Setting Up करना 

API Key को Setting Up करने के लिए निम्नलिखित चरणों का पालन करें:

1. **API Provider चुनें**: अपने API के लिए एक Provider चुनें। कुछ लोकप्रिय Provider में **Google Cloud**, **AWS**, **Microsoft Azure** और **IBM Cloud** शामिल हैं।
2. **API Key Generate करें**: अपने Provider के Dashboard में जाएं और **API Key Generate** बटन पर क्लिक करें। यह आपको एक Unique API Key प्रदान करेगा।
3. **API Key Setting Up करें**: अपने API Key को Setting Up करने के लिए, आपको अपने Provider के Dashboard में जाना होगा। वहां आपको **API Key** को **Enable** करना होगा और **Settings** में जाना होगा।
4. **API Key को Secure करें**: अपने API Key को Secure करने के लिए, आपको **Environment Variable** में **API Key** को Add करना होगा। इससे आपका API Key सुरक्षित रहेगा।
5. **API Key का उपयोग करें**: अब आप अपने API Key का उपयोग कर सकते हैं और अपने API को Setting Up कर सकते हैं।

**Example: Google Cloud API Key Setting Up**

* **Google Cloud Console** में जाएं और **APIs & Services** पर क्लिक करें।
* **Dashboard** में जाएं और **Enable API** पर क्लिक करें।
* **API Key** को **Enable** करें और **Settings** में जाएं।
* **Environment Variable** में **API Key** को
openamer model        # कल्पित मॉडल चुनिए
openamer update       # **नवीनतम संस्करण अपडेट करें**
```
