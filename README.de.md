# OpenAmer Agent

**Das sich selbst verbesserte AI-Agent — lerne aus Erfahrungen, entwickle Fähigkeiten, erinnere dich an deine Vorlieben und arbeite für dich überall.**

Ich bin bereit, Texte in Deutsch zu übersetzen. Bitte gib mir den Text, den du übersetzt haben möchtest.

## Funktionen

- ****Interaktives Terminalfenster — Vollständiges TUI mit Autocomplete, Historie und Stream-Tool-Ausgabe****
- **Lebt, wo du bist — Telegram, Discord, Slack, WhatsApp und mehr aus einem Gateway**
- **Lernst über die Zeit — Gedächtnis, sich selbst verbesserte Fähigkeiten, Kreuz-Session-Erinnerung**
- **Delegierte & parallelisiert — spawn Subagenten für parallele Arbeit**
- **Geplante Automatisierungen — eingebauter Cron für tägliche Berichte, Sicherungen, Audits**
- **Überall laufen — lokal, Docker, SSH, Cloud, serverlos**

## Schnelle Installation

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## **Einstieg**

```bash
openamer              # Lass uns beginnen. Wie geht es dir heute?
openamer setup        # API-Schlüssel und -Anbieter einrichten.
openamer model        # Ich wähle den Model "Professional translator
openamer update       # Aktualisieren Sie auf die neueste Version.
```

## Aktualisierung

OpenAmer überprüft automatisch nach Updates und zeigt eine Warnung im Willkommensbanner an. Führe openamer update aus, um die neueste Version zu erhalten – dabei wird deine Datenbank vorher gesichert.
