Most updates in this thread are ops snapshots. This one is the engineering ledger: what actually changed in the code today, why, and the one command that proves it.

**Today's fixes (all on `main`):**

1. `440c6d75b` — **competitor-watchdog: the watch was blind.** `QUERIES[]` in `competitor_scan.py` was dead code — Algolia was queried with no `query=` parameter, so the scan pulled the *global* HN front feed and alerted on every story over 50 points (EPA politics, OpenAI math research, a Toast TUI IDE — none of them competitors). Now each query is sent as `query=`, results are merged and deduped by `objectID`, and alerts fire only for agent-relevant hits ≥50 pts. Post-fix it surfaces real intel it used to miss: *OKF Agent Memory* (80 pts — git-native persistent memory for coding agents) and *Geiger* (48 pts — inventory of every AI agent/MCP server on a machine).
2. `77abeb0c0` — same subsystem, hardened: send the query, dedupe the persisted seen-store, add tests (`test_competitor_scan.py`).
3. `489540938` — **auto-skill dedup by slug, not by a drifting answer prefix.** The old dedup key changed as answers drifted, so the same skill got re-created repeatedly. Slug-based dedup + tests.
4. `58b7784dc` — refactor of `mini_step.py`: `pick_seed` hoisted to module scope, and the test now asserts *behaviour* instead of mirroring the source shape (a green test that just restates the implementation proves nothing).
5. `deb2c84a2` — **win32 import bug:** three scripts (`ai_deep.py`, `knowledge_inventory.py`, `safe_restart.py`) died at import because `OPENAMER_HOME` was used as a raw `str`. Wrapped in `Path()`.
