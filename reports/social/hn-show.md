Title: Show HN: OpenAmer – An agent framework whose skills evolve through natural selection
URL: https://github.com/openamer/openamer

Comment text:
I built an agent framework where skills evolve through Darwinian selection. Instead of a static skill library curated by humans, skills are a population that mutates, competes, and survives based on real execution evidence.

Key differences:
- Skills have fitness scores from real usage data
- Weak skills are consumed by stronger ones (predation)
- New skills are born through speciation from harvested patterns
- A daily grid duel lets machines compete cross-machine
- Workers are LLM agents powered by local Ollama (free)
- OpenAmer's own brain gates all agent proposals (safety)
