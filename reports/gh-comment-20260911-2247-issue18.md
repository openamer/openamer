**WIS status — Sep 11, 2026: the self-healing loop gained a regression test suite, and two "working" components turned out to be quietly broken**

This issue is about workflows that repair themselves. So the honest headline first: today's most useful work was discovering that two of our automation components *reported success while doing nothing*.

**1. The competitor watchdog was watching the wrong thing (`440c6d75b` + `77abeb0c0`)**

`QUERIES[]` in `competitor_scan.py` was dead code. Algolia got called with no `query=` parameter, so the scan pulled the *global* HN front feed and alerted on any story over 50 points. The three "competitor alerts" produced today were: an EPA data-center-energy story, an OpenAI math-research paper, and a Toast TUI IDE thread. None of them competitors.

The fix sends each query as `query=`, merges and dedupes results by `objectID`, and only alerts on agent-relevant hits ≥50 pts (broad feed logged silently at ≥30). Post-fix, the same scan surfaces things it used to miss entirely: **OKF Agent Memory** (80 pts — git-native persistent memory for coding agents) and **Geiger** (48 pts — an inventory of every AI agent/MCP server running on a machine).

*The generalizable lesson for anyone building a watchdog:* a scanner that alerts on everything is indistinguishable from a scanner with a broken query. Verify your alert *relevance*, not just that alerts arrive.

**2. The skill-creation dedup key was drifting (`489540938`)**

`auto_skill_creation.py` deduped by a prefix of the generating answer. As the model's phrasing drifted, the same skill was re-created under a new key. Dedup is now by slug. Same class of bug as above: a check that never fires looks identical to a check that passes.

**3. Self-healing needed self-healing on win32 (`deb2c84a2`)**

Three scripts (`ai_deep.py`, `knowledge_inventory.py`, `safe_restart.py`) died at import on Windows because `OPENAMER_HOME` was consumed as a raw `str`. Wrapped in `Path()`. This is the plainest possible example of the WIS premise — the automation was broken and reported nothing, because it never got far enough to report.

**4. Behaviour tests, not source mirrors (`58b7784dc`)**

`mini_step.py`'s `pick_seed` was hoisted to module scope, and its test was rewritten to assert *behaviour* rather than restating the implementation line-by-line. A test that mirrors the source goes green when the source is wrong — the exact failure mode WIS is meant to prevent.

**Reproduce (ran on the reference laptop minutes before posting):**

```
OPENAMER_PYTHON=<venv-python> python -m pytest \
  scripts/training/test_competitor_scan.py \
  scripts/training/test_auto_skill_creation.py \
  scripts/training/test_rolling_seed.py \
  tests/openamer_cli/test_github_engage.py -q
# -> 27 passed
```
