# OpenAmer Agent

**O le agent AI e fa'aleleia lava ia — a'oa'o mai le poto, fa'usia talimalama, manatua au filiga, ma galulue mo oe i so'o se mea.**

Fa'aaoga so'o se fa'ata'ita'iga e te mana'o ai — OpenRouter, OpenAI, DeepSeek, ma isi. Sui i le `openamer model` — e leai se suiga i le code.

## Vaega Autu

- **Fa'agasuupo monasa monuia — TUI atoatoa e iai le autocomplete, tala’aga, ma le streaming a meafaigaluega output**
- **E ola i mea e te ola ai — Telegram, Discord, Slack, WhatsApp ma isi mea atu mai le tasi lava le gateway**
- **A’oa’oina i le taimi e fai ai — manatupuna, tomai e fa’aleleia pea, manatupuna i vaa’iga eseese**
- **Faia le fa'alaitumana'ia ma fa'atupula'ia — fa'atupula'ia ni auiliili la'ititi mo galuega fa'atupula'ia**
- **Autometis faatulaga — cron faia i totonu mo ripoti i aso taʻitasi, backup, ma auiliiliga**
- **E savali i so'o se mea — local, Docker, SSH, cloud, serverless**

## Fa'aputua Vave

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Amata lau faigofia

```bash
openamer              # Amata le talanoaga
openamer setup        # Faatulaga au ki API & le tuuina atu
openamer model        # Filifili lau fa'ata'ita'iga
openamer update       # Fa'afou i le version fou lava
```

## Fa'afouina

O le OpenAmer e siaki otometi pe iai ni update fou ma fa'ailoga se lapotopoto i le banner fa'afeleleia. Fa'aaoga le polokalame `openamer update` ina ia maua le version foumaia — o le a saili muamua e backup-ia au fa'amatalaga.
