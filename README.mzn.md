# OpenAmer Agent

**ای‌-آی ایجنتِ خود-به‌بودبخش — از تجربه یاد بگره، مهارت بسازه، ترجیحاتِ شمه رو به یاد دونه و هر جا بَوِ، برای شمه کار کِنه.**

هر مدلی که بخواسی استفاده کِنه — OpenRouter, OpenAI, DeepSeek و بقیه. با `openamer model` عوضش کِنه — بدون اینکه کدی تغییر بدِنی.

## ویژگی‌ها

- **واقعی ترمینال اینترفیس — کامل TUI با اتوکومپلیت، تاریخچه و استریمینگ خروجی ابزارها**
- **همون‌جه که تو هستی — تلگرام، دیسکورد، اسلک، واتس‌اپ و بقیه، همگی از یه درگاه**
- **وقت بگذره یاد می‌گیره — حافظه، مهارت‌های خود-به‌بود، یادآوری بین جلسات**
- **واگذار کنه و موازی کنه — برای کارِ موازی، زیر-عامل (subagent) بسازه**
- **برنامه‌ریزی‌شده اتومیشن‌ها — کرونِ داخلی برای گزارش‌های روزانه، بک‌آپ‌ها و حسابرسی‌ها**
- **هر جا بـِـرِـن — محلی، Docker، SSH، کلاود، serverless**

## سریع نصب

ویندوز (پاورشل):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

لینوکس / مک‌او‌اس:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## شروع کردن

```bash
openamer              # گپ زدنشَه شروع کُن
openamer setup        # API کی‌ها و پرووایدرِ خودتِ تنظیم کِنه
openamer model        # مدلِتِ انتخاب کِنه
openamer update       # به آخرین ورژن آپدیت کَن (به آخرین ورژن به‌روز رَس)
```

## به‌روزرسونی

OpenAmer خودبه‌خود آپدیت‌ها ره چک کِنه و تو بنر خوش‌آمدگویی هشدار می‌ده. برای اینکه آخرین ورژن ره بگیری، `openamer update` ره اجرا کِنه — ای اول از همه از داده‌هاتون بک‌آپ می‌گیره.
