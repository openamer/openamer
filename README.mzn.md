بازیابی کلید API
----------------

بازیابی کلید API برای دسترسی به سرویس‌های مختلف، مانند سرویس‌های وب، API، یا سرویس‌های دیگر، یک مرحله ضروری است. در این بخش، مراحل بازیابی کلید API برای یک سرویس نمونه را توضیح می‌دهیم.

### 1. ثبت نام در سرویس

ابتدا، باید در سرویس مورد نظر ثبت نام کنید. این شامل وارد کردن اطلاعات شخصی، انتخاب یک نام کاربری و رمز عبور، و تأیید قوانین استفاده از سرویس است.

### 2. درخواست کلید API

پس از ثبت نام، باید درخواست برای دریافت کلید API را ارسال کنید. این درخواست ممکن است شامل وارد کردن اطلاعات خاصی مانند نام اپلیکیشن، نوع استفاده، یا اطلاعات تماس برای ارتباط با پشتیبانی باشد.

### 3. دریافت کلید API

پس از ارسال درخواست، سرویس باید کلید API را به شما ارسال کند. این کلید ممکن است به صورت رمزنگاری شده باشد و باید برای استفاده در اپلیکیشن یا سرویس خود، آن را رمزگشایی کنید.

### 4. استفاده از کلید API

پس از دریافت کلید API، می‌توانید آن را در اپلیکیشن یا سرویس خود استفاده کنید. این شامل وارد کردن کلید در درخواست‌های API یا در کد اپلیکیشن است.

### 5. مدیریت کلید API

در نهایت، باید کلید API را مدیریت کنید. این شامل نگهداری از کلید، تغییر یا حذف آن است. در صورت تغییر یا حذف کلید، باید درخواست جدیدی برای دریافت کلید API را ارسال کنید.

**مراحل بازیابی کلید API**
---------------------------

1. **ثبت نام در سرویس**: در سرویس مورد نظر ثبت نام کنید.
2. **درخواست کلید API**: درخواست برای دریافت کلید API را ارسال کنید.
openamer model        # **Model:** Mazandarani-English Translator

Please provide the text you'd like to translate into Mazandarani.
openamer update       # **برسی به نسخه‌ی جدید**

## **بازیابی**

OpenAmer به طور خودکار به‌روزرسانی‌ها را چک می‌کند و در بالای صفحه خوش‌آمدگویی هشدار نشان می‌دهد. برای دریافت نسخه‌ی جدید، openamer update را اجرا کنید — پیش از این که داده‌های شما را پشتیبان بگیرد.
