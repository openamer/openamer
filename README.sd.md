# OpenAmer Agent

**خود-به-خود بهتري ڪندڙ AI ايجنٽ — تجربي مان سکو، مهارتون پيدا ڪريو، توهان جي پسند کي ياد رکو، ۽ هر جڳهه تي توهان لاءِ ڪم ڪريو.**

ڪنهن به ماڊل جو استعمال ڪريو جيڪو توهان چاهيو — OpenRouter, OpenAI, DeepSeek, ۽ ٻيا. `openamer model` جي ذريعي تبديل ڪريو — ڪوڊ ۾ ڪنهن تبديلي جي ضرورت ناهي.

## خاصيتون

- **حقيقي ٽرمينل انٽرفيس — مڪمل TUI جنهن ۾ آٽو ڪمپليٽ (autocomplete)، تاريخ (history)، ۽ اسٽريمنگ ٽول آؤٽ پٽ شامل آهي**
- **اتي رهي ٿو جتي توهان آهيو — ٽيليگرام، ڊسڪورڊ، سليڪ، واٽس اپ ۽ ٻيا گهڻا، رڳو هڪ گيٽ وي (gateway) تان**
- **وقت سان سکي ٿو — ياداشت، پاڻ کي بهتر بڻائڻ واري صلاحيتون، سیشنز جي وچ ۾ ياد رکڻ**
- **صوبائي ۽ متوازی ڪري ٿو — متوازی ڪم لاءِ سب-ايجنٽس (subagents) پيدا ڪري ٿو**
- **شيڊيولڊ آٽوميشنز — روزاني رپورٽن، بيڪ اپس ۽ آڊيٽس لاءِ بلٽ-ان ڪرون (cron)**
- **ڪنهن به جڳهه تي هلندو آهي — لوڪل، Docker، SSH، ڪلاؤڊ، سرورليس**

## تيز انسٽاليشن

ونڊوز (پاور شيل):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

لينڪس / میک او ايس (Linux / macOS):
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## شروعات ڪرڻ

```bash
openamer              # ڳالهاڻڻ شروع ڪريو
openamer setup        # پنهنجون API ڪي-ز (keys) ۽ پرووائيڊر (provider) سيٽ اپ ڪريو
openamer model        # پنهنجو ماڊل چونڊيو
openamer update       # تازي ورژن ۾ اپڊيٽ ڪريو
```

## اپڊيٽ ڪرڻ

OpenAmer پاڻمرادي اپڊيٽس لاءِ چيڪ ڪري ٿو ۽ ويلڪم بينر ۾ هڪ وارننگ ڏيکاري ٿو. تازي ورزن کي حاصل ڪرڻ لاءِ `openamer update` هلايو — اهو پهريان توهان جي ڊيٽا جو بيڪ اپ کڻندو.
