# OpenAmer Agent

**Ennast parandav AI agent — õppi kogemustest, loo uusi oskusi, mäleta oma soove ja tööta sinu eest kuskil.**

Ei ole teil üks.

## Ominaisused

- **Tõeliselt terminali põhinev vaheline interface — täielik TUI autokomplektimisega, ajaloo ja streamimisega töövahendite väljavalikuteks.**
- **Elab, kus elad — Telegram, Discord, Slack, WhatsApp ja palju teisigi ühest sildadest**
- **Aja jooksul õpib — mälu, enda parandavad oskused, sünsete vahelise mälu**
- **Delegaadid & paralleeliseerib — lase selle töö paralleelseteks alamagentideks**
- **Eelnevalt määratud automatsioonid — sisemine cron päevasteks aruannete, tagastite, auditeks**
- **Käib kõikjal — kohalikult, Docker, SSH, cloud, ilma serverita**

## Kiirendatud Installeerimine

Windows (PowerShell)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Algusaeg

```bash
openamer              # Alusta vestlust
openamer setup        # Konsoolide asukohad & teenusepakkujad sätta
openamer model        # Valige oma mudel
openamer update       # Uuenda viimase versiooni.
```

## Uuendus

OpenAmer kontrollib automaatselt uuendusi ja näitab ettepanekut vastavas sõnumis. Suunatud openamer update, et saada teada viimase versiooni — see salvestab andmeid esmalt.
