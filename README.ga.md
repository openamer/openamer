# OpenAmer Agent

**An agent umhaolach - an bhfuil aon taithí agat, cruthaigh scileanna, abair a bhfuil áthas agat, agus obair leat i gcéin.**

Táim ag dul i ngleic leis an aistriúchán.

## Tairiscintí

- ****Inneachtaí Trealaimh** — TUI lán le **achomhainne**, **stair**, agus **fhuaimniúlacht** na daltanais.**
- **Tá áit le búrcaigh leat — Telegram, Discord, Slack, WhatsApp agus breis ó ghaoithe amháin.**
- **Tá sé ag foghlaim le h-am, — cuimhne, scileanna a athnuachan, athbheochan seisiúnacha**
- **Déanann comhaltaí & parálaithe — spreagann aigneogaí bunaitheacha don obair paraillí**
- **Tá rudaí cumasacha á chur i bhfad le haghaidh tuarascálta láithe, cóidíochtaí, agus athbhairteacha.**
- **Déanann sé a bheith ar fáil ar bith — áitreach, Docker, SSH, cluich, neamhshóisialta**

## Cúpla Cóir

Comharsanaí (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Tosaigh agus déan!

```bash
openamer              # Táim ag dul i gcónaí i gcraiceann leat! (I'm always here to chat with you!)
openamer setup        # Tóg do cheanaitheacha API & do theagmhara
openamer model        # Táim ag dul i dteanga na Gaeilge. Cé a chuid model a roghnaigh?
openamer update       # Tóg an leagan is déanaí abhfuil ar fáil.
```

## Nuashonraíonn

Tugann OpenAmer athinsint ar athruithe neamhshuimiúla agus déantar a fháil amach i gcuid an chéad chruinnithe. Cuir OpenAmer athinsint i bhfeidhm chun an leagan is déanaí a fháil — táimid ag cosaint a bhfuil againn roimhe sin.
