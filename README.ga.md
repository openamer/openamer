# OpenAmer Agent

**An gníomhaire AI féinféardúcháin — foghlaim ó thaithmic, cruthaigh scileanna, cuimhnigh ar do thosaíocht, agus oibrigh duit i háit own.**

Úsáid cás múnla ar bith a theastaíonn uait — OpenRouter, OpenAI, DeepSeek, agus eile. Athraigh go simplí le `openamer model` — gan aon athruithe ar an gcód.

## Gnéithe

- **Interface teerminail fíor — TUI iomlán le huathoiliú, stair, agus tairseachas tooling sruthaithe**
- **Cónaíonn sé ansin Wishing — Telegram, Discord, Slack, WhatsApp agus eile, go léir ó ghaiteamháire amháin**
- **Foghlaimíonn le himeacht an ama — cuimhne, scileanna féinféin-upróimseach, cuimhneachán tras-seisiúne**
- **Tugann sé úsáid d'others & déanann parallelization — cruthaíonn sé fo-ghníomhaireachtaí le haghaidh oibre pharaileleach**
- **Uathoibriú a scealbaiu — cron ionsomaithe do thuairiscí láitheacha, cópiasaistéalaí, agus audait**
- **Rithann sé an áit ar an áit — áitiúil, Docker, SSH, scuab, serverless**

## Suiteáil Thapaidh

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Tús a chur leis

```bash
openamer              # Tosaigh ag comhrú
openamer setup        # Socrú do chliúidí API & soláthraí
openamer model        # Roghnaigh do mháilín
openamer update       # Nuachtáil go dtí an leagan is nuaí
```

## Ag nuashonrú

Déanann OpenAmer seiceáil go huathoibrithe le haghaidh nuashonruithe agus taispeánann sé rabhadh sa bhannear fáilte. Seachnaigh `openamer update` chun an teasca is déanaí a fháil — déanann sé cóip shábháilte de do chuid sonraí ar an gcéim.
