# OpenAmer Agent

**Агент AI, саморазвивающийся — учиться на опыте, создавать навыки, помнить ваши предпочтения и работать для вас где угодно.**

Я использую OpenAI.

## Функции

- **Полноценный терминальный интерфейс — полноценный TUI с автодополнением, историей и потоковым выводом инструментов.**
- **Живет, где вы живёте — Telegram, Discord, Slack, WhatsApp и так далее из одного воротца.**
- **Обучается в процессе времени — память, самоулучшающиеся навыки, перекличка на сессию.**
- **Делегирует и параллелизует — запускает подагентов для параллельной работы**
- **Расписанные автоматизации — встроенная cron для ежедневных отчетов, резервных копий, аудитов.**
- **Работает везде — локально, в Docker, через SSH, в облаке, без сервера.**

## Быстрый Установщик

Windows (PowerShell)
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Начало работы

```bash
openamer              # Начать разговор.
openamer setup        # Установите свои ключи API и провайдера.
openamer model        # **Выберите модель**
openamer update       # Обновить до последней версии
```

## Обновление

OpenAmer проверяет обновления автоматически и показывает предупреждение в баннере приветствия. Запустите openamer update, чтобы получить последнюю версию — она сначала создаст резервную копию ваших данных.
