# OpenAmer Agent

**OpenAmer — это агент, который не ломается — и который доказуемо улучшается с использованием.**

Он работает на вашей собственной машине, встречает вас в каналах, которыми вы уже пользуетесь, и становится лучше, чем дольше вы его используете. Две вещи выделяют его:

1. **Он не ломается.** Самообновление защищено от режимов сбоя, которые оставляют других агентов наполовину установленными — блокировки файлов, прерванные установки, устаревшие маркеры восстановления. Агент проверяет, прежде чем утверждать, и сообщает о реальных ошибках, а не выдумывает результаты.
2. **Он доказуемо улучшается с использованием.** Память сохраняется между сессиями, навыки извлекаются из сложных задач и оттачиваются при повторном использовании, а рой A2A делится курируемыми, подписанными и не допускающими утечек знаниями между узлами. Обучение, которое можно наблюдать, а не лозунг.

Используйте любую модель — OpenRouter, OpenAI, собственный эндпоинт и [многие другие](https://github.com/openamer/openamer/blob/main/website/docs/integrations/providers). Переключайтесь с помощью `openamer model` — без изменения кода, без привязки.

## Возможности

| Возможность | Описание |
|---|---|
| **Не ломается** | Защищённое самообновление, которое переживает блокировки файлов, прерванные установки и устаревшие маркеры восстановления. Агент проверяет, прежде чем утверждать, и сообщает о реальных ошибках, а не выдумывает результаты. |
| **Доказуемо улучшается** | Память сохраняется между сессиями, навыки извлекаются из сложных задач и оттачиваются при повторном использовании, а рой A2A делится курируемыми, подписанными и не допускающими утечек знаниями между узлами. |
| **Настоящий терминальный интерфейс** | Полный TUI с многострочным редактированием, автодополнением slash-команд, историей разговора, прерыванием-и-перенаправлением и живой потоковой выдачей инструментов. |
| **Живёт там, где вы** | Telegram, Discord, Slack, WhatsApp, Signal и CLI — один шлюз, один разговор, который следует за вами по каждому каналу. Голосовые заметки транскрибируются автоматически. |
| **Плановые автоматизации** | Встроенный cron-планировщик с доставкой на любую платформу. Опишите ежедневный отчёт, ночное резервное копирование или еженедельный аудит простым языком — и он выполняется без присмотра. |
| **Делегирует и распараллеливает** | Запускайте изолированные субагенты для параллельных рабочих потоков или пишите Python-скрипты, вызывающие инструменты через RPC, чтобы свести многошаговые конвейеры к одному ходу. |
| **Работает где угодно, не только на ноутбуке** | Шесть терминальных бэкендов — локальный, Docker, SSH, Singularity, Modal и Daytona. Daytona и Modal добавляют бессерверную персистентность, так что окружение вашего агента засыпает в простое и просыпается по требованию — почти без затрат между сессиями. |
| **Приватно по умолчанию** | Номера телефонов, пароли, электронные письма и номера карт редактируются перед сохранением. ОС, оборудование и модель вашего узла остаются в вашем собственном системном промпте. |
| **Готово к исследованиям** | Пакетная генерация траекторий и сжатие траекторий для обучения следующего поколения моделей, вызывающих инструменты. |

## Быстрая установка

### Linux, macOS, WSL2, Termux

```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

### Windows (нативно, PowerShell)

```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Установщик делает всё: uv, Python 3.11, Node.js, ripgrep, ffmpeg и портативный Git Bash.

## Начало работы

```bash
openamer              # Интерактивный CLI — начать разговор
openamer model        # Выбрать провайдера и модель LLM
openamer tools        # Настроить, какие инструменты включены
openamer gateway      # Запустить шлюз обмена сообщениями (Telegram, Discord, …)
openamer setup        # Запустить полный мастер настройки
openamer update       # Обновиться до последней версии
openamer doctor       # Диагностировать проблемы
```

## Обновление

OpenAmer автоматически поддерживает себя в актуальном состоянии. При каждом запуске он в фоне проверяет, доступна ли более новая версия — если да, приветственный баннер показывает `⚠ Отстаёт на N коммитов — выполните 'openamer update'` прямо в чате.

```bash
openamer update
```
