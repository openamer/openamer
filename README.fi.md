## Ominaisuudet

- **Käyttöliittymä, joka on toteutettu täysin tekstikäyttöliittymänä (TUI) ja sisältää automaattisen täydentämisen, historian ja virtuaalilaitteen tulosteiden välittämisen.**
- **Asutteessaasi - Telegram, Discord, Slack, WhatsApp ja useita muita yhdestä portista**
- **Oppii ajan myötä — muisti, itseparannetut taidot, rinnakkaisistunnon muistinvaraisuus**
- **Suorittajat & paralellisoi — luo alikäsiteltäviä agentteja paraleelliselle työlle**
- **Aikataulutetut automaattiset toiminnot – sisäänrakennettu cron päivittäiset raportit, varmuuskopiot, tarkistukset**
- **Suoraa mistä tahansa — paikallisesti, Docker, SSH, pilven, serverless**

## Alkamisvaiheet

```bash
openamer              # Aloita keskustelu.
openamer setup        # Aseta API-avaimet ja palveluntarjoaja
openamer model        # Valitse mallisi.
openamer update       # Päivitä ohjelmaasi viimeisimmäksi versioon.
```

## Päivittäminen

OpenAmer tarkistaa päivityksiä automaattisesti ja näyttää varoituksen välilehdellä. Käynnistä komento `openamer update` saadaksesi uusimman version - se varaa tiedot ensin.
