# OpenAmer Agent

**AI agent si lea ɖe eɖokui ƒe nu — xɔ nuwɔrsu tso nuwɔnawo me, ɖe dzesiwo ɖe ŋutifor, yaadra wònuvɔvɔwo, eye wòwɔ wò dzesiwo le afi ɖeka hã.**

Lo aɖu model si nɔ nu vevi be nàlo — OpenRouter, OpenAI, DeepSeek, kple ewo ƒe nu bubuwo. Trɔ model siawo kple `openamer model` — gakpɔ nu si nàtrɔ le code dzi o.

## Nudzɔkuwo

- **Terminal interface nyenye — TUI ɖeka si me autocomplete, history, kple streaming tool output le me**
- **Wònye anyi afi si wòle — Telegram, Discord, Slack, WhatsApp kple eƃwo tso gateway ɖeka me**
- **Xɔna nu ɣesiaɣi — ŋutifafa, dzesi si ƒo ɖe eɖoku ŋu, eye wòɖo ŋu be wòɖo nu si wòxɔna le gbe si va yi me ŋu**
- **Ɖo ŋutikpɔlawo na nuwɔnawo kple wòwo tɔ — ɖo subagent-wo ɖe nuwɔnawo ƒe parallel-wɔwɔ me**
- **Automations si woɖo go — cron si le eme na nuvovovo daily reports, backups, kple audits**
- **Eɖo ɣesiafia — local, Docker, SSH, cloud, serverless**

## Ðɔkuɖuɖu Gbeɖu

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Dzesiɖe

```bash
openamer              # Dze nuŋuɖuɖu dze
openamer setup        # Ðe dzesi wò API keys kple provider
openamer model        # Kpɔ wò model tso nuwotɔ me
openamer update       # eɖo ŋu be wòɖo ɣe ƒe nuveve elatesia
```

## Leɖoɖo ƒe nuveve nu ɖo eyo eye

OpenAmer doa ŋu ade ŋu kpɔtɔtɔ be update vɔ̃wo le eye wòaɖo ŋuɖãlele ɖe welcome banner ƒe nu me. Ðe `openamer update` ɖe nu be nànyra version kuɖikui na — wòaɖe wò datawo ɖe nu wò hã gbeɖe.
