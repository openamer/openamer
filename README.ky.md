# OpenAmer Agent

**Өзүн-өзү өнүктүрүүчү AI агент — тажрыйбадан үйрөнөт, көндүмдөрдү түзөт, сиздин каалоолоруңузду эсинде сактайт жана каалаган жерде сиз үчүн иштейт.**

Каалаган моделиңизди колдонуңуз — OpenRouter, OpenAI, DeepSeek жана башкалар. `openamer model` командасы менен которуңуз — кодду өзгөртүү талап кылынбайт.

## Өзгөчөлүктөрү

- **Чыныгы терминал интерфейси — автотолуктоо, тарых жана куралдардын чыгышын түз агымдап көрсөтүү функциялары бар толук TUI**
- **Сиз болгон жерде жашайт — Telegram, Discord, Slack, WhatsApp жана башкалары бир шлюз аркылуу**
- **Убакыттын өтүшү менен үйрөнөт — эс тутум, өзүн-өзү жакшыртуу көндүмдөрү, сессиялар аралык эскериүү**
- **Делегаттап жана параллелдештирет — параллелдүү иш үчүн суб-агенттерди түзөт**
- **Пландалган автоматташтыруулар — күнүмдүк отчеттор, резервдик көчүрмөлөр жана аудиттер үчүн камтылган cron**
- **Каалаган жерде иштейт — жергиликтүү, Docker, SSH, булуттук, серверсиз**

## Тез орнотуу

Windows (PowerShell):
```powershell
iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash
```

## Башталышы

```bash
openamer              # Сүйлөшүүнү баштоо
openamer setup        # API ачкычтарыңызды жана провайдериңизди жөндөңүз
openamer model        # Моделиңизди тандаңыз
openamer update       # Акыркы версиясына жаңыртыңыз
```

## Жаңыртуу

OpenAmer жаңыртууларды автоматтык түрдө текшерет жана саламдашуу баннеринде эскертүү көрсөтөт. Акыркы версияны алуу үчүн `openamer update` командасын иштетиңиз — ал алгач сиздин маалыматтарыңызды резервдик көчүрмөсүн жасайт.
