## Функциялар

- **Туулган терминал интерфейси — толук ТУИ жана аутокомплектация, тарыхы жана аңгемелөөчү аспаптын чыгымы.**
- **Сизде жашайсың - Telegram, Discord, Slack, WhatsApp жана башкаларды бир жол менен**
- **Узактында ойлонуп чыгат — хотумдулуу, көзөлүүлүк, көчүрүлүүчүлүк, сессиядан сессияга эстөө.**
- **Делегаттар & параллеликтирүү — параллелүүчү иштерди жасоо үчүн кичинекей агенттерди айрымалайт.**
- **Тизмектештирүүлөр — күнүнө күнүнүн автозакарлары, күбөлүктөр, аудиттер.**
- **Көчкөн жерде — локал, Docker, SSH, облако, серверсузсуз**

## Башталыш

```bash
openamer              # Баштоо баштады.
openamer setup        # **API кеңештери жана сунушчуларын иштетүү**

API кеңештери жана сунушчуларын иштетүүнүн үчүнчү жолу үчүн:

1. [Google Cloud Platform](https://console.cloud.google.com/) сайтына келип, **API кеңештери** сатып алуу бөлүмүнө келиңиз.
2. **API кеңештери жана сунушчуларын иштетүү** сатып алуу үчүн **Сатып алуу** буйругун тапкылашыңыз.
3. **API кеңештери жана сунушчуларын иштетүү** сатып алуу үчүн **Сатып алуу** буйругун тапкылашыңыз.
4. **API кеңештери жана сунушчуларын иштетүү** сатып алуу үчүн **Сатып алуу** буйругун тапкылашыңыз.
5. **API кеңештери жана сунушчуларын иштетүү** сатып алуу үчүн **Сатып алуу** буйругун тапкылашыңыз.
6. **API кеңештери жана сунушчуларын и
openamer model        # **Тилди тандаңыз**
openamer update       # **Сүрөттөрдү жакындаштыру**
```

## **Кайра көчүрүү**

OpenAmer otunchu kөзүндө түзөттөрдү өзгөчө көрсөтүүнү көрсүн. Акырындык менен аны күнүртүүнү көрсүн. OpenAmer update кылуу менен жаңы версияны алыңыз — ал алдын ала маалыматтарыңызды сактайт.
