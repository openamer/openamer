- **Интерфейси барномӣ - интерфейси ТУИ (Terminal User Interface) дар барнома, ки бо истифодаи тарҷеъи хатҳои автокомплит, тарҷеъи история ва тарҷеъи махсуси кори ҷойҳои кори барномаи хатҳои барномаи ТУИ.**

## Таркиб кардани хурд

Виндоус (PowerShell)
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Оғози кор

```bash
openamer              # Моҳонаи навон!
openamer setup        # Танзимоти API ва муҳаррир
openamer model        # **Model:** Neural machine translation model for Tajik language
**Source language:** English
**Target language:** Tajik (Tojikī)

Translation: 
Please select a model for me to translate into Tajik.
openamer update       # Обновление до последней версии
```
