# OpenAmer Agent

**Агент-ИИ-и худи такмилдодашаванда — аз таҷриба омӯзед, малакаҳо эҷод кунед, бартариҳои худро дар ёд доред ва дар ҳама ҷо барои шумо кор кунед.**

Аз ҳар як модели хоҳлатон истифода баред — OpenRouter, OpenAI, DeepSeek ва ғайра. Бо ёрии `openamer model` иваз кунед — бе тағйироти код.

## Хусусиятҳо

- **Интерфейси воқеии терминал — TUI-и пурра бо пуркунии худкор, таърих ва ҷараёни натиҷаҳои воситаҳо**
- **Он ҷое зиндагӣ мекунад, ки шумо ҳастед — Telegram, Discord, Slack, WhatsApp ва дигарҳо аз як шлюз (gateway)**
- **Бо гузариши вақт меомӯзад — хотира, малакаҳои худбахуд беҳтаршаванда, бозхониши маълумот аз сессияҳои гузашта**
- **Супориш ва параллелсозӣ — эҷоди суб-агентҳо барои кори параллелӣ**
- **Автоматизатсияҳои банақшагизошташуда — cron-и дохилӣ барои ҳисоботҳои рӯзона, нусхагириҳо ва аудитҳо**
- **Дар ҳама ҷо кор мекунад — маҳаллӣ, Docker, SSH, абр, serverless**

## Насби зуд

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Оғози кор

```bash
openamer              # Оғози сӯҳбат
openamer setup        # Калидҳои API ва провайдери худро танзим кунед
openamer model        # Модели худро интихоб кунед
openamer update       # То ба версияи охирин навсозӣ кунед
```

## Навсозия

OpenAmer ба таври автоматикӣ навсозиҳоро тафтиш мекунад ва дар баннери истиқболӣ огоҳӣ менамошонад. Барои гирифтани версияи охирин фармони `openamer update`-ро иҷро кунед — он аввал аз маълумоти шумо нусхаи эҳтиётӣ (backup) мегирад.
