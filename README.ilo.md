# OpenAmer Agent

**Ti AI agent a mangpaimbag iti bagina — agadal manipud iti padas, mangbukel kadagiti kinalaing, laglagipen dagiti pagayatanmo, ken agtrabaho para kenka iti sadino man.**

Usarem ti aniaman a model a kayatmo — OpenRouter, OpenAI, DeepSeek, ken dadduma pay. Agbaliwka babaen ti `openamer model` — awan ti panagbaliw iti koda.

## Dagiti Rambak

- **Siyudad a terminal interface — kompleto a TUI nga addaan autocomplete, history, ken streaming output ti tool**
- **Agbiag no sadino ka — Telegram, Discord, Slack, WhatsApp ken dadduma pay manipud iti maysa a gateway**
- **Mangadal itika-alaan ti tiempo — memorya, kinalaing a mangpaimbag iti bagi, ken panaglagip iti naglabas a session**
- **Mangidelegat ken mangparalelo — mangaramid kadagiti subagent para iti parallel a trabaho**
- **Naisked a panag-automatize — built-in cron para kadagiti kanito a report, backup, ken audit**
- **Agandar iti anyan man — local, Docker, SSH, cloud, serverless**

## Sipudud a Panang-install

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Panangrugi

```bash
openamer              # Mangrugi ti makitinnulong
openamer setup        # Iset-up dagiti API keys ken provider-mo
openamer model        # Pilien ti modelom
openamer update       # I-update iti kastaun a bersion
```

## Ag-update

Ag-check ti OpenAmer para iti updates iti automatiko ken mangipakita iti pakaammo iti welcome banner. Patgangen ti `openamer update` tapno maala ti latest a version — i-back up-na pay ti datam sakbayna.
