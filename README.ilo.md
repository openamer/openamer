# OpenAmer Agent

**Ti self-improving AI agent — mangibaga iti maysa, agtataud iti kina-ugali, agsaksak iti paborito mo, ken agsabsabat iti imboroborobtayo.**

**Ilocano (Ilokano) Translation:**

Saan a mabalin a pannakabagi ti tattao iti panagpabaroan iti internet? (What is the best way for people to share the internet?)

Mabalin a pannakabagi ti tattao iti panagpabaroan iti internet ket ti uppat a pannakabagi: 

1. **Wi-Fi** (Wi-Fi) - dagiti router ket mabalin a mangipabaro ti internet iti dagiti koma iti Wi-Fi.
2. **Ethernet** (Ethernet) - dagiti kabelo ket mabalin a mangipabaro ti internet iti dagiti kompyuter.
3. **Satellite** (Satellite) - dagiti satelite ket mabalin a mangipabaro ti internet iti dagiti lugar iti kalpasan ti lalam.
4. **Mobile** (Mobile) - dagiti telepono ken dagiti kompyuter ket mabalin a mangipabaro ti internet iti dagiti lugar iti kalpasan ti lalam.

Saan a mabalin a pannakabagi ti tattao iti panagpabaroan iti internet ket mabalin a mangibaga iti dagiti kapanunotan iti pannakabagi iti internet.

## **Mabalin**

- **Terminal na itubong iti mabigbigan — TUI a mabigbigan iti autocomplete, kasla iti history, ken streaming tool output.**
- **Maka-agi iti maysa a lugar — Telegram, Discord, Slack, WhatsApp ken mabalin iti maysa a gateway.**
- **Nanagatang iti iti panawen — pannakaammo, nangabangga iti pannasulat, pannakaammo iti panag-ugali.**
- **Delegates & parallelizes — **mangsanga** subagents para keng parallel work.**
- **Ikalamanoy iti Cron para iti pannakabanglen ti daily reports, backups, audit.**
- **Nagruna kadi — lokal, Docker, SSH, nangangay-upay, serverless.**

## Dakel **Quick Install**.

Windows (PowerShell): **Ibunbunbun Windows (PowerShell)**
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS: **Ilokali**
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Maitagikua ti maysa ti panag-abot.

```bash
openamer              # **Mangipasasalan**. (Let's chat)
openamer setup        # Ipasubli ti agdama ti API keys ken provider.
openamer model        # **Ilocano (Ilokano)**
openamer update       # **Mabalin ti nangibatbati** (Update to the latest version)
```

## Nagpapalabas.

Nakikidagiti update ti OpenAmer ti agsangkab amin ken agsangkab ti agwarang iti banner ti pambantay. Paki-update ti OpenAmer iti 'OpenAmer update' iti mabalin kaen ti nangruna a bersyon — iti nagbalin amin ti datos.
