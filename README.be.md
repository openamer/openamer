## Прымальніцтвы

- **Прафесійны перакладчык. Пераклад у беларускую мову. Выратоўваць усе інлайн Маркдаўн (**, відэакампаненты бачныя тэксту), захоўваць каманды/адрасы URL у якасці. Вяртаць ТОЛЬКО пераклад, без каментарыяў/абмежаванняў.
Прафесійны інтэрфейс тэрмінала — поўны TUI з аўтаматычным запампоўваннем, гісторыяй і страмінгавым вывадам інструменту.**
- **Жывецеце, дзе вы жывецеце — Telegram, Discord, Slack, WhatsApp і іншыя з аднаго гейтвея.**
- **Вучыцца па хоцькі час — памяць, самадапаўняльныя умы, перадача памяці між сэсіі**
- **Дэлегавальнікі & паралелізуе — выдзяляе падагенцтва для паралельнай працы**
- **Узаканенныя аўтаматызацыі — убудаваная cron для дзённых справаздач, архіваў, аўдытаў**
- **Runuje kуды — лакальны, Docker, SSH, аўтаматычныя сэрвэры, безсэрвэрны**

## **Універсальная інсталяцыя**

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Пачатак

```bash
openamer              # Пачатваць размову.
openamer setup        # Устанавіце ключы API і прадстаўнікаў
openamer model        # Выберыце сваё мадэль
openamer update       # Абнавіцца да апошніх версіі.
```

## Актуалізацыя

OpenAmera рэгулярна шукае ановыкі і паказвае паведамленне ў банеры ўітчынга. Выклікай openamer update, каб атрымаць апошнія версіі — яна спачатку збяргне даныя.

## Удзельнічаць

Давайце разам працавалі — адкрывіце праблемы, падацеяўскія запыты, альбо далучайцеся да супольнасці.
