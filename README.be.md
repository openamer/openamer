# OpenAmer Agent

**Сампаўлеканы ШІ-агент — вучыцеся на вопыце, стварайце навыкі, забіхвайце свае перавагі і працуйце на вас у любым месці.**

Выкарыстоўвайце любую мадэль па жаданні — OpenRouter, OpenAI, DeepSeek і іншыя. Пераключайцеся з дапамогой `openamer model` — без змяненняў у кодзе.

## Асаблівасці

- **Сапраўдны інтэрфейс тэрмінала — поўнавартасны TUI з аўтазапаўненнем, гісторыяй і патокавым вывадам інструментаў**
- **Жыве там, дзе і вы — Telegram, Discord, Slack, WhatsApp і іншыя ў адным шлюзі**
- **Вучыцца з часам — памяць, навыкі самаўдасканалення, прыгадванне паміж сесіямі**
- **Дэлегуе і паралелізуе — стварае суб-агентаў для паралельнай працы**
- **Планавыя аўтаматызацыі — убудаванага cron для штодзённых справак, рэзервовага капіявання і аўдытаў**
- **Працуе дзеці — лакальна, у Docker, праз SSH, у воблаку, serverless**

## Хуткая ўсталёўка

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Пачатак работы

```bash
openamer              # Пачніце чаціць
openamer setup        # Наладзьце свае API-ключы і пастаўшчыка
openamer model        # Абярыце вашу мадэль
openamer update       # Абнавіце да найсвежа boreal версіі
```

## Абнаўленне

OpenAmer аўтаматычна праверяе наяўнасць абнаўленняў і паказвае папярэджанне ў прывітальным банеры. Запусціце `openamer update`, каб атрымаць найсвежаю версію — перад гэтым праграма створыць рэзервную копію вашых даных.
