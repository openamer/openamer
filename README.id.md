# OpenAmer Agent

**Agen AI yang mampu meningkatkan diri sendiri — belajar dari pengalaman, menciptakan keterampilan, mengingat preferensi Anda, dan bekerja untuk Anda di mana saja.**

Gunakan model apa pun yang Anda inginkan — OpenRouter, OpenAI, DeepSeek, dan lainnya. Beralihlah dengan `openamer model` — tanpa perlu perubahan kode.

## Fitur

- **Antarmuka terminal asli — TUI lengkap dengan pelengkapan otomatis, riwayat, dan output alat streaming**
- **Hadir di tempat Anda berada — Telegram, Discord, Slack, WhatsApp, dan lainnya dari satu gateway**
- **Belajar seiring waktu — memori, keterampilan yang terus berkembang, pengingatan lintas sesi**
- **Mendelegasikan & memparalelkan — membuat sub-agen untuk pekerjaan paralel**
- **Otomatisasi terjadwal — cron bawaan untuk laporan harian, pencadangan, audit**
- **Berjalan di mana saja — lokal, Docker, SSH, cloud, serverless**

## Instalasi Cepat

Windows (PowerShell):
```powershell
iex (irm https://github.com/openamer/openamer/raw/main/scripts/install.ps1)
```

Linux / macOS:
```bash
curl -fsSL https://github.com/openamer/openamer/raw/main/scripts/install.sh | bash
```

## Memulai

```bash
openamer              # Mulai mengobrol
openamer setup        # Atur kunci API & penyedia Anda
openamer model        # Pilih model Anda
openamer update       # Perbarui ke versi terbaru
```

## Memperbarui

OpenAmer memeriksa pembaruan secara otomatis dan menampilkan peringatan di banner selamat datang. Jalankan `openamer update` untuk mendapatkan versi terbaru — perintah ini akan mencadangkan data Anda terlebih dahulu.
