## 2. Reddit r/selfhosted Post

### Title
**I built an open-source AI agent that self-improves, has background computer-use, A2A swarm, and a 100/100 health score**

### Body

After months of building on top of the Hermes Agent architecture, I'm releasing **OpenAmer** — an open-source AI agent that runs **entirely on your own machine** with no external dependency, no telemetry-by-default, and no vendor lock-in.

**Why self-hosted?**
- Every install is a standalone, private-first node. Your data stays local.
- No API middleman — bring your own model (99+ model providers supported).
- Full background Computer-Use that **doesn't steal focus** — drive Windows, macOS, or Linux desktop without interrupting your work.
- A2A (Agent-to-Agent) swarm: every install is a P2P node. Query the network, share lessons, build collectively.

**What makes it special:**

| Feature | What it does |
|---|---|
| 🖥️ **Background Computer-Use** | Click, type, record, replay desktop actions — no focus steal |
| 🌐 **A2A Agent Swarm** | Peer-to-peer mesh. Query other agents across the network |
| 🧠 **Brain Learning Loop** | Auto-collects training data, shows growth graphs |
| 🛠️ **99+ Tools / 117 Skills** | Largest library in the open-source agent space |
| 👥 **Multi-Agent Crews** | Role-based teams (researcher, writer, analyst) |
| 🏪 **Agent Marketplace** | Search, install, publish community agents |
| 💾 **Durable Execution** | Checkpoint/resume — survives crashes |
| 📊 **Superintelligence Dashboard** | System health score 0–100 (currently **100/100**) |
| 🧩 **Self-Improving Skills** | Skills that improve during use |
| 🛡️ **Human-in-the-Loop** | Approve risky actions, auto-deny on timeout |
| 🔧 **Self-Modify with Test Gate** | Edit core code — rolled back atomically if tests fail |
| 🪟 **Windows-Native** | Full native support. No WSL. |

**Quick start (self-hosted):**
```bash
# Install
pip install openamer
openamer setup

# Or from source
git clone https://github.com/openamer/openamer
cd openamer
pip install -e .

# Start
openamer                      # chat right away
openamer super status         # see your 100/100 health score
openamer computer-use record my-task   # record desktop actions
openamer a2a status           # see your swarm identity
```

**License:** Apache 2.0  
**GitHub:** https://github.com/openamer/openamer  
**Docs:** https://openamer.github.io/openamer/

### First Comment

OpenAmer is a self-improving, self-learning open-source AI agent that runs entirely on your own hardware. No cloud dependency, no telemetry-by-default, no vendor lock.

**What it does differently:**

- **Background Computer-Use** — The only open-source agent that drives your desktop (Windows, macOS, Linux) without stealing focus. Also supports record/replay and cron-scheduled replay.
- **A2A Agent Swarm** — Every install is a peer-to-peer node. Query the network, share knowledge across instances. No central server.
- **Brain Learning Loop** — Automatically collects privacy-scrubbed training data from your sessions. Shows stats and growth graphs via `openamer brain stats`.
- **Self-Improving Skills** — 117+ bundled skills that improve during use.
- **Superintelligence Dashboard** — Real-time system health score (0–100). Currently scoring **100/100** on all metrics.
- **99+ tools** — Terminal, browser, filesystem, code editing, vision, voice, sub-agents, desktop control, and more.
- **Multi-Agent Crews** — Role-based teams (researcher, writer, analyst, etc.) built in.
- **Durable Execution** — Checkpoint/resume survives crashes.
- **Self-Modify with Test Gate** — You can edit the agent's core code, skills, or plugins. Changes are rolled back atomically if tests fail.
- **Agent Marketplace** — Search, install, and publish community agents.
- **Windows-Native** — No WSL required. Full native support.
- **Vector Memory Store** — Unlimited TF-IDF semantic memory, cross-session learning.

Everything is open-source under Apache 2.0: https://github.com/openamer/openamer
